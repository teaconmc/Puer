# 屋面瓦与屋脊

群青提供了六色屋面瓦家族与配套的屋脊系统，均位于 `ultramarine:building_blocks` 创造页签。

## 屋面瓦

每种颜色都有普通瓦、阶梯瓦与檐口瓦：

| 颜色 | 瓦 |
|:---|:---|
| 灰 | `ultramarine:gray_roof_tiles`、`ultramarine:gray_roof_tile_stairs`、`ultramarine:gray_roof_tile_edge` |
| 黄 | `ultramarine:yellow_roof_tiles`、`ultramarine:yellow_roof_tile_stairs`、`ultramarine:yellow_roof_tile_edge` |
| 绿 | `ultramarine:green_roof_tiles`、`ultramarine:green_roof_tile_stairs`、`ultramarine:green_roof_tile_edge` |
| 蓝 | `ultramarine:blue_roof_tiles`、`ultramarine:blue_roof_tile_stairs`、`ultramarine:blue_roof_tile_edge` |
| 青 | `ultramarine:cyan_roof_tiles`、`ultramarine:cyan_roof_tile_stairs`、`ultramarine:cyan_roof_tile_edge` |
| 黑 | `ultramarine:black_roof_tiles`、`ultramarine:black_roof_tile_stairs`、`ultramarine:black_roof_tile_edge` |

## 屋脊

屋脊用于封顶脊线，有黑、黄两色。黑色屋脊构件包括：

- `ultramarine:black_roof_ridge_upper` 与 `ultramarine:black_roof_ridge_lower` —— 两种屋脊型面。
- `ultramarine:black_roof_ridge_connection` 与 `ultramarine:black_main_roof_ridge_connection` —— 交接件。
- `ultramarine:black_roof_ridge_upper_slab`、`ultramarine:black_main_roof_ridge_slab`、`ultramarine:black_main_roof_ridge_panel`、`ultramarine:black_main_roof_ridge_plate` 与 `ultramarine:black_main_roof_ridge_stairs` —— 台阶/片/板/楼梯形式。

黄色套件与黑色一一对应：`ultramarine:yellow_roof_ridge_upper`、`ultramarine:yellow_roof_ridge_lower`、`ultramarine:yellow_roof_ridge_connection`、`ultramarine:yellow_main_roof_ridge_connection`、`ultramarine:yellow_roof_ridge_upper_slab`、`ultramarine:yellow_main_roof_ridge_slab`、`ultramarine:yellow_main_roof_ridge_panel`、`ultramarine:yellow_main_roof_ridge_plate` 与 `ultramarine:yellow_main_roof_ridge_stairs`。
