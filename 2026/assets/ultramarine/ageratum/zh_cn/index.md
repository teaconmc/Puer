# 群青（Ultramarine）

群青（Ultramarine）是一个中国风 Minecraft 模组，在九个创造模式页签下加入传统建筑构件、大木作结构、家具与室内陈设。本模组面向 NeoForge 加载器开发，当前为 `0.8-snapshot` 版本，支持 Minecraft 26.1.2（NeoForge 26.1.2.36-beta）。

## 阅读路线

1. [材料与采矿](01_materials_and_mining)：开采玉、菱镁矿、赤铁矿与钴，精炼后制备砖、屋面瓦、瓷器、染料粉与木作模板。
2. [制作台与工具](02_crafting_stations_and_tools)：木槌、青花瓷工具，以及木作台、砖窑、刻花台与对应的自定义配方类型。
3. [建筑材料](03_building_blocks)：各类砖、石材、地板砖，以及花梨木板与竹席等木质建材。
4. [屋面瓦与屋脊](04_roofing_and_ridges)：六色屋面瓦（含阶梯与檐口变体），以及屋脊构件。
5. [大木构架](05_structural_woodwork)：斗拱、彩绘木、柱、方心、爪头、栱头、椽、梁、雀替、垂花、栏杆与守门石狮。
6. [家具、门窗、陈设与植物](06_furniture_doors_decor_plants)：柜橱与坐具、门窗、室内庭院陈设、灯具与植物。

## 创造页签

群青注册了九个创造页签，每个页签收纳一组相关物品：

| 页签 | 代表性物品 |
|:---|:---|
| `ultramarine:materials` | 矿石、精炼材料、砖、屋面瓦、瓷器、染料粉、模板 |
| `ultramarine:tools` | 木槌、青花瓷工具、工作台 |
| `ultramarine:building_blocks` | 砖、石材、地板砖、木板、屋面瓦与屋脊 |
| `ultramarine:decorative_blocks` | 斗拱、彩绘木、柱、结构饰件、栏杆 |
| `ultramarine:decorations` | 书房、瓷器、庭院道具、墙面、食物 |
| `ultramarine:furniture` | 柜橱、桌、椅、床、屏风 |
| `ultramarine:windows_and_doors` | 门、窗、门扇、窗帘 |
| `ultramarine:lamps` | 灯笼、灯、路灯、烛台 |
| `ultramarine:plants` | 荷花、常春藤、落叶堆、盆景 |
