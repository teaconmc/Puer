# 材料与采矿

`ultramarine:materials` 创造页签汇集了模组使用的原矿、精炼产物与中间材料。

## 矿石与精炼材料

四种矿石及其精炼产物：

| 矿石方块 | 精炼产物 |
|:---|:---|
| `ultramarine:jade_ore`、`ultramarine:deepslate_jade_ore` | `ultramarine:jade`，另有 `ultramarine:jade_block` 与 `ultramarine:jade_parts` |
| `ultramarine:magnesite_ore`、`ultramarine:deepslate_magnesite_ore` | `ultramarine:magnesite`、`ultramarine:magnesite_dust` |
| `ultramarine:hematite_ore`、`ultramarine:deepslate_hematite_ore` | `ultramarine:raw_hematite`、`ultramarine:hematite_dust` |
| `ultramarine:nether_cobalt_ore` | `ultramarine:raw_cobalt`、`ultramarine:cobalt_dust` |

`ultramarine:bronze_ingot` 与 `ultramarine:bronze_dust` 延伸了青铜材料链，`ultramarine:bronze_block` 用于存储。

## 砖与屋面瓦

砖家族先制成生黏土（`ultramarine:unfired_clay_brick`）、染色生砖（`ultramarine:unfired_cyan_brick`、`ultramarine:unfired_black_brick`、`ultramarine:unfired_brownish_red_stone_brick`）与烧成结果（`ultramarine:fired_brick`）。成品砖为 `ultramarine:cyan_brick`、`ultramarine:black_brick` 与 `ultramarine:brownish_red_stone_brick`。此处另有次级材料 `ultramarine:prismarine_dust`。

屋面瓦遵循类似的生坯到烧成的路线：`ultramarine:unfired_roof_tile` 烧成各色瓦 `ultramarine:gray_roof_tile`、`ultramarine:yellow_roof_tile`、`ultramarine:green_roof_tile`、`ultramarine:blue_roof_tile`、`ultramarine:cyan_roof_tile` 与 `ultramarine:black_roof_tile`。

## 木板与框架

每种原版木材以及模组自带的木材都有抛光木板：`ultramarine:polished_oak_plank`、`ultramarine:polished_birch_plank`、`ultramarine:polished_spruce_plank`、`ultramarine:polished_jungle_plank`、`ultramarine:polished_acacia_plank`、`ultramarine:polished_dark_oak_plank`、`ultramarine:polished_warped_plank`、`ultramarine:polished_crimson_plank`、`ultramarine:polished_mangrove_plank`、`ultramarine:polished_cherry_plank`、`ultramarine:polished_rosewood_plank` 与 `ultramarine:polished_ebony_plank`。`ultramarine:wooden_frame` 是常用的建筑框架原料。

## 瓷器材料

瓷器链始于 `ultramarine:calcite_dust` 与 `ultramarine:blue_and_white_glaze_powder`。粘土中间物包括 `ultramarine:small_clay_vase`、`ultramarine:medium_clay_vase`、`ultramarine:large_clay_vase`、`ultramarine:tall_clay_vase`、`ultramarine:clay_pot`、`ultramarine:tall_clay_pot`、`ultramarine:clay_plate` 与 `ultramarine:clay_bowl`。成品瓷器包括白釉与绿釉花瓶、`ultramarine:tall_blue_porcelain_vase`、`ultramarine:tall_blue_and_white_porcelain_vase`、`ultramarine:black_porcelain_plate` 与 `ultramarine:blue_and_white_porcelain_plate`。余料可回收为 `ultramarine:blue_and_white_porcelain_piece`、`ultramarine:blue_and_white_porcelain_shards` 与 `ultramarine:porcelain_piece`。

## 染料粉与模板

十六种染料粉（`ultramarine:white_dye_powder` 至 `ultramarine:black_dye_powder`）加上 `ultramarine:gold_dye_powder` 为彩绘木着色。刻花模板覆盖每类装饰构件：`ultramarine:carved_wood_template`、`ultramarine:carved_wool_template`、`ultramarine:fangxin_template`、`ultramarine:fangxin_edge_template`、`ultramarine:zhaotou_template`、`ultramarine:gutou_template`、`ultramarine:rafter_template`、`ultramarine:rafter_end_template`、`ultramarine:architrave_template` 与 `ultramarine:caihua_template`。

## 零件与其他材料

通用零件可组合为陈设：`ultramarine:wooden_parts`、`ultramarine:gold_parts`、`ultramarine:jade_parts`、`ultramarine:porcelain_parts` 与 `ultramarine:bronze_parts`。日常材料还包括 `ultramarine:incense`、`ultramarine:fur`、`ultramarine:grease`、`ultramarine:silk`、`ultramarine:xuan_paper` 与 `ultramarine:copper_cash_coin`。

可食用材料也在此页签：`ultramarine:mooncake`、`ultramarine:mung_bean_cake`、`ultramarine:raw_meat`、`ultramarine:cooked_meat` 与 `ultramarine:baozi`。
