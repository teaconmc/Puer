# 电报

电报机是《书信、信号与电话》里的「信号」：一条以频率为键、逐个符号操作的广播通道。

## 机器

`telegraph_machine` 是金属方块（强度 2.5 / 6.0，需要正确工具才掉落），拥有自己的方块实体与界面。

<recipe id="letter_signal_phone:telegraph_machine"/>

**同一台机器同时只能由一名玩家操作。** 第二名玩家试图打开时会被拒绝：「这台电报机正被其他玩家使用。」

## 操作

界面通过一小组状态字符串回报其状态：

| 状态 | 含义 |
|:---|:---|
| 频率已设置 | 已选定频率 |
| 无法开始 | 当前状态下无法开始发报 |
| 已开始 | 发报进行中 |
| 点 | 键入了一个点 |
| 划 | 键入了一个划 |
| 空格 | 键入了一个间隔 |
| 已结束 | 发报结束 |

因此一条消息是由**点、划与空格**逐步构成的——是莫尔斯式击键，而非直接输入文本。

## 频率

发报绑定到某个**频率**。设为同一频率的机器构成一条通道，这正是消息能到达接收方而不只停留在操作机上的方式。

## 电报纸

`telegram_paper`（堆叠上限 1）是接收消息的物品，其提示文本以 `电报：%s` 显示解码后的内容。

电报纸**没有合成配方**——它来自电报机制本身。
