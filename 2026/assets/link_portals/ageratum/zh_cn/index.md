# 联界门

联界门让你建造**具名传送门**并把它们编入**频道**。任何两个共享同一频道名的传送门即互相连通，走进其中一个就会到达另一个——不限距离，也不限维度。

当一个频道里有超过两个传送门时，走进去会打开**目的地列表**，由你选择去哪。

## 首先要读的

::: warning
**模组的两件物品都无法合成。** 本检出**根本没有 `data/` 目录**，因此模组不随包任何配方、战利品表或进度。

在此之上，创造分页里**只有联界门激活器**。联界门框架的方块物品不属于任何创造分页，因此创造模式搜索也找不到它——实际上只能 `/give`。

**生存可行的路线是原版哭泣的黑曜石**，模组在任何接受自有框架方块的位置都同样接受它。见 [01 获取开始](01_getting_started)。
:::

## 各部分如何配合

| 部件 | 作用 |
|:---|:---|
| **联界门框架**（或哭泣的黑曜石） | 你搭建的那个环 |
| **联界门激活器** | 右键环体点亮它并命名 |
| **频道名称** | 连接关系 —— 同名即连通 |
| **传送门名称** | 在目的地列表中显示的标签 |

频道名称留空会变成 `default`，因此你从未费心命名的传送门之间仍然能互相找到。
