# 开始使用

## 你实际需要安装什么

元数据声明了三个依赖，构建却需要十一个。以下是诚实的清单：

| 模组 | 已声明？ | 为何需要 |
|:---|:---|:---|
| NeoForge、Minecraft | 是 | |
| **`modulargolems`** | **是**——必需，`[26.1.2.0,)` | 你要打的傀儡、它们的物品与实体类 |
| **`golemdungeons`** | **否** | 商店货币，以及本模组写入的那套配置系统 |
| L2Core | 否 | 注册、配置管线、创造分类 |
| L2Serial | 否 | 网络 |
| L2DamageTracker | 否 | 攻击监听器 |
| L2Tabs、L2MenuStacker、L2ItemSelector | 否 | 界面 |
| Registrate | 否 | 注册 |
| Curios | 否 | 装备槽位 |
| L2ModularBlock | **随包内置** | 打包在 jar 内 |

只有一个库被打包进 jar，其余全部必须在场。

::: warning
**`golemdungeons` 是最需要留意的那个。** 它不只是编译期的便利：本模组把 **200 个配置文件写到 `golemdungeons` 自己的配置命名空间**，而其商店条目是用那个模组的物品计价的——`reforge_upgrade`、`resistance_upgrade`、`ancient_forge`、`flame_sword`。

源码中**任何地方都没有 `ModList.isLoaded` 守卫**，因此不存在优雅降级。请安装整条链：`modulargolems` → `golemdungeons` → 本模组。
:::

Minecraft 范围是 `[26.1.2,26.2)`，因此接受 26.1.x 而不接受 26.2。

## 什么都不能合成

模组**完全不附带 recipe 目录**。每件物品都来自地牢本身——战利品表、商人，或创造分类。

创造分类注册在 L2Core 的命名空间下，因此请在该库提供的分类中寻找 **无限地牢**，而不是把它当作一个独立条目。

## 三件要紧的物品

| 物品 | 作用 |
|:---|:---|
| **通行钥匙** | 传送进出迷宫 |
| **迷宫地图** | 右键打开地图；对**重生锚**右键可前往其他重生锚 |
| **死者之钥** | 取回你上次在迷宫中死亡时**最多九件**物品 |

死者之钥的提示文本会显示有多少件物品在等待，因此你能一眼看出是否有待取回的东西。

**请注意那个九件的上限。** 带着满物品栏死在迷宫深处，意味着大部分东西没了——死者之钥是部分救援而非完全救援。请规划你带进去的东西。

## 七种方块

| 方块 | 作用 |
|:---|:---|
| 迷宫石 | 地牢的结构石材 |
| 填充方块 | 生成器填充用 |
| 力场 / 力场方块 / 破损力场 | 封锁房间的屏障 |
| 商人方块 | 商人出现的位置 |
| 定位器 | 地牢布局标记 |

它们是生成器的家具而非建筑材料——你在迷宫里遇到它们，而不是自己放置它们。

## 第一次游玩

1. 安装上述完整依赖链。
2. 获得一把**通行钥匙**并使用它。
3. 清空第一个房间——仅此一项就能拿到一个成就。
4. 从提供的选项中取一项祝福。
5. 寻找**精英房间**解锁整层地图，再找**首领房间**下潜。

接下来请读 [02 迷宫](02_the_maze)：该维度有一些会让你措手不及的规则，包括床会爆炸。
