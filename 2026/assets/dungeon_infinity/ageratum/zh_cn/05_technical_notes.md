# 须知

## ⚠️ 不要在迷宫里睡觉

::: danger
**床在迷宫维度里会爆炸。** 你无法睡觉、无法设置重生点，尝试使用会直接引爆那张床——与下界完全一样。

**进去之前先设好你的重生点。** 迷宫内部没有任何办法建立安全落点，所以请围绕「怎么回去」来规划行程，而不是围绕「在里面休息」。
:::

## 迷宫与主世界的其他差异

| 行为 | 在迷宫里 |
|:---|:---|
| **床** | **会爆炸** —— 不能睡、不能设重生点 |
| **岩浆** | 流速很快，与下界一致 |
| **袭击** | 无法发起 |
| **猪灵** | 不会僵尸化，传送门也不会生成它们 |
| 环境光 | 昏暗但不会全黑 |
| 天气 | 没有 |

## 迷宫里不会自然生成任何东西

迷宫本身**没有矿石、没有洞穴、也没有自然生成的生物**。你遇到的一切都是地牢生成器有意放置的。

::: tip
**这正是迷宫显得「被设计过」而非随机的原因。** 别指望进去挖资源——墙里什么都没有。所有值得拿的东西都在房间、箱子与商店里。

这也意味着危险程度完全是设计出来的。如果某一层感觉更难，那是有意为之，而不是刷怪运气差。
:::

## 本模组没有任何可合成的东西

**完全没有配方。** 钥匙、地图与方块都来自地牢本身、商店，或创造模式。

所以「陵墓钥匙」与「通行钥匙」是你**找到或买到**的东西，永远不是你做出来的。

## ⚠️ 必需的配套模组

::: danger
**本模组无法单独运行。** 它属于同一作者的模组链，需要同时安装：

- **傀儡装配（Modular Golems）**
- **Golem Dungeons**

以及同作者的若干支持库。

**缺少依赖会导致启动失败，而不是功能降级。** 这里没有优雅的回退——如果加入本模组后游戏起不来，第一个该检查的就是配套模组是否缺失。

好消息是它们都出自同一作者且版本配套发布，所以整组一起安装就能完全避开这个问题。
:::

## 七个难度层级，五套主题布局

模组定义了**七个层级**的敌人与装备——early、copper、stone、mineshaft、deepslate、sculk 与 deepest。

::: info
**但其中只有五个有自己的结构集。** 最深的两个层级只提高难度而不引入新的房间布局，因此你会认出建筑样式，而危险仍在继续攀升。

知道这一点，你就不会误以为地牢停止生成新内容了——到那个阶段成长的是敌人而不是房间。见[迷宫](02_the_maze)。
:::

## 语言支持

**英文与简体中文都完整且完全对应。** 这里没有翻译欠账——中文客户端全程显示正常名称。

模组采用 **LGPL-2.1**，因此可以在该许可条款下再分发——不同于本区间大多数模组，那些需要作者的明确许可。
