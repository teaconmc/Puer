# 祝福与进度

## 挑选祝福

清空一个房间后，你会**从若干项中获得一项奖励**——界面标题是*选择其中一个奖励*。你可以**刷新有限次数**，界面会显示剩余刷新次数。刷新需要**消耗经验值**。

因此每次取胜都是一个带预算的小决策：现在拿一个够用的，还是花经验与刷新次数去找更好的。

祝福会累积为*迷宫祝福*，可在其专属面板中查看，旁边还有迷宫信息面板。

## 十项祝福

| 祝福 | 效果 |
|:---|:---|
| **基岩甲** | 你在迷宫中时获得常驻属性加成 |
| **弹簧手** | 你在迷宫中时获得常驻属性加成 |
| **神行靴** | 你在迷宫中时获得常驻效果 |
| **地牢力场** | 按百分比减少你受到的伤害 |
| **神圣祝福** | 立即获得一个效果 |
| **天降宝牌** | 立即获得物品 |
| **胜者之徽** | 每次通过房间时，为**你所有傀儡——迷宫中的与物品栏内的**恢复一定百分比生命值 |
| **战后补给** | 每次通过房间时获得物品 |
| **真实之眼** | **房间探测器奖励翻倍**，并**视野范围 +1** |
| **迷宫保险** | 当你在迷宫中死亡时，复活后获得一些东西 |

其中三组值得分开来看：

**常驻类**——基岩甲、弹簧手、神行靴、地牢力场——在你身处迷宫期间生效，离开后即无关。它们是会复利的选择：早期拿到，之后每个房间都受益。

**逐房间类**——胜者之徽与战后补给——每次清空都会发放，因此其价值随你打算下潜的深度而放大。短程游玩时它们不如一次性固定加成。

**真实之眼是信息型选择。** 探测器奖励翻倍改变你能看清多少层内容，而视野范围影响地图。若你苦于找不到精英或首领房间，这项祝福直接有帮助。

::: tip
**胜者之徽治疗的是物品栏内的傀儡，不只是已部署的。** 傀儡在放置前以物品形式携带，而该祝福明确覆盖两者。若你在战斗中轮换傀儡，它比字面读起来强得多——你收进包里的受损傀儡仍会恢复。
:::

**迷宫保险是唯一在失败时发放的祝福。** 其余全部假设你会赢。在很可能死亡的深潜中，它把一次全灭转化为部分回收——请与死者之钥搭配，后者能从同一次死亡中取回最多九件物品。

## 九个成就

它们勾勒出从抵达到最底层的完整一程。

| 成就 | 要求 |
|:---|:---|
| 欢迎来到无限地牢 | 造访迷宫 |
| 初次交锋 | 通过第一个房间 |
| 地图室 | 通过**精英**房间——解锁完整地图 |
| 中央指挥所 | 通过**首领**房间——解锁下一层 |
| 收集者 | 清空**一层的所有房间** |
| 探险家 | 探索 100 个迷宫房间 |
| 老练冒险家 | 通过 100 个房间 |
| 深渊之底 | 进入**最底层** |
| 征服者 | 通过**最底层的大型房间** |

请注意成就文本印证了 [02 迷宫](02_the_maze) 所述的两道闸：精英房间明示的奖励是地图，首领房间的是下一层。两个「一百房间」成就是分开的——一个数**探索过**的房间，另一个数**通过的**房间——因此游荡与战斗被独立统计。

**收集者是完美主义者的陷阱。** 清空一层的所有房间是可选的；单靠首领房间就能打开向下的路。做全清要付出时间与资源，换来的是成就以及那些额外房间里的战利品。
