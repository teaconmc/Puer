# 迷宫

地牢位于自己的维度 `dungeon_infinity:maze` 中，配有自定义区块生成器与自定义生物群系。它没有任何一点像主世界。

## 该维度的规则

进去之前请先读这些，因为其中两条会让你吃亏。

| 规则 | 取值 |
|:---|:---|
| **床** | **无法设置重生点、无法睡觉，且会爆炸** |
| 生物自然生成 | **无**——每个生成列表都是空的 |
| 地形特征与洞穴雕刻 | **无**——生物群系不生成任何东西 |
| 降水 | 无 |
| 环境光 | 0.5 |
| 袭击 | 无法开始 |
| 岩浆 | 快速流动，与下界相同 |
| 猪灵 | 不僵化，传送门也不生成它们 |

**床会爆炸。** 不要带一张床进去指望它当存档点——维度类型在禁止睡觉与设置重生点之外还设了 `explodes: true`。重生锚才是这里可用的机制，而迷宫地图与它们联动；见 [04 地图与商人](04_map_and_merchants)。

**没有生物会自然生成。** 生物群系生成表的每一项都是空的，且该群系完全没有特征与雕刻器。你遇到的一切与看到的一切都由地牢生成器放置。这正是地牢能保证自身难度曲线的原因——不会有东西游荡进来。

## 房间类型

地图图例列出八种地点：

| 房间 | 用途 |
|:---|:---|
| 战斗 | 普通战斗房间 |
| 精英 | 更难的战斗；清空一个可**解锁整层地图** |
| 首领 | 清空一个可**解锁下一层** |
| 商店 | 商人 |
| 奖励 | 战利品 |
| 休整 | 战斗之间的恢复 |
| 上行 / 下行楼梯 | 层间移动 |

因此每一层的推进有两道闸：**精英房间**给你信息（整张地图），**首领房间**给你深度（向下的路）。你可以在信息不全的情况下下潜，但不能不打首领。

## 主题与层级

地牢有**五套已搭建的主题**，各有自己的结构集：

| 主题 | 结构数 |
|:---|:---|
| 铜 | 13 |
| 石 | 13 |
| 废矿井 | 13 |
| 深板岩 | 13 |
| 幽匿 | 13 |

每套是**2 个根件 + 6 条走廊 + 5 个房间**。另有一套名为 `test` 的 5 件集合，属开发脚手架而非内容。

但难度配置识别的是**七个层级**，不是五个：

| 层级 | 有自己的结构吗？ |
|:---|:---|
| 早期 | **无** |
| 铜 | 有 |
| 石 | 有 |
| 废矿井 | 有 |
| 深板岩 | 有 |
| 幽匿 | 有 |
| 最深 | **无** |

**早期与最深拥有完整的生成、装备与试炼配置，但没有自己的迷宫结构**，因此它们靠复用其他主题的几何体、配上自己的敌人与战利品表来实现。实际效果是：一次游玩的最初与最末段看起来像邻近主题，但打起来完全不同。

## 敌人是什么

傀儡，来自母模组。每个层级都有自己的表：

| 配置类型 | 七个层级合计文件数 |
|:---|:---|
| 生成表 | 69 |
| 装备表 | 85 |
| 试炼定义 | 46 |

装备表是详细的而非象征性的——它们为每个护甲槽位指定加权物品池，逐条目带附魔等级与掉落概率，并为人形、马与狼的护甲分设表格。例如铜层级的胸甲池以相等权重混合铁、金与铜，前两者附魔等级 30、第三者 20。

**装备条目的掉落概率统一为 0.085**——即大约十二件里有一件能从其穿戴者身上留下来。刷地牢换装备可行，但很慢。

## 一层的结构

层由**列布局**配置排布，用主题的走廊与房间组装，并以力场方块封锁。地图图例以数字显示层数，上下楼梯连接各层。

生成器、布局预设与模板全部是**数据驱动**的——五个模板文件、一个列预设，加上上述逐层级的表格。这也是整合包作者要修改地牢时应编辑的机制。
