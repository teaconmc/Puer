# 地图与商人

## 迷宫地图

右键迷宫地图可打开该层地图。它显示你已知的房间并按类型标记，当前层数以数字呈现。

图例使用这些标记：

| 标记 | 含义 |
|:---|:---|
| 战斗 | 战斗房间 |
| 精英 | 精英房间 |
| 首领 | 首领房间 |
| 商店 | 商人 |
| 奖励 | 战利品房间 |
| 休整 | 恢复房间 |
| ↑ / ↓ | 上行与下行楼梯 |
| 🔎 | 放大镜 |

**默认情况下你看不到整层。** 清空精英房间才解锁完整地图；在那之前你只能依靠已探索与已揭示的部分。

## 房间探测器

探测器是一种消耗资源，用于**揭示**你尚未造访的房间。地图会显示你还剩多少个。

**真实之眼**祝福会让探测器的收益翻倍并加 +1 视野范围，这使探测器成为该祝福所围绕设计的机制。若你在挑选祝福且手里握有若干探测器，这个组合是可用的最强信息型打法。见 [03 祝福与进度](03_blessings_and_progression)。

## 地图覆盖层

地图不只是一个界面。一个可配置的**屏幕覆盖层**可以在你游玩时常驻，并有自己的设置面板：

| 设置 | 选项 |
|:---|:---|
| 屏幕地图 | 关闭 / 手持时 / 非手持时 / 始终 |
| 跟随玩家 | 开 / 关 |
| 位置 | 可调 |
| 缩放 | 百分比 |
| 大小 | 百分比 |

**「手持时」与「非手持时」是两个分开的选项，且两者都存在。** 这不寻常且实用：你可以让覆盖层只在地图*不*在手上时出现，从而在你真正阅读完整地图界面时不挡视线。

## 传送点与重生锚

模组加入了可传送的路径点，由专用数据包在客户端与服务端之间同步。

迷宫地图还有一个容易被忽略的第二功能：**用它对重生锚右键，可以前往其他重生锚。** 由于该维度禁止睡觉且床会爆炸（见 [02 迷宫](02_the_maze)），重生锚是迷宫中唯一的固定点——而地图就是你在它们之间移动的方式。

请在下潜时布设锚点。它们同时是你的快速旅行网络与重生方案。

## 从死亡中恢复

有两样东西能减轻在迷宫中死亡的损失，且两者可叠加：

**死者之钥**能从你最近一次在迷宫中的死亡里取回**最多九件**物品。它的提示文本会报告有多少件在等待。

**迷宫保险**（若你取了该祝福）会在你复活后给予一些东西。

请注意那个上限：九件是部分恢复。在迷宫深处丢掉的满物品栏大部分是永久损失，而这正是本模组真正的难度压力所在——不是战斗本身，而是一次全灭的代价。

## 三名商人

商人出现在商店房间的商人方块处，共三种：

| 商人 | 职能 |
|:---|:---|
| **铁匠** | 装备 |
| **杂货商** | 补给 |
| **回收商** | 转化不需要的货物 |

商店存货是**逐主题数据驱动**的——五套已搭建主题各有一个商店配置文件，另有一份图标定义。因此铜层级的铁匠与幽匿层级的铁匠按设计提供不同的东西。

::: warning
**商店价格部分以另一个模组的物品计价。** 商店配置中列出的成本包括 `golemdungeons:reforge_upgrade` 与 `golemdungeons:resistance_upgrade`，战利品条目也引用 `golemdungeons:ancient_forge` 与 `golemdungeons:flame_sword`。

它们来自 `golemdungeons`，而该模组**未在本模组的元数据中声明**。未安装它时，受影响的商店与战利品条目指向的是不存在的物品。见 [01 开始使用](01_getting_started)。
:::

## 选择商人提供的内容

有一个专用数据包把**类型选择**从客户端送到服务端，因此商人界面允许你选择类别，而不只是浏览一份固定清单。结合逐主题的商店文件，你能买到什么既取决于你在哪里，也取决于你要什么。
