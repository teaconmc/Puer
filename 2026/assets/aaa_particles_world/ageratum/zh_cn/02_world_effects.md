# 世界特效

## 暴击与魔法暴击

普通暴击会在受击实体包围盒中心播放 `essentials/critical` 特效；魔法暴击使用蓝色的迷你爆炸特效。模组会拦截原版的 `CRIT` 与 `ENCHANTED_HIT` 跟踪粒子，因此启用替换时不会再同时生成对应的原版跟踪发射器。

两类暴击有独立开关，可以只保留其中一种替换。

::: warning
当前源码的 `handleAnimate` 注入误用实体 ID 判断动画动作。运行时实体 ID 恰为 `4` 或 `5` 时，任意动画包都可能被错误当作普通暴击或魔法暴击，并在对应替换开关开启时取消；这与实体类型无关。其他实体仍通过原版跟踪粒子的替换路径处理暴击。
:::

## 闪电

每个新闪电实体只领取一次播放资格。启用替换且仍有并发额度时，模组在闪电位置播放新特效并隐藏该闪电的原版渲染；若额度已经用完，该闪电会保留原版外观。

![紫白色闪电特效与飞散碎片](aaa_particles_world:ageratum/aaa_particles_world_showcase_lightning_bolt.png)

## 爆炸

- 小型爆炸使用黄色迷你爆炸。
- 大型爆炸使用完整爆炸特效。
- 客户端收到带半径的爆炸数据时，会以 `半径 x 1.75` 作为视觉缩放依据。
- 当小型爆炸粒子提供器发现爆炸点附近十格内有正在死亡的末影龙时，会改用蓝色版本。

大型与小型替换相互独立。只关闭大型替换时，原版大型爆炸内部生成的小爆炸仍可能被替换；想完整恢复原版爆炸，需要同时关闭两项。

![大型爆炸产生的明亮粒子冲击](aaa_particles_world:ageratum/aaa_particles_world_showcase_explosion.png)

## 战利品光束与落地音效

掉落物只在生成后尝试创建一次光束。模组读取物品提示的第一行名称颜色：

- 名称没有颜色或颜色为白色：不生成光束，也不播放专用落地音效。
- 名称带其他颜色：以该颜色生成光束。

落地音效依赖光束功能开启。为避免物品在高度略有差异的方块边缘重复响声，只有离地后的 Y 轴速度小于或等于 `-0.1`，随后重新接地时，才会重置下一次播放资格。

![有色掉落物上方的战利品光束](aaa_particles_world:ageratum/aaa_particles_world_showcase_loot.png)

## 火球尾焰

模组为支持的 `Fireball` 实体绑定 `missile_boost` 尾焰，按实体尺寸缩放，并用飞行速度确定朝向。启用时会隐藏该火球的原版着火外观和原版尾迹。不可见火球不会在加入客户端世界时创建尾焰。

火球尾焰要求粒子档位为“全部”。

## 沼泽萤火虫

萤火虫是围绕本地玩家移动的纯视觉环境发射器，仅在以下条件全部成立时出现：

- 客户端玩家所在生物群系属于沼泽标签。
- 世界默认时钟处于 `13000`（夜晚开始）至 `23500` 之间。
- 当前世界没有下雨。
- 萤火虫开关开启，且 Effekseer 特效整体可用。

离开条件范围后，发射器会用 `20` 个客户端刻淡出，然后停止。
