# 开始使用

## 安装条件

当前开发快照面向 Minecraft `26.1.2`，同时提供 Fabric 与 NeoForge 实现，并强制依赖 **AAA Particles** `2.1` 或更高版本。AAA Particles 负责加载和播放 Effekseer 资源，本模组负责把这些资源接入世界事件。

Fabric 元数据将模组声明为客户端环境；NeoForge 版本也把视觉初始化与配置注册放在客户端入口。模组没有服务端借助才能触发的玩法内容。

## 启用方式

进入世界后效果会自动生效，不需要手持物品、执行命令或设置按键。所有功能默认开启。

NeoForge 版本注册了模组配置界面，可从支持该入口的模组列表打开。Fabric 版本通过 Forge Config API Port 注册同一份客户端配置；是否有图形界面取决于当前整合环境，配置项本身保持一致。

## 快速检查

可用以下事件确认模组是否正在工作：

1. 对生物造成一次普通暴击或魔法暴击。
2. 在安全距离观察一次闪电。
3. 观察一次小型或大型爆炸。
4. 丢出一个名称带非白色品质颜色的物品，查看光束与落地音效。

如果其中一类没有变化，先检查对应配置开关。若所有类别都没有变化，则检查 AAA Particles 是否加载、Minecraft 粒子设置是否为“最少”，以及当前平台是否被 AAA Particles 判定为不受支持。
