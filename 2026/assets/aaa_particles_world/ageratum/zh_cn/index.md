# AAA Particles: World

AAA Particles: World 是 **AAA Particles** 的客户端视觉扩展。它不增加可合成物品，而是自动替换或补充世界中的战斗、爆炸、掉落物与环境特效。

## 阅读路线

1. [开始使用](01_getting_started)：依赖、启用方式与快速检查。
2. [世界特效](02_world_effects)：暴击、闪电、爆炸、光束、火球和萤火虫。
3. [客户端配置](03_configuration)：全部开关、并发上限与默认值。
4. [兼容性与性能](04_compatibility_and_performance)：粒子档位、平台限制和故障排查。

## 快速认识

- 当前源码版本为 `2.0.1-alpha.4`，面向 Minecraft `26.1.2`。
- 模组依赖 `aaa_particles` `2.1` 或更高版本。
- 效果在客户端自动运行，没有专用按键、命令、物品、方块或配方。
- 每类效果都能单独关闭，闪电、爆炸和战利品光束还有并发上限。

::: tip
第一次使用时，先阅读“开始使用”，再到安全地点观察暴击、闪电或爆炸。若完全没有特效，请直接查看“兼容性与性能”。
:::
