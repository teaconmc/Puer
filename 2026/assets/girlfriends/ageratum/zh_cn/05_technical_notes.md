# 须知

## 三个开关，全部默认开启

整个配置就三个开关，一切开箱即用：

| 选项 | 控制什么 |
|:---|:---|
| 关系绑定 | 能否缔结关系 |
| 任务 | 任务系统 |
| 邀请回家 | 能否邀请角色回家 |

::: tip
**如果服务器禁用了其中某项，游戏里会明确告诉你**——每个开关都有对应的拒绝提示，而不是让你自己猜。
:::

## 好感度命令需要管理员权限

`/affection` 可以读取、设置或增减一名角色的好感度。**它被限制为游戏管理者可用**，所以在服务器上那是管理员的工具，不是每个玩家都能用的。

把它指向五名角色之外的任何东西会得到明确的拒绝提示。

## 角色遵循每日作息

每名角色都按一条**每日时间线**生活——清晨、日间工作、下午、黄昏、夜间休息——由主世界时钟驱动。

结合她们对周围环境的感知（花、蜂巢、庇护所、敌对生物），她们的行为取决于**一天中的时刻与所在位置**，而不仅仅是你下达的指令。

::: tip
**找不到某个角色时，先看看时间。** 她多半正在做作息表上的事，而不是走丢了。
:::

## 语音只有中文，但字幕不是

角色说话有录制好的语音——**共 103 条，只录了中文**。这套系统本身是为多语言设计的，但其他语言的录音并不存在。

字幕与音频是分开的，且**英文与中文都已完整翻译**，所以任何语言下字幕都能正常显示。

::: info
因此英文玩家听到的是中文语音、但下方显示的是正确的英文字幕。这是预期行为，不是安装出了问题。
:::

## 不需要额外安装任何东西

::: tip
**模组除 NeoForge 与 Minecraft 外别无所需** —— 这句话经核实是真的。没有动画库、没有 Curios、没有任何可选项。

装上就能用。
:::

## 一个小谜团：四张方块形状的贴图，却没有方块

jar 里有几张看起来像方块的贴图，但模组根本不注册**任何方块**。它们属于浇水壶的立体物品模型——所以如果你在翻资源时看到「方块」贴图，那就是它们的用途。
