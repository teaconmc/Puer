# 开始使用

## 把角色带进世界

::: warning
**使用 `/summon`。** 没有刷怪蛋、没有自然生成，也没有任何包含她们的结构。

```
/summon girlfriends:momo
/summon girlfriends:yuxi
/summon girlfriends:meishu
/summon girlfriends:wanying
/summon girlfriends:youruo
```

五人全部注册为 `MobCategory.MISC`——原版用于「永不自行生成」之物的类别——且模组不添加生成放置规则与生物群系修改器。当前状态下这是一个只能召唤的模组。
:::

## 你需要安装什么

除 NeoForge 与 Minecraft 之外什么都不需要。元数据恰好只声明了这两个，而这是正确的：构建文件提到了一个库，但源码从未使用它。

Minecraft 范围是 `[26.1, 26.2)`，NeoForge 范围是很宽的 `[26,)`。

## 六个物品

| 物品 | 堆叠 | 说明 |
|:---|---:|:---|
| **花束** | 1 | 模组的招牌礼物 |
| **喷壶** | 1 | 可装水——记录水位 |
| **白色缎带** | 16 | |
| **淡灰色缎带** | 16 | |
| **灰色缎带** | 16 | |
| **粉色缎带** | 16 | |

缎带**只有四种颜色**——白、淡灰、灰、粉——而不是每种染料一种。

喷壶有两处不寻常：它以**物品组件**形式存储水位、初值为零；并且它由四张方块式贴图（顶/侧/底/壶嘴）绘制而非一张平面图，因此在手中呈现为一个小型三维物体。

## 互动界面

右键角色可打开**角色互动**界面。它提供：

| 按钮 | 作用 |
|:---|:---|
| 赠送礼物 | 打开赠礼界面 |
| 查看任务 | 打开任务详情 |
| 接受任务 / 交付任务 | 接下或提交任务 |
| 确认关系 | 亲密度那一步 |
| 邀请回家 | 请她搬进来 |
| 跟随模式：… | 循环切换她如何跟随你 |
| 关闭 | |

任务详情会显示**目标**列表，而接受是一个双按钮选择——**接受任务**或**再想想**——因此误点一下不会造成承诺。

## 第一次上手

1. 在一处宜人的地方 `/summon girlfriends:momo`。
2. 合成一束**花束**送给她——它是不止一名角色的最爱。
3. 留意她的好感提示；每次赠礼都会报告变化量。
4. 打开互动界面并设定**跟随模式**。
5. 等她足够信任你之后，看看**查看任务**与**邀请回家**。

在围绕它们做规划之前请注意两条限制：**赠礼有逐角色的每日上限**，以及**邀请回家要求你的重生点是一张双人床**。两者分别在 [03 好感与赠礼](03_affection_and_gifts) 与 [04 任务、家与日常](04_quests_home_and_daily_life) 中说明。
