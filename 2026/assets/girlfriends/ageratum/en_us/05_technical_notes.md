# Good to Know

## Three switches, all on by default

The whole config is three toggles, and everything works out of the box:

| Option | Controls |
|:---|:---|
| Relation binding | Whether relationships can be formed |
| Quests | The quest system |
| Home invitation | Inviting a character home |

::: tip
**If a server has disabled one of these, you get told in game rather than left guessing** — each toggle has its own refusal message.
:::

## The affection command needs gamemaster permission

`/affection` can read, set or add affection for a character. **It is restricted to game masters**, so on a server it is an operator tool, not something every player can use.

Pointing it at anything other than one of the five characters gets a clear refusal message.

## Characters follow daily schedules

Each character lives by a **daily timeline** — morning, day work, afternoon, sunset, night rest — driven by the overworld clock.

Combined with what they sense around them (flowers, beehives, shelter, hostile mobs), their behaviour depends on **the time of day and where they are**, not only on your commands.

::: tip
**If you cannot find a character, check the time.** She is probably in her scheduled activity rather than lost.
:::

## Voices are Chinese-only, but subtitles are not

The characters speak with recorded voice lines — **103 of them, recorded only in Chinese**. The system is built for more languages, but no other recordings exist.

Subtitles are separate from the audio and **fully translated into both English and Chinese**, so captions work correctly everywhere.

::: info
So an English player hears Chinese voice lines but reads correct English captions underneath. That is the intended behaviour, not a broken install.
:::

## Nothing else to install

::: tip
**The mod needs nothing beyond NeoForge and Minecraft** — that claim checks out. No animation library, no Curios, nothing optional.

Install it and it works.
:::

## A small mystery: four block-shaped textures with no blocks

The jar contains textures that look like blocks, but the mod registers **no blocks at all**. They belong to the watering can's three-dimensional item model — so if you spot "block" textures while browsing resources, that is what they are for.
