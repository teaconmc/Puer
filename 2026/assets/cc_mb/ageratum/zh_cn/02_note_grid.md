# 音符纸带

音符纸带是这个模组的介质。它最大堆叠为 1，因为每一条都是有各自内容的独立打孔纸卷。

## 三层嵌套上限

| 层级 | 上限 | 含义 |
|:---|--:|:---|
| 每拍音符数 | **25** | 音高 0–24，同时奏响构成和弦 |
| 每页拍数 | **64** | 一页永远正好 64 拍 |
| 每条纸带页数 | **64** | 一条纸带可有 1 到 64 页 |

因此一条满载纸带是 64 × 64 = **4096 拍**，每一拍最多可承载 25 个同时发声的音。

从「拍」的存储方式还能推出两点：

- **一拍是集合而非列表。** 打一个已经存在的音高不会有任何效果——你无法在同一拍里叠两个相同的音。
- **页长是固定的。** 新建的一页是 64 个空拍；不存在「短页」这种东西。结尾的静音是免费的，因为连续空拍以「游程长度」而非逐拍存储。

## 不用穿孔台也能读纸带

把鼠标悬停在音符纸带上，提示文本会显示 **`Page size: n`**，即它有多少页。这是在物品栏里区分一页碎纸与 64 页长卷最快的办法。

合成出来的纸带**永远是一页**。要得到更长的，要么从创造分页取预设空白，要么在穿孔台上把多条**粘接**起来。

## 音符实际存在哪里

打孔图样以数据组件 `cc_mb:notes` 的形式存放在物品上。它是持久化且网络同步并带缓存的，这意味着纸带在物品栏、箱子、漏斗、展示框与死亡掉落之间流转时都会保留其音乐，与任何组件数据一样。

内部编码刻意做得紧凑：每个音一个字节，换页是 0，连续空拍以单个负字节记录。因此一条非常稀疏的 64 页纸带占用远小于密集的那条。该格式对结尾标记很严格——畸形编码会被记录一条错误日志并**按空处理**，而不是部分加载。

## 音高与乐器是分开的

纸带**只存音高**。它不携带乐器、速度或八度信息，这三者存在别处：

| 属性 | 存放位置 |
|:---|:---|
| 音高图样 | **音符纸带**上（`cc_mb:notes`） |
| 乐器 | **八音盒正下方的方块** |
| 速度 | **八音盒**上（由锥子写入） |
| 八度偏移 | **八音盒**上 |

这种分离正是本模组主要的编曲杠杆：同一条纸带换个乐器、换个速度、或移一个八度，就是另一首曲子。**你永远不需要为了重新编排而重打一遍纸带。**

## 损坏与修补

纸带会损坏，而**纸浆**可在穿孔台的 `FIX` 模式下修补它。见 [03 穿孔台](03_perforation_table)。
