# 纸带八音盒（Music Box）

纸带八音盒是 c20c01 的 TeaCon 2026 参赛作品——与「撅电报」同一位作者——模组 ID `cc_mb`，组 ID `io.github.c20c01.cc_mb`，版本 `0.5.4`，采用 **GPL-3.0**，面向 Minecraft 26.1.2。

它是一台**纸带打孔音乐机**。你用锥子在纸质音符纸带上打孔，把纸带装进八音盒，通上红石就能演奏。围绕这个核心还有一张具备五种操作模式的穿孔台、一台由红石驱动的自动打孔机，以及一枚能**录下游戏中任何声音**并把它变成乐器的声响碎片。

## 它的过人之处

**这个模组里的一切都能合成，也都能挖回来。** 8 个已注册的物品与方块全部有配方，4 个方块全部有战利品表，两份语言文件覆盖完全一致。在这一批充满「注册了却拿不到」与孤儿翻译键的模组中，它一处都没有。

## 注册了什么

| 注册表 | 条目 |
|:---|:---|
| 方块 | `music_box_block`、`puncher_box_block`、`perforation_table_block`、`sound_box_block` |
| 方块实体 | 3 个 —— 穿孔台没有 |
| 物品 | `note_grid`、`awl`、`sound_shard`、`paper_paste` + 4 个方块物品 |
| 数据组件 | `notes`、`tick_per_beat`、`sound_info` |
| 菜单 | `perforation_table_menu` |
| 创造分页 | 1 个，标题直接复用八音盒自身的名称键 |
| 配方 | **8 个 —— 每个物品与方块各一** |
| 战利品表 | **4 个 —— 每个方块各一** |
| 进度 | 8 个，全部是配方解锁 |
| Mixin | 2 个（`MixinMob`、`MixinSoundEngine`） |
| 命令 / 配置 | **均无** |
