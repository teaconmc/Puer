# 本机正常

**本机正常**（Works On My Machine，简称 `womm`）是一个灵感来自经典“在我机器上运行得好好的”梗的小型开发工具。开发者可以把一个世界的配置打包成**世界模板**，随后用一条命令在另一台客户端上复现同一个世界——让同样的环境可靠地“在我机器上正常”（在你机器上也正常）。

本模组不添加任何物品、方块、实体或配方。唯一的入口是 `/womm` 命令，以及它所读取的 `world_templates` 数据包内容。

## 阅读路线

## 快速说明

| 项目 | 值 |
|:---|:---|
| 模组 ID / 命名空间 | `womm` |
| 命令 | `/womm <identity>` |
| 模板数据位置 | `data/<namespace>/world_templates/*.json` |
| 运行端 | 客户端 + 专用服务器（单人游戏内不可用） |
| 物品 / 方块 | 无 |
