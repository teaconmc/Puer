# Getting Started

## Before Opening the Tree

Your target must be another player, and both your main hand and offhand must be empty. The friendship tree uses an interaction-modifier plus the normal Use input. It does not replace ordinary empty-hand use unless the modifier is held.

The default keys are:

| Function | Default input |
|:---|:---|
| Interaction modifier | `Tab` |
| Use the targeted player | Right mouse button |
| Open expression menu | `]` |
| Toggle camera lock | `=` |

All keys can be rebound in Minecraft's Controls menu.

## Opening Your First Friendship Tree

1. Empty your main hand and offhand.
2. Face another player and stay within normal interaction range.
3. Hold `Tab`, then right-click that player.
4. Wait for the friendship screen to open and choose a node.

The screen is not forced open over another active screen. A successful empty-hand interaction is consumed by the mod so that it does not also perform the ordinary entity-use action.

## Requests and Confirmation

Friendship-tree actions fall into two groups:

- **Unlock requests** ask the other player to unlock a node together. When conditional friendship is enabled, progression order and item balance are validated.
- **Interaction requests** ask to perform the node's paired action immediately, such as a high five or hug.

After the requester chooses a node, the receiver sees an acceptance prompt. The unlock or action proceeds only after the receiver accepts. Cancellation, leaving the world, or the target leaving ends the current request.

## If the Screen Does Not Open

Check these conditions in order:

- Both hands are genuinely empty, including the offhand.
- `Tab` is not conflicting with another mod or has not been rebound.
- The crosshair is targeting a player rather than an armor stand or another entity.
- Chat, a container, or another screen is not already open.
- The client and server have compatible versions installed and have completed data synchronization.

::: tip
Have both players stand still at close range while testing `Tab + right-click`; this removes distance and movement from the diagnosis.
:::
