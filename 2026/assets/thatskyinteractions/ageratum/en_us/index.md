# That Sky Interactions

That Sky Interactions brings Sky-style expressions, friendship trees, and two-player actions to Minecraft. This documentation follows the current `2.1.0-rc2` source for `thatskyinteractions`.

## Reading Path

- [Getting Started](01_getting_started): open the friendship tree, send your first request, and resolve common problems.
- [Friendship Tree and Paired Actions](02_friendship_tree): understand built-in nodes, interaction levels, and handholding controls.
- [Expressions, Camera, and Calls](03_expressions_and_controls): solo expressions, the full key set, and player voices.
- [Unlock Costs and Data Layout](04_costs_and_data): conditional friendship, candle costs, and the default tree.
- [Server Administration and Data Packs](05_admin_and_datapacks): administration commands, configuration, and extensible data directories.

## Feature Overview

- Perform high fives, hugs, head pats, piggyback rides, and other paired actions after confirmation.
- Maintain a separate friendship-tree state for each pair of players.
- Use solo expressions including bow, nod, no thanks, point, and wave.
- Use an optional third-person camera controller and data-driven player call voices.
- Let servers adjust the experience through configuration, administration commands, and data packs.

::: warning
The Java registration code in the current 2.1.0-rc2 snapshot registers no items or blocks. Language and texture files still contain legacy cloud, candle cluster, and Wing of Light assets, but they are not obtainable content in this snapshot. This page therefore binds no item or recipe.
:::
