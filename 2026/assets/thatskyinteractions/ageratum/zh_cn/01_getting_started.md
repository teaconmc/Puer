# 开始互动

## 打开好友树前

目标必须是另一名玩家，且你的主手和副手都要为空。好友树使用“互动键 + 使用键”的组合，不会替代普通空手右键，除非互动键正被按住。

默认按键如下：

| 功能 | 默认输入 |
|:---|:---|
| 互动修饰键 | `Tab` |
| 对准玩家使用 | 鼠标右键 |
| 打开表情菜单 | `]` |
| 切换相机锁定 | `=` |

所有按键都能在 Minecraft 的按键设置中重新绑定。

## 第一次打开好友树

1. 清空主手和副手。
2. 面向另一名玩家并保持在可交互距离内。
3. 按住 `Tab`，再对该玩家点击鼠标右键。
4. 等待好友树界面打开，然后选择一个节点。

界面不会在已有其他屏幕打开时强行弹出。成功的空手互动会被模组接管，避免同时触发普通实体交互。

## 请求与确认

好友树操作分为两类：

- **解锁请求**：请求另一名玩家共同解锁某个节点。条件式好友树开启时，解锁顺序和物品余额会参与校验。
- **互动请求**：请求立即执行节点对应的双人动作，例如击掌或拥抱。

请求者选择节点后，接收者会看到接受界面。只有接收者接受，解锁或动作才会继续；取消、离开世界或目标离开会终止当前请求。

## 没有打开时

依次检查以下条件：

- 双手是否真的为空，包括副手。
- `Tab` 是否被其他模组占用，或者已经重新绑定。
- 准星是否对准玩家，而不是盔甲架或其他实体。
- 是否已有聊天栏、容器或其他界面打开。
- 服务端与客户端是否安装了兼容版本，并完成数据同步。

::: tip
先在近距离让两名玩家都静止，再测试 `Tab + 右键`，最容易排除距离和输入冲突。
:::
