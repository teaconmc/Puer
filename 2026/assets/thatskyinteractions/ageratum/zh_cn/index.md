# 那些互动

那些互动将《光·遇》风格的表情、好友树和双人动作带入 Minecraft。本套文档依据 `thatskyinteractions` 的 `2.1.0-rc2` 当前源码编写。

## 阅读路线

- [开始互动](01_getting_started)：第一次打开好友树、发送请求并排查常见问题。
- [好友树与双人动作](02_friendship_tree)：了解内置节点、互动等级和牵手控制。
- [表情、相机与呼唤](03_expressions_and_controls)：单人表情、完整按键和语音呼唤。
- [解锁成本与数据结构](04_costs_and_data)：条件式好友树、蜡烛成本与默认树形。
- [服务端管理与数据包](05_admin_and_datapacks)：管理命令、配置和可扩展数据目录。

## 功能概览

- 双方确认后执行击掌、拥抱、摸头、背背等双人动作。
- 为每一对玩家维护独立的好友树状态。
- 提供鞠躬、点头、拒绝、指向和挥手等单人表情。
- 提供可切换的第三人称相机控制与数据驱动的玩家呼唤声。
- 允许服务器通过配置、管理命令和数据包调整体验。

::: warning
当前 2.1.0-rc2 的 Java 注册代码没有注册物品或方块。语言文件和纹理中仍保留云、蜡烛簇、光翼等旧内容，但它们不是这个快照中可获取的游戏内容，因此本页没有绑定物品或配方。
:::
