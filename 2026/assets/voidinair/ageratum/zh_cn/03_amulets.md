# 护符

天猫行空加入了一套基于铁砧工艺护符系统的护符。每件都是扁平的物品，可放在物品栏或护符槽中。多件还能合成为更强的护符。

## 基础护符

| 物品 | ID | 效果 |
|:---|:---|:---|
| 虚空护符 | `void_amulet` | 免疫虚空伤害（`amulet_valid/void`）；落入虚空时获得缓降并传送到主世界顶部对应 xz 坐标。 |
| 雪花护符 | `snowflake_amulet` | 免疫冻结伤害；可在细雪上行走。 |
| 蜂巢护符 | `beehive_amulet` | 免疫蜜蜂/蜂巢居住者伤害；可安全采集蜜脾与蜂蜜；蜂类生物不再以你为目标或攻击你。 |
| 黄金护符 | `gold_amulet` | 在猪灵眼中你身穿黄金甲。 |
| 海豚护符 | `dolphin_amulet` | 给予海豚眷顾 III，并使守卫者更不易注意到你。 |
| 南瓜护符 | `pumpkin_amulet` | 在你头上戴上一个虚拟的雕刻南瓜。 |

每件基础护符都由银锭加主题材料在**珠宝合成**（铁砧工艺的珠宝合成台）中制作。例如：雪花护符需要银锭和三桶细雪；蜂巢护符需要蜜脾与蜜块；海豚护符需要海晶碎片与海晶砂粒；南瓜护符需要南瓜籽与雕刻南瓜。

虚空护符额外带有死亡保护组件（再生、吸收、抗火与缓降，以及从虚空救起的传送和不缩小效果），如同更强的"不死图腾"。

## 砧艺护符

`anvilcraft_amulet`（砧艺护符）把铁砧工艺的四件基础护符——**异常（Abnormal）**、**铁砧（Anvil）**、**宝石（Gem）** 与**自然（Nature）**——合一。它由这四件护符加一块超越块（Transcendium Block）与 `four_to_one_smithing_template` 在四合一锻造配方中制作。提示文本称其*"包含所有铁砧工艺的护符效果（战友护符除外）"*。

## 黑猫护符

`black_cat_amulet`（黑猫护符）是终极护符——它同时具备**全部**天猫行空护符效果（虚空、雪花、蜂巢、黄金、海豚、南瓜）加上**砧艺护符**（并可作为战友/黑猫护符）。它由六件天猫行空护符、砧艺护符与铁砧工艺的战友护符（Comrade Amulet），加超越块与 `eight_to_one_smithing_template` 在八合一锻造配方中制作。

它的特殊之处：手持并右键可**署名**，把自己的名字登记到护符上。一旦署名，由你造成的伤害会被同时佩戴同一黑猫护符的玩家忽略——这是一种队友保护效果。提示文本会把每位署名玩家按名字列出。
