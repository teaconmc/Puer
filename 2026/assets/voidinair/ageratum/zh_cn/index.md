# 铁砧工艺：天猫行空

铁砧工艺：天猫行空（AnvilCraft: Void in Air，命名空间 `voidinair`）是铁砧工艺（AnvilCraft）的一个附属模组，主题围绕虚空与黑猫。它加入了虚空涌泉（一种只产出虚空衰变产物的方块）、一整套护符、黑猫砧及其头颅、随机发信器红石方块，以及虚空图腾。所有物品都在 **铁砧工艺：天猫行空** 创造页（`voidinair:tab`，图标为黑猫砧）中。

## 一览

| 类别 | 物品 / 方块 | 说明 |
|:---|:---|:---|
| 铁砧类方块 | `black_cat` | 黑猫造型的可使用铁砧；从高处坠地可能吓出一只真黑猫 |
| 生产 | `void_fountain` | 像矿物涌泉一样生长虚空衰变的产物 |
| 红石 | `random_transmitter` | 在每个面随机发出红石脉冲 |
| 装饰 | `black_cat_head`、`black_cat_wall_head` | 可放置与墙上的黑猫头 |
| 非原版物品 | `totem_of_void` | 不死图腾升级版，用于落入虚空时保命 |
| 护符 | `void_amulet`、`snowflake_amulet`、`beehive_amulet`、`gold_amulet`、`dolphin_amulet`、`pumpkin_amulet`、`anvilcraft_amulet`、`black_cat_amulet` | 伤害/实体免疫、实用效果与复合护符 |
