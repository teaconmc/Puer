# 节点动作

每个节点都可以携带动作，女仆抵达时触发。用编辑器对节点点两次以打开它的界面，然后使用 **+ 添加动作**。

## 五种动作类型

| 动作 | 列表中的标签 | 作用 |
|:---|:---|:---|
| 消息 | `[M] …` | 发送一条聊天消息 |
| 标签 | `[L] …` | 在节点处显示一段文字标签 |
| 信标光束 | `[B] #RRGGBBAA` | 在节点处绘制一道彩色信标光束 |
| 图标 | `Icon[ … ]` | 在节点处显示一个物品图标 |
| 音效 | `[S] …` | 播放一个音效 |

每种类型都有自己的小编辑器，从同一界面进入。信标光束编辑器使用**带透明度的十六进制颜色**——列表显示原始值，因此 `#FF00FFFF` 是不透明的洋红色。

## 各自适合做什么

**消息**用于讲解。它以聊天形式送达玩家，前缀是女仆的名字，因此导览中的一个停靠点可以自己把话说清楚。

**标签**与**图标**是世界内的标示。它们停留在节点上而不是在聊天栏里滚走，因此更适合给一处地方命名、或展示那里生产什么。

**信标光束**用于远距离找到节点。光束能越过地形被看见，因此它适合当「下一站在这里」的路标，而不是细节说明。

**音效**播放任意音效事件。模组自带一个 `welcome` 音效，但该动作并不限于它。

## 管理一个节点的动作

节点界面为每个动作提供**编辑**与**删除**，另有针对节点本身的**删除节点**，会先要求确认。

请记住**起始节点无法被删除**——你可以清掉它的全部动作，但节点会留下。

## 动作与分支配合使用

这两项功能会以显而易见的方式组合起来，而且值得提前规划：在岔路节点上放一条**消息**来提问，并在它的每条出口上放**标签**或**信标光束**，让玩家在选择之前就能看到选项。

否则岔路的表现就只是女仆停下来、给出默认提问，而玩家看不出两条路各自通向何处。
