# 绘制路径

路径编辑器是一件工具，只有四种手势。所有操作都在服务端进行，并存储在物品自身上，因此路径随编辑器一起走。

## 四种手势

| 手势 | 效果 |
|:---|:---|
| 右键空处 | 新增一个节点，并从当前节点连过来 |
| 右键已有节点 | 选中它 |
| 右键**已选中的**那个节点 | 打开它的编辑界面 |
| **潜行** + 右键节点 | 切换「当前节点 → 该节点」的边 |

其中两条很容易被漏掉，值得明说：

**要编辑一个节点需要点它两次**——第一次选中，再一次打开界面。没有另外的编辑工具。

**边是切换而不是只能添加。** 对已经连通的节点潜行右键会**移除**那条边。聊天栏会告诉你发生了哪一种：*「已连接 A -> B」* 或 *「已移除 A -x-> B」*。

## 节点落在哪里

节点放置在**你点击的那一面上**，而不是方块内部。右键石块的顶面，节点就落在它上方的空气里——那正是你希望女仆站的位置。

在全新编辑器上的第一次右键会创建**起始节点**。该节点是特殊的：它无法被删除。

## 路径是一张分支图

这不是一串路径点的列表。一个节点可以有多条出边，而这正是设计意图——有两条出口的节点会成为一个**岔路**，女仆会停在那里问你想走哪边。

连接时会强制三条规则：

| 规则 | 提示 |
|:---|:---|
| 节点不能连到自己 | *「无法把节点连到它自己。」* |
| 目标必须已经是节点 | *「…… 不是路径中的节点。」* |
| **不允许成环** | *「此连接会形成环，已阻止。」* |

**环检查是真实且严格的。** 添加边之前模组会检查目标是否已经是当前节点的祖先，若是则拒绝。因此路径永远是一张有向无环图——你无法搭出让女仆永远走下去的循环。

这条约束正是导览有限的原因：每条路线最终都会走到一个没有出口的节点，导览随之结束。

## 选中跟随你的上一次操作

成功的潜行连接之后，选中会**移动到目标节点**。这让串联变得自然——把 A 连到 B，此时你已在 B 上，随即可以把 B 连到 C。

普通右键节点同样会选中它，因此你可以跳到图中任何位置去开一条新分支。

## 读懂编辑器

提示文本显示两项：

- **Current**——选中节点的坐标
- **Nodes**——路径共有多少个节点

手持编辑器时，节点会在世界中以标记形式绘制，当前选中的那个标注为 `<< CURRENT >>`。标记只在可配置的距离内渲染，默认 64 格——见 [06 配置](06_configuration)。

## 你可能撞到的失败提示

| 提示 | 含义 |
|:---|:---|
| *「这个编辑器上没有路径数据。」* | 你在创建任何节点之前就潜行点击了 |
| *「未选中节点。请先左键一个节点。」* | 尚未选中任何东西 |
| *「无法删除起始节点。」* | 第一个节点是永久的 |

形状调好之后，就在节点上挂动作——见 [03 节点动作](03_node_actions)。
