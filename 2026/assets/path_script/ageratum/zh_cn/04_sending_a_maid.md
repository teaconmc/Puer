# 派出女仆

## 派活

用带有路径的路径编辑器右键一名女仆。会施加两项检查：

- **她必须是你的。** 别人的女仆会拒绝，提示 *「这只女仆不属于你。」*
- **编辑器上必须有路径。** 空编辑器会拒绝，提示 *「这个编辑器上没有路径数据。」*

成功后她会切换到**路径导航**任务并从起始节点出发。确认提示为 *「…… 开始沿路径导航，起点为 ……」*。

## 路径导航改变了她的哪些行为

该任务大幅改写了她的行为。其中有四项在你依赖她之前值得知道：

| 行为 | 导航期间 |
|:---|:---|
| 张望与游走 | **禁用**——她专注于任务 |
| 惊慌 | **禁用**——受伤时她不会逃跑 |
| 坐在娱乐方块上 | **禁用** |
| 被实体推动 | **禁用**——她无法被挤离路径 |
| 推动其他实体 | **禁用**——她也不会挤你 |

**惊慌被关掉这一条最需要提前规划。** 导览途中被攻击的导游女仆不会跑开，她会继续走自己的路线。这对导览而言正是你想要的，对危险区域而言则不是——请让路线绕开敌对生物，而不要指望她自己反应。

她同时不再推动也不被推动，这正是导游不会被人群挤进坑里的原因——但也意味着她无法被物理地挤出门口。

## 她会等你

这是导游体验的核心，由一小组行为共同实现：

- **你落后时她会等**，而不是一个人走下去。
- **等待时她会看着你**，读起来就像她回头找你。
- **你离得太远时她会传送到你附近**——传送到最合适的附近节点，而不是你脚下。该节点如何挑选完全可配置，见 [06 配置](06_configuration)。

传送是一种恢复机制，好让导览能扛住你中途停下挖点东西。它有上限，而这个上限的形态出人意料——在假定她总能找到你之前，请先读配置页。

## 岔路

在有多条出口的节点上她会停下来询问。默认提问是 *「那么我们走哪边呢？」*，由玩家选择路线。

这正是路径必须是严格无环图的原因：每次选择都向前推进，因此导览不可能折回成环。见 [02 绘制路径](02_drawing_a_path)。

## 导览的终点

当她走到一个没有出口的节点时，她会停在那里等待。终点状态标注为 *「导览结束」*。

此时她仍处于路径导航任务——她不会自动回到之前在做的事，因此导览结束后请你自己把她切回去。

## 离开路径

有一个专门的行为用于退出路径模式，因此女仆可以被撤出导览、回到常规工作。若在她行走途中路径数据被清空——传送逻辑有可能做这件事，见 [06 配置](06_configuration)——她也会离开路径模式。
