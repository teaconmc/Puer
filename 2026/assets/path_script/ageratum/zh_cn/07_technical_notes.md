# 须知

## ⚠️ 导路女仆防玩家，不防世界

::: danger
**导路女仆不会被其他玩家伤害，但她会站在原地被苦力怕炸死。**

保护只取消玩家的攻击与交互。它明确**不会**取消生物伤害与环境伤害。

所以如果导路女仆的路线经过危险地带，**她既不会自卫也不会逃跑**——要么让路线远离怪物，要么接受失去她的可能。
:::

## 导路女仆按设计就是一次性的

从引导牌创建的女仆被刻意完全排除在你的女仆备份体系之外。

::: warning
**她永远无法从备份恢复。** 她死了就是没了。

这是有意为之——避免用完即弃的导路女仆污染你真正的女仆备份。但这意味着你应该把每一个导路女仆都当作临时的，除非你接受风险，否则不要让你真正重要的女仆去当向导。
:::

## 你的普通女仆不受任何影响

本模组改变的一切都以「女仆正在执行导路任务」为前提。

::: tip
安装它不会改变你任何普通女仆的行为——没有推动变化、没有备份差异、什么都没有——直到某位女仆被实际指派去导路为止。
:::

## 路径能在存储中保留

画好的路径存在路径编辑器物品本身上，因此**把编辑器放进箱子里路径依然完好**。

## 两处小的显示瑕疵

- 三条界面消息（开始前等待、下一步、结束）用了缩短的内部名称，另一个模组理论上可能与它们撞名。
- 欢迎音效的字幕显示为字面词「welcome」而不是翻译文本。

两者都不影响系统工作。

## 它需要车万女仆

这是一个附属模组：**车万女仆是必需的**，且依赖声明规范——缺失时你会看到清晰的依赖提示而不是崩溃。

## 这个模组做对了的地方

值得直说：编辑器**拒绝构建会成环的路径**，而不是造出一个环然后祈祷寻路能活下来；两种语言完整且对等；附属关系声明得干干净净。
