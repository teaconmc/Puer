# 女仆的路径剧本

女仆的路径剧本把 **Touhou Little Maid（东方女仆）** 的女仆变成导游。你在世界里逐个节点画出一条路径，在节点上挂上动作——消息、标签、信标光束、图标、音效——然后派一名女仆走这条路，你跟着走。

这条路径不是简单的直线，而是一张**分支图**：一个节点可以通向多处，女仆会停下来问你想走哪边。

## 两种执行路径的方式

**让你自己的女仆去走。** 用路径编辑器右键你拥有的女仆，她就会开始走。她仍然是你的女仆，只是在做一份工作。

**做一块导游牌。** 把路径转移到牌子上，右键即可召唤一名**一次性导游女仆**，她只为这趟导览而存在。再右键一次她就消失了。
