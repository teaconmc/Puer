# 电脑

## 打开菜单

右键电脑会打开菜单。它有一个只能放入音乐唱片的输入槽和一个只能取出的输出槽，以及歌曲 URL、歌名和时长（秒）三个输入框。

## 自定义歌曲

把音乐唱片放入输入槽，输入 `http` 或 `https` URL、显示歌名和时长，然后点击 `制作唱片`。客户端发送 `netmusic:set_music_id` 到服务端，服务端把自定义歌曲写入唱片并移动到输出槽。

模组自带提示把支持的音频限定为 MP3 与 FLAC。直接 HTTP 流、网易云 URL、m3u8 流与央广电台 URL 各有专用客户端音频处理器。

## 本地文件

URL 输入框也接受 Windows 风格本地路径，例如 `C:\music\song.mp3`。客户端会检查文件是否存在，转换为 `file:` URL 后写入唱片。

本地文件播放是客户端侧的：唱片保存的是创建它的客户端路径，因此只有该客户端能听到音乐；除非同一路径在另一台机器上也存在相同文件。

## 只读

制作前勾选只读，可以给生成的唱片标记 `read_only`。只读唱片无法被唱片刻录机或电脑覆盖写入。
