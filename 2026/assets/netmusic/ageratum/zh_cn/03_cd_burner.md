# 唱片刻录机

## 打开菜单

右键唱片刻录机会打开菜单。它有一个只能放入音乐唱片的输入槽，以及一个只能取出的输出槽。关闭菜单时，仍在任一槽位的唱片会放回你的物品栏。

## 输入与输出

把音乐唱片放入输入槽，在文本框中输入网易云音乐标识，可选勾选只读，然后点击 `制作唱片`：

- 纯数字歌曲 ID（例如 `123456`）。
- `dj/123456` 形式的播客 ID。
- 网易云歌曲链接，例如 `https://music.163.com/song?id=123456`。
- 网易云播客链接，例如 `https://music.163.com/dj?id=123456`。

客户端从网易云 API 获取歌曲信息，并发送 `netmusic:set_music_id` 到服务端。服务端把取得的歌曲数据写入唱片，再移动到输出槽。

## 限制

唱片刻录机面向网易云音乐链接，需要能访问 `music.163.com`；模组自带提示注明仅在中国大陆可用。如果输入唱片已经只读，刻录会被拒绝。

刻录出的唱片仍可能携带 VIP 歌曲，但未安装歌曲 URL 解析器时，唱片机会拒绝播放 VIP 歌曲。
