# 让我看看（你的代码）

**让我看看**（命名空间 `let_me_see_see`，版本 `1.3.10`，LGPLv3.0，作者 xkball）是一个**开发者工具**，不是玩法模组。它不添加方块、不添加配方、不添加世界内容——它给你三件游戏内仪器来读**别人模组**的代码：对着方块一点就找出背后的类、浏览并反编译已加载的类、导出物品图标与元数据。

如果你想找点东西来玩，这个不是。如果你在写附属、调整合包，或者在准备百科词条，这是一台工作台。

## 它实际上是什么

三件物品，全部 `stacksTo(1)`：

| 物品 ID | 显示名 | 作用 |
|:---|:---|:---|
| `let_me_see_see:scanner` | Scanner | 右键方块或生物实体，收集涉及的类 |
| `let_me_see_see:explorer` | Class Explorer | 打开类浏览 / 搜索 / 导出界面 |
| `let_me_see_see:item_data_exporter` | Item Data Exporter | 把物品图标渲染成 PNG 并导出元数据 |

其余一切——反编译视图、已导出类数据库、语法高亮——都活在这些界面里。

## 开始之前要知道的两件事

**没有任何配方。** 模组**完全没有 `data/` 目录**，因此三件物品都无法合成。请从创造分页 `let_me_see_see:tab` 取用，或使用 `/give`。

**三件工具中有两件需要运行时类检查，一件不需要。** 当它不可用时，类浏览器会显示专门的「Class Explorer Unavailable」界面，物品数据导出器则照常工作。但扫描仪**会静默失效**——它是唯一一种游戏内完全没有任何信号的情况。参见 [02 扫描仪](02_scanner) 与 [06 排障](06_technical_notes)。
