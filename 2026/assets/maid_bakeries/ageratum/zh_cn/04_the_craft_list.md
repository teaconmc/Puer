# 制作清单

制作清单是编辑器。手持它右键即可打开，然后描述你想让人干的活。它有**六个槽位**。

## 四种模式

每个条目都指定一种制作模式，它同时决定女仆走向哪台机器、以及她被允许使用哪本配方书：

| 模式 | 配方来源 |
|:---|:---|
| 搅拌机 | 烘焙坊搅拌机配方 |
| 烤炉 | 烘焙坊烤炉配方 |
| 面胚制作台 | 烘焙坊面胚制作台配方 |
| 工作台无序合成 | 原版**无序**合成配方 |

请注意最后一项**只限无序配方**。处于「工作台无序合成」的女仆无法遵循有序配方，因此任何需要特定网格摆法的东西都做不到。

## 操作方式不太寻常

三个控件中有两个使用**鼠标中键滚轮**，在你到处找按钮之前值得先知道：

| 控件 | 使用方式 |
|:---|:---|
| 制作模式 | **滚动鼠标中键** |
| 物品需求数量 | **滚动鼠标中键** |
| 物品 ID | 在文本框中输入 |

文本框接受的是**物品 ID** 而非显示名——所以要写 `minecraft:bread` 而不是「面包」。框内提示也是这么说的。这意味着你需要知道目标物品的 ID，对烘焙坊的物品来说就是 `bakeries:` 命名空间下的那些。

需求数量表示你要多少个该物品；它会成为女仆努力达成的目标数量。

## 校验发生在之后

编辑器会允许你写下一个实际做不出来的条目。「该结果是否真能由所选模式产出」这项检查发生在你**把订单交给女仆**时，而不是在你输入时——因此选错模式或打错 ID 在这里看起来完全正常，之后才被静默丢弃。

若女仆接受了订单却跳过了部分工作，被跳过的正是没通过那项检查的条目。详见 [03 下达订单](03_giving_an_order)。

## 六个槽位，五个步骤

清单有六个槽位，但女仆的队列**上限是五个步骤**。因此写满六条的清单在交接时会丢掉最后一条，且没有任何警告。

请把五当作实际可用上限。

## 清空

清空清单会重置全部六个槽位并擦掉已存文本，让你得到一张空白纸而不必重新合成一个。制作清单是可复用的工具，不是消耗品。
