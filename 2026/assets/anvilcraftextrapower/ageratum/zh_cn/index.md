# 铁砧工艺：额外电力

铁砧工艺：额外电力（命名空间 `anvilcraftextrapower`）是铁砧工艺（AnvilCraft）的附属模组，在其物品与电力系统之上新增发电、储能、磁力与燃烧材料。所有内容注册在 `anvilcraftextrapower` 创造页中，页签图标为铁砧工艺的电容器。

## 阅读路线

- [01 快速上手](01_getting_started.md) — 创造页、新材料（镁、硫磺、煤粉、酸类）与电池类物品。
- [02 电力与核能](02_power_and_nuclear.md) — 太阳能板、核能收集器、铀棒、电容器与核弹。
- [03 磁力](03_magnetism.md) — 电磁铁、磁力展示台与羊驼砧。
- [04 燃烧方块与装饰](04_burning_and_decor.md) — 燃烧煤/镁块、灰烬与氧化镁，以及标识牌/展示装饰方块。

## 一览

| 领域 | 物品与方块 | 说明 |
|:---|:---|:---|
| 材料 | `magnesium_ingot`、`magnesium_nugget`、`magnesium_block`、`sulfur`、`sulfur_block`、`coal_powder`、`ashes`、`magnesium_oxide` | 新材料（带 `ingots/magnesium`、`nuggets/magnesium`、`sulfur`、`dust/coal`、`storage_blocks/magnesium`、`storage_blocks/sulfur` 标签） |
| 储能 | `lead_acid_battery`、`lead_acid_battery_empty`、`multiphase_capacitor`、`multiphase_capacitor_empty`、`potato_battery`、`flashing_potato_battery` | 均挂 `capacitor` 标签 |
| 发电 | `solar_panel`、`nuclear_collector`、`uranium_rod`、`burning_coal_block`、`burning_magnesium_block` | 热源与一个铁砧工艺电力生产者 |
| 磁力 | `electromagnet`、`magnetic_display_stand`、`llama_anvil` | 电磁铁挂 `MAGNET` 标签；羊驼砧为 `NON_MAGNETIC` 且属于 `anvil` |
| 武器/风险 | `nuclear_bomb`、`mushroom_cloud`、`frost_controller`、`pedometer`、`anvil_projector` | 核爆伤害类型 `anvilcraftextrapower:nuclear_explosion` |
| 装饰 | `light`、`earth`、`display_mushroomcloud`、十种 `sign_*` | 创造/演出方块与警示告示牌 |

唯一的创造页为**铁砧工艺：额外电力**（`anvilcraftextrapower:anvilcraftextrapower_tab`），图标为铁砧工艺电容器。
