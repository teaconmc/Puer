# TerrariaBoulders（泰拉巨石）

TerrariaBoulders（模组 ID `terraria_boulders`，版本 1.0）——泰拉瑞亚风格的巨石模组。由 XiaoJin 与 Txt Text 开发（MIT 许可），项目位于 `org.confluence.terraria_boulders`，目标环境为 Minecraft 26.1.2 / NeoForge（`26.1.2.73`），并可选集成 Jade 与 JEI。

## 模组内容

- **巨石类型** —— 一批滚动巨石方块/实体：经典 `boulder`、`oak_log_boulder`、`follower_boulder`、`explode_boulder`、`rolling_cactus_boulder`、`bouncy_boulder`、`ghoulder`、`lava_boulder`、`spider_boulder`、`rainbow_boulder`、`snow_boulder`、`camouflaged_boulder` 与 `giant_boulder`。
- **巨石大炮** —— `boulder_cannon` 方块带乘坐座位（`CannonSeatEntity`），用泰拉风格 `TerraStyleExplosion` 发射巨石。
- **工具与物品** —— `boulder_glove`（搬运/投掷巨石，堆叠上限 1）、可用 `is_locked` 数据组件锁定/解锁的 `camouflaged_boulder`，以及既是食物也是方块的 `boulder_bread`。
- **效果与音效** —— 自定义状态效果（如吃 `boulder_bread` 带来的 `choking` 窒息）与自定义音效/爆炸。
