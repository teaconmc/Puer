# 便携电台

`cc_ms:portable_radio` 是手持端点。它最大堆叠为 1，全部数据都存在物品组件上，因此每台电台各自保有自己的频道列表与设置。

## 收集频道

一台电台最多持有 **16 个频率**。添加方式有两种：

- **对磁石方块使用电台。** 目标必须真的是磁石，对其他方块使用不会有任何反应。成功时会播放磁石指针锁定音效。
- **在物品栏界面中用磁石指针右键电台。** 拿起一枚已锁定到磁石的指针，对电台执行副键点击即可。指针不会被消耗。

若该频率**已在列表中**，电台不会添加重复项，而是转为**选中**该条目——这是切换频道的便捷捷径。若列表已满 16 项，你会看到「电台无法容纳更多位置」的动作栏提示与一声村民「拒绝」音效，且不会添加任何东西。

## 电台界面

手持电台使用即可打开界面。共有四个控件：

| 模式 | 用途 |
|:---|:---|
| **频道选择模式** | 列出已持有频率；点击其一加入，点击已加入的那个则退出 |
| **频道删除模式** | 列出已持有频率；点击其一将其从电台中删除 |
| **声音设置模式** | 列出**服务器**提供的电报声音；点击选择你发送时使用的声音 |
| **切换广播状态** | 开关发送功能——**默认关闭** |

有两条限制：

- **同一时刻只能加入一个频道。** 加入新频道会退出旧频道。
- **不能同时打开两台电台。** 尝试时会显示「无法同时打开多个电台」。

## 物品栏里只有一台电台能保持加入

服务端会 tick 你物品栏中每一台已选中频率的便携电台，但只有**第一台**成为你的活动会话。其余每一台已加入的电台，其选中频率都会被**静默清除**。

这件事**没有任何提示信息**。如果你随身带着一台曾调好频率的备用电台，请预期下次查看时它已经退出了频道。建议只保持一台加入，其余不要选中频率。

## 发送：潜行

**没有任何发送用的按键绑定**。发送直接绑定到你的潜行状态，并在服务端判定：

- **按住潜行** → 你的电台把配置好的信号代码发送到已加入的频道。
- **松开潜行** → 你的电台发送空信号，把你的信号从频道上移除。

只要电台在物品栏中的任何位置即可生效，**不需要手持**。前提是先打开广播状态。

由于模组只在数值真正变化时才重发，按住潜行只会发送一次，而不是每刻向频道刷屏。

## 你会听到自己

便携电台会话在频道上**同时注册为接收器与发射器**。因此你自己的发送会回到你身上，以你自身位置为中心播放、无方向偏移。这是确认「广播已开、且确实在你以为的那个频道上」的有用反馈。

## 组件里存了什么

| 组件 | 内容 |
|:---|:---|
| `cc_ms:frequencies` | 已持有的频率列表，最多 16 个 |
| `cc_ms:selected_frequency` | 当前已加入的频率（若有） |
| `cc_ms:signal_code` | 你发送的信号代码——即你选择的声音 |
| `cc_ms:sound_code` | 声音选择状态 |

四者都持久化且网络同步，因此电台被丢出、存进箱子或交给其他玩家时都会保留其频道列表。
