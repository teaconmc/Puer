# 入门

## 没有配方

源码资源与生成资源中都不存在 `recipe` 目录。本模组里没有任何东西是通过合成、烧炼、酿造或工作台制作出来的。

一切只经由三条途径抵达你手上：

| 途径 | 给你什么 |
|:---|:---|
| **刷取可疑方块** | 「奇异」遗骸 —— 真正的玩法循环 |
| **鉴定手册** | 由战利品表掷出的已鉴定遗骸 |
| **创造分页** | 一切，直接给 |

## 创造菜单里的位置

模组注册了自己的分页 `living_unvanished`，其中列出**全部**已注册物品——它由物品注册表生成而非手工罗列，因此不可能遗漏任何东西。

它还向**五个原版分页**注入了物品，若你不用模组自有分页，就靠这些找东西：

| 原版分页 | 内容 |
|:---|:---|
| **自然方块** | 蓝鸠蛋、可疑泥土、可疑红沙、可疑腐木 |
| **功能方块** | 修复台 |
| **工具与实用物品** | 泥浆桶、鉴定手册、回忆录 |
| **原材料** | 蓝鸠蛋、全部 13 件遗骸、全部 6 页残页 |
| **刷怪蛋** | 毛里求斯蓝鸠刷怪蛋 |

请注意蓝鸠蛋**同时**出现在自然方块与原材料两个分页中。

## 遗骸：未鉴定与已鉴定

十三件物品构成挖掘链。其中四件是未鉴定的发现，其余是它们可以变成的东西：

| 未鉴定 | 可鉴定为 |
|:---|:---|
| **奇异头骨** | 鸟类头骨、兽类头骨 |
| **奇异羽毛** | 蓝色正羽、橙色正羽 |
| **奇异骨骼** | 龙骨突、肋骨、股骨 |
| **奇异皮革** | 条纹皮革 |

命名本身就在讲故事：鸟类对兽类、蓝对橙的羽色、**龙骨突**（鸟类胸骨的隆脊）对**股骨**与**肋骨**，以及属于袋狼的**条纹**皮革。判断某件发现归属哪个物种，正是这里的谜题。

鉴定见 [03 鉴定](03_identification)。

## 修复台没有功能

`restoration_table` 注册为木质方块，强度 2.5，可被岩浆点燃。它的类体内**除构造器外什么都没有**——无方块实体、无使用处理、无菜单、无 ticker。

结合「不存在任何配方」以及「唯一注册的菜单属于**鉴定手册这件物品**」两点，结论无可回避：**修复台目前没有任何功能。** 它能放置、看起来像个工作站，但与它交互不会发生任何事。

它**也没有战利品表**，因此破坏一个就等于销毁它。

目前请把它当作工坊场景的陈设。

## 如何获得这两种动物

- **毛里求斯蓝鸠** —— 有刷怪蛋，并会产下可孵化的蛋方块。见 [05 两个物种](05_the_two_species)。
- **袋狼** —— **没有刷怪蛋**。它作为实体已完整实现（属性、模型、动画、AI，还有一层护甲渲染层），但随包构建没有给你任何可以放置它的物品。实际操作上这意味着只能 `/summon`。

两种实体都以 **`noLootTable()`** 注册，因此**击杀任何一方都不会掉落任何东西**。这是刻意且切题的设计：**你无法把一种已灭绝的动物当作零件来源。**

## 第一次体验

1. 找到可疑泥土、可疑红沙或可疑腐木 —— 见 [02 挖掘](02_excavation)。
2. 用原版刷子刷它，收取奇异遗骸。
3. 手持**鉴定手册**使用以打开界面，放入一件奇异物品，按下鉴定。
4. 挖掘途中收集残页，并读它们。
