# Sip Moment（微醺一刻）

Sip Moment 是 renyigesai 的 TeaCon 2026 参赛作品，模组 ID `sip_moment`，组 ID `com.renyigesai.sip_moment`，版本 `1.0.0`，面向 Minecraft 26.1.2 / NeoForge 26.1.2.75。

它是一个**酒吧模组**：十种需要「小口喝」而非一饮而尽的饮品、可以摆放并堆叠的玻璃器皿、一张打开绿宝石定价酒单的吧台，以及一把真能坐下去的吧椅。围绕这个核心还有两层流行文化：**《赛博朋克：边缘行者》**一脉（大卫·马丁内斯特调、黑星咖啡、边缘行者与狂怒效果、《Dust To Dust》唱片）与**《EVA》**一脉（朗基努斯之枪，以及一句「融化成 LCL」的死亡信息）。

## 许可 —— 打包前请先读这条

模组声明的是**双许可：`BSD-3-Clause + CC BY-NC-SA 4.0`**。其中 CC 那一半是**非商业（NonCommercial）+ 相同方式共享（ShareAlike）**，比本批多数模组严格。如果你要做任何形式的商业化整合包，这个模组的素材是首先需要确认的。
