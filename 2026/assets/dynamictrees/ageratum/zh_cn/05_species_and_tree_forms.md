# 树种与树形

基础模组在 `trees/dynamictrees/species/` 下自带一批树种。每个树种绑定一个家族（木头/树叶配色）、生长逻辑套件、土壤类型、种子物品与可选的特殊特性。

## 主世界树种

| 树种 | 说明 |
|:---|:---|
| `oak` | 温带全能树种；法杖默认树种。橡树可生成落叶、蜂巢、蘑菇与腐烂特性。 |
| `birch` / `tall_birch` | 纤细白桦，以及生成于高大白桦森林的高大形态。 |
| `spruce` | 寒冷气候针叶树，树冠呈锥形；拥有巨型变种 `mega_spruce`。 |
| `jungle` | 宽大树冠的热带树，带藤蔓与下层植被；拥有巨型变种 `mega_jungle`，并通过可可树种生成可可豆。 |
| `dark_oak` | 粗壮低枝的森林树，使用深色橡树干逻辑；树干可达半径 24，带壳层方块。 |
| `pale_oak` | 苍白花园的树；可生成吱吱怪之心特性。`hideCreakingHeart`（默认 `true`）开启时，树心会伪装成普通树枝，直到被剥皮才发现。 |
| `cherry` | 粉色树冠的樱花树。 |
| `acacia` | 金合欢草原树，呈平顶金合欢形态。 |
| `mangrove` | 带气生根的红树；接受泥土、泥巴与水，可以种在流体上。 |
| `swamp_oak` | 耐水的橡树，生长于沼泽与浅水中，根部下垂。 |
| `azalea` | 一种根系系统，随洞穴生态园的洞穴根源世界生成生长；原生杜鹃与开花杜鹃树苗在放置时不会被替换。 |
| `oak_undergrowth` / `jungle_undergrowth` | 森林与丛林中的低矮下层植被形态。 |

## 果实与豆荚树种

- `apple_oak` — 橡树形态的苹果树；其果实方块掉落苹果，苹果本身也是种子转化配方中的材料（见[果实与豆荚](06_fruits_and_pods)）。
- `cocoa` — 与丛林关联的树种，豆荚长在丛林树干上。它配置为 `drop_seeds: false`，因此繁殖依赖收获豆荚，而不是树冠掉种子。

## 下界树种

- `crimson` 与 `warped` 是动态菌类树种，只能长在对应的菌岩或其根系菌岩上，且不会在主世界生成。两者都有巨型变种（`mega_crimson`、`mega_warped`）。

## 巨型树种

`mega_spruce`、`mega_jungle`、`mega_crimson` 与 `mega_warped` 是树干极其粗壮的独立树种，通过巨型种子或巨型药剂获得——见[巨型树与下界菌类](07_mega_trees_and_nether_fungi)。

::: note
并非每个树种都会在不同配置下生成种子物品：种子生成是逐树种的开关（`should_generate_seed`）。生成资源中确认存在的种子物品已列在[首页](index)。
:::
