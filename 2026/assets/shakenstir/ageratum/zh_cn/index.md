# Shake n Stir（调酒）

为 Minecraft 26.1.2 的 NeoForge 模组，让你经营自己的酒吧。寻找烈酒与植物配料，用摇合、搅拌与蒸馏三种方式调制专属鸡尾酒，倒入玻璃杯交给游戏内**调酒师**（Bartender）上桌——再处理一下喝过头带来的各种效果。

## 阅读路线

- [快速开始](01_getting_started) — 搭建酒吧、雇佣调酒师、收集烈酒与配料，调出第一杯酒。

## 快速说明

| 类别 | 内容 |
|:---|:---|
| 模组 ID | `shakenstir` |
| 实体 | `bartender`（调酒师 NPC） |
| 制作方式 | `shake_recipe` 摇合 · `stir_recipe` 搅拌 · `distiller_recipe` 蒸馏 · `spirit_bottle_special_recipe` |
| 烈酒 | gin 金酒 · whisky 威士忌 · vodka 伏特加 · rum 朗姆 · tequila 龙舌兰 · brandy 白兰地（`bottle` 为空瓶） |
| 调和物 | `bubbles` 气泡水 · `tonic` 汤力水 · `bitters` 苦精 · 糖浆 · 蜂蜜 · 果汁 · 柠檬汁 |
| 玻璃杯 | `long_drink_glassware` 长饮杯 · `short_drink_glassware` 短饮杯 |
| 酒吧方块 | `bar_counter` 吧台 · `bar_menu` 菜单 · `cabinet` 酒柜 · `distiller` 蒸馏器 · `recipe_scroll` 配方卷轴 · `shaker` 摇酒壶 |
| 效果 | drunk 醉酒 · fall_down · lemon · paralysis · misdirection · miss_step · dodge |
| 配置 | `shakenstir-common.toml`（`debug_mode`）· `shakenstir-server.toml`（`enable_wrong_fluid_in_bottle`、`shaker_animation_upload_distance`） |

适量饮酒：喝太多鸡尾酒会施加`drunk`醉酒等效果，身边常备`sobering_tea`解酒茶。按 **F** 键打开游戏内菜单。
