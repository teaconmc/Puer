# 手机发电机

**手机发电机**（模组 ID `phone_generator`，版本 `1.0.0`，MIT）把真实手机变成电源。放下发电机，它会**在自己的面上渲染一个二维码**；用手机扫码，你在手机上的操作就变成世界里的 Forge Energy。

它提供**两个方块、一个实体、零配方**，并且**依赖一个外部网络服务才能工作**。

## 阅读路线

## 首先要读的

::: warning
**这个模组离线无法工作。** 发电机会请求一个网络服务创建「房间」，把返回的加入链接渲染成二维码，然后与该服务保持一条 Socket.IO 连接。若没有可达的服务器，方块面上会依次显示 *连接中… → 服务器无法访问 → 重新连接中…*，且**完全不发电**。

默认服务器是 **`http://phone-generator.karlcx.cn:10841`** —— 一个写在配置里的第三方地址，走**明文 HTTP**。在你在意的服务器上部署前请先读[网络、隐私与自建服务](03_network_privacy_and_hosting)。
:::

::: info
**两个方块都没有配方。** 模组里根本不存在 `recipe/` 目录，因此发电机与小风扇只能创造模式或 `/give` 获得。但两者都有战利品表，破坏时掉落自身。
:::

## 完整链路

1. **放置发电机。** 它联系 API 服务器创建房间。
2. **方块面显示二维码**，编码一个加入链接——该链接携带你的玩家名与 UUID。
3. **用手机扫码**并在手机端交互。
4. **你的活动变成一个「等级」**，由服务器推回游戏。
5. **等级映射为电量**：默认等级 1–4 分别是 `100 / 500 / 2000 / 5000` FE。
6. **电量推送给相邻方块**，默认每刻最多 100 FE。
7. **也可以接给小风扇** —— 它会转速攀升并发射一枚你能乘上的扇叶。见[发电与风扇](02_power_and_fan)。
