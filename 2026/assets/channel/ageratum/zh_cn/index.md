# 沉浸语音

Channel 是一个客户端与服务端共同安装的游戏内语音模组。它提供 Opus 语音传输、固定或 AI 降噪、按玩家音量、路径追踪空间声学，以及可以跨远距离和维度转播的麦克风/音响频道。

## 阅读路线

1. [语音设置](01_voice_setup)：选择输入设备，理解采样率、监听和首次连接状态。
2. [传输与触发](02_transmit_and_triggers)：配置常开、VAD、响度阈值、按住说话或切换静音。
3. [降噪与前处理](03_noise_processing)：使用固定降噪、高通、回声消除和增益控制。
4. [输出与空间音频](04_output_and_spatial_audio)：调整玩家音量、网络缓冲、路径追踪和自我监听。
5. [频道与设备](05_channels_and_devices)：使用手持话筒、固定式麦克风和三种音响建立频道。
6. [命令与权限](06_commands_and_permissions)：管理全服发话限制、重置 Subspace，并理解当前校验边界。
7. [Subspace 中继](07_subspace)：把语音数据转交给独立中继进程，并选择安全等级。
8. [平台与故障排查](08_platforms_and_troubleshooting)：检查原生库、NVIDIA AI 条件和常见无声问题。

## 快速说明

| 项目 | 当前实现 |
|:---|:---|
| 默认配置按键 | `Alt+C` |
| 默认讲话按键 | `Y`，仅用于按住或切换模式 |
| 普通空间语音距离 | 小于 `64` 格 |
| 固定麦克风收音距离 | 不超过 `2` 格 |
| 音响可听距离 | 不超过 `64` 格 |
| 固定注册物品 | 五个 |
| 生存配方 | 无 |
| 可用中继协议 | 当前仅 TCP |

::: warning
Channel 处理真实麦克风音频。加入服务器前先确认输入设备和触发模式，不要把“常开”或过低的响度阈值用于不希望持续传输声音的环境。
:::
