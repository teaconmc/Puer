# 玩偶（Doll）

「玩偶」是 MaxPixelStudios（XiaoPangxie732）的 TeaCon 2026 参赛作品，模组 ID `mpsdoll`，组 ID `cn.maxpixel.mods`，版本 `0.1`，采用 **MIT** 许可，面向 Minecraft 26.1.2。其声明的描述只有一句「A doll.」（一个玩偶）。

**当前模组没有注册任何内容。** 检出的源码是一份未经改动的 NeoForge MDK 模板，其全部注册接线都被注释掉了。安装它只会在模组列表里多出一个条目，除此之外别无他物：没有物品、没有方块、没有创造分页、没有配置文件、没有命令、没有贴图，也没有玩法。

因此本指南记录项目的真实状态，而不为其编造行为。如果你在寻找可玩内容——目前还没有。
