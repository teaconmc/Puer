# 地质层

**地质层**是 Craton 地下结构的原子单位。它是一个由数据包注册的对象，含五个数值加一个方块。

## 层的字段

| 字段 | JSON 键 | 默认值 | 含义 |
|:---|:---|:---|:---|
| 方块状态 | `block` | （必填） | 该层由什么方块构成。 |
| 厚度 | `thickness` | 24.0 | 该层有多厚。 |
| 振幅 | `amplitude` | 12.0 | 层边界上下起伏的幅度。 |
| X 频率 | `freq_x` | 0.01 | 沿 X 方向的噪声频率。 |
| Z 频率 | `freq_z` | 0.01 | 沿 Z 方向的噪声频率。 |
| 种子 | `seed` | 0 | 该层专属的噪声偏移。 |

由于每层携带**自己的**种子与频率，相邻层的边界不会平行——它们会交错、收窄，这正是让岩层看起来像真实地质而非千层蛋糕的原因。

这些层全部使用对应岩石的**原岩表面处理基础方块**。

## 如何读这些数值

有几个值得注意的规律：

- **`deepslate` 厚度最大（48）**且振幅低——它充当承载其余一切的深部基底。
- **`gravel` 最薄（5）且振幅最小（4）**——是一条薄而相对平缓的带，而非一大团。
- **`pegmatite` 刻意做得薄（12）且频率最低**——分布宽阔、变化平缓，并且在剖面中很罕见。它只出现在一个剖面里，参见[地质剖面](03_geology_profiles.md)。
- **`gneiss` 振幅最高（18）**——其边界起伏最剧烈，因此片麻岩层看起来最扭曲。
