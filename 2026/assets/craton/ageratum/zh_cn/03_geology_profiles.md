# 地质剖面

**地质剖面**把一个生物群系标签绑定到一串有序的地质层。当表面系统构建某一列时，与该列匹配的剖面决定其岩层。

模组自带 13 个剖面。它们全部以 **NeoForge 通用生物群系标签**为键，而不是单个生物群系——因此任何携带正确标签的模组生物群系都会自动被覆盖。

## 共用的平原层序

五个剖面复用同一套层序，源码中称之为 *common* 组：

**石灰岩 → 石头 → 凝灰岩 → 安山岩 → 片麻岩 → 深板岩**

| 剖面 | 生物群系标签 |
|:---|:---|
| `plains` | `IS_PLAINS` |
| `river` | `IS_RIVER` |
| `swamp` | `IS_SWAMP` |
| `beach` | `IS_BEACH` |
| `snowy_plains` | `IS_SNOWY_PLAINS` |

因此在河流下方挖掘的感受与平原下方完全相同——这是刻意设计，不是遗漏。

## 共用的森林层序

三个剖面共享第二套层序：

**石头 → 石灰岩 → 安山岩 → 片麻岩 → 花岗岩 → 深板岩**

| 剖面 | 生物群系标签 |
|:---|:---|
| `forest` | `IS_FOREST` |
| `taiga` | `IS_TAIGA` |
| `jungle` | `IS_JUNGLE` |

## 独立层序

| 剖面 | 生物群系标签 | 层序（自上而下） |
|:---|:---|:---|
| `hills` | `IS_HILL` | 安山岩 → 石头 → 花岗岩 → 片麻岩 → 辉长岩 → 深板岩 |
| `mountains` | `IS_MOUNTAIN` | 片麻岩 → 花岗岩 → **伟晶岩** → 辉长岩 → 流纹岩 → 深板岩 |
| `desert` | `IS_DESERT` | 石灰岩 → 花岗岩 → 石头 → 辉长岩 → 片麻岩 → 深板岩 |
| `savanna` | `IS_SAVANNA` | 花岗岩 → 流纹岩 → 安山岩 → 辉长岩 → 玄武岩 → 深板岩 |
| `ocean` | `IS_OCEAN` | 玄武岩 → 凝灰岩 → 辉长岩 → 石头 → 安山岩 → 深板岩 |

## 实际影响

- **每个剖面都以 `deepslate` 结尾。** 它是通用的基底。
- **`pegmatite` 只出现在一个剖面 —— `mountains`。** 想要伟晶岩就去山地下方挖，其他任何地方都不会自然生成。
- **`marble` 完全没有出现在任何剖面中。** `marble` 层带着完整数值被注册，但自带的剖面没有任何一个引用它，因此**大理岩在任何地方都不会自然生成**。请从创造页获取，或通过数据包添加剖面——参见[数据包与 API](05_datapack_and_api.md)。
- **`gravel` 同样没有出现在任何剖面中**，尽管它已作为层被注册。
- `basalt` 只出现在 `savanna` 与 `ocean` 中，海底以它开头。
- **没有下界或末地剖面** —— 本模组只重塑主世界，其唯一的生物群系修改器作用域是 `IS_OVERWORLD`。

## 没有匹配剖面的生物群系

剖面集覆盖平原、河流、沼泽、沙滩、雪原、森林、针叶林、丛林、丘陵、山地、沙漠、热带草原与海洋。不携带上述任一标签的主世界生物群系——例如蘑菇岛，或繁茂/溶洞类洞穴生物群系——没有属于自己的剖面。
