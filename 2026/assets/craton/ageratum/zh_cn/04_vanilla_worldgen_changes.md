# 它对原版做了什么改动

Craton 不只是添加岩石——它还**移除**了原版地下的一部分多样性，用分层岩层取而代之。在把它装到你在意的存档之前，请先读这一页。

## ⚠️ 九类地下团块不再生成

以下原版特性会从**所有主世界生物群系**中被移除：

| 不再以团块形式生成 |
|:---|
| 花岗岩（上下两种） |
| 闪长岩（上下两种） |
| 安山岩（上下两种） |
| 凝灰岩 |
| **地下泥土** |
| **地下砂砾** |

::: warning
**花岗岩、闪长岩与安山岩仍然存在——但只作为岩层。** 它们会出现在岩石剖面包含它们的生物群系中，成为分层的一部分，而不再是你随处会撞见的散布团块。

**实际后果是：如果某个生物群系的剖面不含花岗岩，那里就完全没有花岗岩。** 你再也不能指望「挖得够深就能找到」这三种岩石中的任意一种。
:::

::: danger
**地下砂砾实际上消失了。** 模组注册了砂砾层类型，但随包的岩石剖面没有一个真正用到它，因此地下不再生成砂砾。

如果你依赖地下砂砾来获取燧石——比如前期做箭——**请改为在河床与沙滩取材。** 这是最可能改变你玩法的一项移除。
:::

## ✅ 矿石完全不受影响

::: tip
**每一种矿石的生成都与原版完全一致。** 煤、铁、铜、金、红石、青金石、钻石与绿宝石都不受任何影响。

所以你的挖矿策略无需改变，关于哪个深度最划算的既有经验也依然成立。Craton 改变的是**矿石周围那些石头的样子**，而不是矿石在哪。
:::

## ⚠️ 加到旧存档上会留下一道接缝

::: danger
**已经生成的区块会保留原版石头。** 只有新生成的地形才会有岩层。

这意味着旧存档会在你此前探索过的范围边缘出现一条**可见的分界**——一侧是原版石头，另一侧是分层岩层。

**想要最好的效果，请开新世界。** 如果你确实要加到旧存档上，那条接缝会一直存在，除非你删掉旧区块让它重新生成。
:::

## 岩层是什么时候生成的

分层是在**地形本身生成的同时**创建的，而不是之后由另一个阶段补上。因此从一个区块存在的那一刻起岩层就在——你永远不会看到某个区块先以普通石头生成、然后再变化。

这也意味着岩石剖面是由**地表生物群系**决定的，所以沙漠底下与森林底下的岩层即使在同一深度也不相同。

## 小结

| 改动 | 对你的影响 |
|:---|:---|
| 花岗岩 / 闪长岩 / 安山岩团块 | **消失** —— 只作为岩层，且仅在剖面包含它们的地方 |
| 地下泥土 | **消失** |
| 地下砂砾 | ⚠️ **完全消失** —— 请去河床取燧石 |
| 凝灰岩团块 | **消失** |
| **所有矿石** | ✅ **不变** |
| 旧存档 | ⚠️ **会有可见接缝** —— 建议开新世界 |
