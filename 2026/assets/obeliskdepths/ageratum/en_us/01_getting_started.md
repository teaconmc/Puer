# Getting started

Before you can enter a dungeon you need the two core blocks: an **Obelisk** and an **Obelisk Smithing Table**, plus at least one **Tempering Upgrade** template.

## Craft the Obelisk Smithing Table

The Obelisk Smithing Table is the machine used for tempering. It is crafted with obsidian, echo shards, smooth stone and a vanilla smithing table:

- Pattern: `OEO` / `STS` / `OEO`
- `O` = Obsidian, `E` = Echo Shard, `S` = Smooth Stone, `T` = Smithing Table

Result: `obeliskdepths:obelisk_smithing_table`.

## Craft the Tempering Upgrade template

The **Tempering Upgrade** (`tempering_smithing_template`) is the template used in tempering and also derives the tier/weight that guide the affix it can roll.

- Pattern: `DED` / `ESP` / `DED`
- `D` = Diamond, `E` = Echo Shard, `S` = Netherite Upgrade Smithing Template, `P` = Paper

Result: `obeliskdepths:tempering_smithing_template`.

## The Obelisk

The **Obelisk** (`obelisk`) is a multi-part structure (bottom / middle / top) that opens the portal to the Obelisk Depths. It is not crafted directly; place it and use it when you have a tribute such as iron ingots, diamonds, netherite ingots or echo shards. See [02 Obelisk & the portal](02_obelisk_and_portal).

## Where everything lives

The creative inventory provides two tabs:

- **Obelisk Depths Building Blocks** (`building_blocks`) — all building material blocks.
- **Obelisk Depths Items** (`obelisk_items`) — two default Tempering Upgrades (tier 1, weight 0.00 and 1.00) and the Return Scroll.
