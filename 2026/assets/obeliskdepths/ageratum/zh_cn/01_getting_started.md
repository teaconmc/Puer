# 开始使用

在进入地牢之前，你需要两件核心方块：**方尖碑（Obelisk）** 与**方尖碑锻造台（Obelisk Smithing Table）**，以及至少一个**淬炼升级（Tempering Upgrade）** 模板。

## 合成方尖碑锻造台

方尖碑锻造台用于淬炼合成，由黑曜石、回响碎片、平滑石与原版锻造台合成：

- 图案：`OEO` / `STS` / `OEO`
- `O` = 黑曜石，`E` = 回响碎片，`S` = 平滑石，`T` = 锻造台

产物：`obeliskdepths:obelisk_smithing_table`。

## 合成淬炼升级模板

**淬炼升级**（`tempering_smithing_template`）是淬炼所用的模板，其 tier（等级）与 weight（权重）也会引导它能淬炼出的词缀。

- 图案：`DED` / `ESP` / `DED`
- `D` = 钻石，`E` = 回响碎片，`S` = 下界合金升级模板，`P` = 纸

产物：`obeliskdepths:tempering_smithing_template`。

## 方尖碑

**方尖碑**（`obelisk`）是一个多方块结构（底/中/顶），用于开启通往 Obelisk Depths 的传送门。它并非直接合成：放置后，若能提供铁锭、钻石、下界合金锭或回响碎片等贡品即可使用。参见 [02 方尖碑与传送门](02_obelisk_and_portal)。

## 内容存放位置

创造模式提供两个标签页：

- **Obelisk Depths Building Blocks**（`building_blocks`）— 全部建材方块。
- **Obelisk Depths Items**（`obelisk_items`）— 两个默认淬炼升级（tier 1，weight 0.00 与 1.00）以及返回卷轴。
