# 配置

更多交互只有一个配置文件，且**仅限客户端**。它注册为名为 `extra_interaction_client.toml` 的客户端配置，并且只在游戏运行于客户端时注册 —— 专用服务器根本不会创建该配置文件。

模组还注册了配置界面工厂，因此可以在游戏内通过模组列表中「更多交互」旁的配置按钮编辑该文件。

## 选项

| 键 | 默认值 | 取值范围 | 含义 |
|:---|:---|:---|:---|
| `xPosPercent` | `70` | `0`–`100` | 选项列表的横向位置，按屏幕宽度百分比 |
| `yPosPercent` | `50` | `0`–`100` | 第一个选项的纵向位置，按屏幕高度百分比 |
| `optionWidth` | `120` | `30`–`999` | 单个选项行的宽度，单位像素 |
| `optionHeight` | `20` | `13`–`99` | 单个选项行的高度，单位像素 |
| `showCount` | `3` | `1`–`12` | 同时完整可见的选项行数 |

`xPosPercent` 与 `yPosPercent` 在文件中是百分比，内部会除以 100，因此 `70` 与 `50` 表示 70% 与 50%。两者都以小数存储，也就是说 `72.5` 这样的分数值同样被接受。

游戏内界面会为全部五个选项显示翻译名称，来自语言文件中的 `extra_interaction.configuration.*` 键。

## 各值如何相互作用

- 列表的锚定方式是让第一行在纵向上以 `yPosPercent` 为中心；可见区域自该处向下延伸 `optionHeight × (showCount + 1)`。
- `showCount` 只控制可见行数，从不控制存在多少项。多出的选项仍可通过滚动到达，且选项数超过 `showCount` 时会出现滚动条。
- `optionHeight` 的下限是 `13`，因为该行必须足够高，以容纳一行文本与 14 像素的图标。

::: info
这里的每个选项都只是外观布局。模组没有服务端配置也没有通用配置，因此这些设置无法被服务器强制或覆盖，也绝不影响存在哪些交互、或交互能否使用。
:::

## 改键

交互键是一个普通按键映射 `key.extra_interact.interact`，列在「选项 → 控制」的「游戏内」分类下，不属于配置文件。改键是解决与原版「与副手交换物品」冲突的受支持做法 —— 尽管选项显示在屏幕上时模组已经抑制了该原版动作，参见[选项列表与操作](02_option_list_and_controls)。
