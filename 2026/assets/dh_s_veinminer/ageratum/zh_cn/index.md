# 海瑞的连锁挖矿

**海瑞的连锁挖矿**（模组 ID `dh_s_veinminer`，版本 `1.0.9`，GPLv3）提供连锁挖掘——挖掉一个方块，整条相连的矿脉跟着一起掉。它只用**一个附魔加九个配置项**实现这件事，除此之外什么都没有：没有物品、没有方块、没有实体、没有配方。

## 一句话原理

给挖掘类工具附上**连锁挖矿**（单等级，仅主手），然后按住触发键破坏方块。范围内所有相连的同类方块随之破坏，上限可配置。附魔是唯一的闸门——**没有它，无论配置怎么设都不会发生任何事**。

## 开始前要知道的两件事

::: warning
**`veinMinerMode` 默认值是 `DISABLED`，而这不表示模组被关闭了。** 它是**方块过滤**模式：`DISABLED` 意为**既不套用白名单也不套用黑名单**，因此所有可挖方块都能连锁。把它设为 `BLACKLIST` 或 `WHITELIST` 才是**施加限制**的做法。详见[配置](02_configuration)。
:::

::: tip
**这个附魔在设计上是昂贵的。** `weight: 2` 使它在附魔台上很稀有，而 `min_cost: 20` / `max_cost: 60` 把它放在费用曲线的高位。可靠途径是**图书管理员交易**——而且注意价格随村民升级而**下降**，从 49 绿宝石降到 25。详见[获取开始](01_getting_started)。
:::
