# 获取开始

## 附魔是唯一的闸门

这个模组做的一切都经由一个附魔：

| 属性 | 值 |
|:---|:---|
| ID | `dh_s_veinminer:vein_miner` |
| 最高等级 | **1** —— 没有更高等级 |
| 适用于 | `#minecraft:enchantable/mining`（镐、锹、斧、锄） |
| 槽位 | **仅主手** |
| 附魔台权重 | **2** —— 稀有 |
| 附魔费用 | `最低 20` / `最高 60`，恒定（不随等级变化） |
| 铁砧费用 | 4 |

主手工具上没有这个附魔时，**无论配置如何都不会连锁**。

## 两种获得途径

**附魔台。** 可行但不可靠：`weight: 2` 让它成为较稀有的结果之一，而 20–60 的费用区间把它放在昂贵的那一端。

**图书管理员交易 —— 可靠途径。** 模组随包五条交易，逐村民等级各一条，全部来自图书管理员。五条都给出带 `vein_miner` 等级 1 的附魔书，`max_uses` 均为 12：

| 村民等级 | 绿宝石 | 给予经验 |
|:---|---:|---:|
| 1 新手 | **49** | 10 |
| 2 学徒 | 42 | 15 |
| 3 老手 | 38 | 20 |
| 4 专家 | 30 | 30 |
| 5 大师 | **25** | 40 |

::: tip
**价格随图书管理员升级而下降**——新手 49 绿宝石，大师 25。若某个图书管理员开价 49，把它升级后再买后续副本大约只需一半价钱。由于每条交易 `max_uses` 为 12，**一个大师级图书管理员就能供应整个服务器**。
:::

## 三种触发模式

`veinMinerTriggerAction` 决定附魔工具**何时**连锁。它是字符串，接受三个值：

| 值 | 行为 |
|:---|:---|
| **`KEYBIND`**（默认） | 仅在按住模组按键时连锁 —— **默认 `V` 键** |
| `SNEAK` | 仅在潜行时连锁 |
| `ALWAYS` | 用附魔工具的每次破坏都连锁 |

该按键在控制设置中有自己的分类 **「海瑞的连锁挖矿」**，可像其他按键一样重新绑定。

::: warning
`ALWAYS` 就是字面意思：你用这把附魔工具破坏的每个方块都会连锁。如果这把工具你也用来做普通挖掘，破坏性会很快显现——而且 `veinMinerExtraDurability` 默认为 `true`，所以它同时也在吃耐久。`KEYBIND` 的存在就是为了让一把工具能兼顾两种用途。
:::

## 触发之后

相连矿脉被破坏，并收到一条聊天消息：

```
连锁挖矿完成！共挖掘了 %d 个方块
Vein mining complete! Mined %d blocks
```

这个数字是真实的，因此它也能反馈你是否撞上了上限（`veinMinerMaxBlocks`，默认 64）。

## 耐久

`veinMinerExtraDurability` 默认为 **`true`**：**每个额外方块都消耗额外耐久**。因此连锁 64 个方块大约消耗 64 点耐久，而不是 1 点。想玩得宽松些可设为 `false`——详见[配置](02_configuration)。
