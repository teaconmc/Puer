# 天际俯冲

天际俯冲围绕泰坦装甲提供多人升空与无鞘翅滑翔玩法。本套文档依据 `skywarddive` 1.0.0 的当前源码编写。

## 阅读路线

- [泰坦装甲](01_titan_armor)：当前唯一物品、获取方式与装备属性。
- [发起俯冲](02_starting_a_dive)：启动条件、饱食度消耗和等待阶段。
- [组队升空](03_group_launch)：加入队伍、编队与离队规则。
- [绑架俯冲](04_kidnap_dive)：携带玩家和生物升空时的范围与上限。
- [滑翔与着陆](05_gliding_and_landing)：升空、滑翔效果及结束方式。
- [锁定界面与路径点](06_targeting_and_waypoints)：纯视觉锁定、死亡点和重生点 HUD。
- [配置与限制](07_configuration_and_limits)：服务端参数、客户端选项与已知边界。

## 基本流程

1. 将泰坦装甲装备到胸甲栏。
2. 确保至少有配置要求的饱食度，默认是 6 点。
3. 按 `V` 发起普通俯冲，等待队友右键加入。
4. 倒计时结束或由发起者按跳跃键后升空。
5. 到达目标高度后朝发起者面向方向进入编队滑翔。

::: warning
本模组没有为泰坦装甲提供合成配方。当前版本需要从创造模式、命令或整合包另行提供的获取方式取得它。
:::
