# Wearables and hats

## Hat items

The mod registers seventeen Hat items. Using one with an empty head slot equips it and consumes the stack:

`pictor`, `bismuth_crystal`, `tri_legged_chair`, `wriggle_nightbug`, `shameimaru_aya`, `hakurei_reimu`, `horaisan_kaguya`, `fujiwara_no_mokou`, `sleeping_orange_cat`, `sleeping_ragdoll`, `butterfly`, `head_bucket`, `symbol_of_love`, `christmas_hat`, `toilet_head`, `conehead` and `fan_head`.

## Pilatory

`yuushya:pilatory` equips the item held in the offhand as headwear when the head slot is empty. Using it from the main hand consumes one Pilatory and the whole offhand stack, then places a copy in the head slot.

::: note
The implementation does not restrict the offhand item to registered hat items, so any non-empty item stack can be worn this way. No gameplay attributes are granted by the headwear; it is a wearable cosmetic slot.
:::
