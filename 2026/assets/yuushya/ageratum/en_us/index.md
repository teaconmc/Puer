# Yuushya Townscape

Yuushya Townscape (方块小镇) is a data-driven town-building mod for NeoForge 26.1. It registers a large catalog of building materials, furniture, storefronts, traffic props, windows, signs, lighting and interior decoration, plus blueprint and template tools that turn a creative inventory into a small-town construction workflow.

## Reading order

1. [Getting started: blueprints and creative tabs](01_getting_started): how the mod organizes its content and opens the stonecutter-style blueprint menu.
2. [Block templates](02_block_templates): template items that generate material variants for stairs, slabs, columns, fences, furniture and more.
3. [Building tools](03_building_tools): the Form Wrench and Block Update Brush.
4. [Connected models and forms](04_connected_forms): how blocks connect to neighbours and switch forms.
5. [Seating](05_seating): sit on chairs, benches, sofas and bicycles through the `ride_entity` chair entity.
6. [Structure generators](06_structure_generators): items that place complete tree, vehicle and building structures.
7. [Wearables and hats](07_wearables_hats): hat items and the Pilatory that equips an offhand item as headwear.
8. [Client options and resource packs](08_client_options): the optional startup check screen, client config and built-in packs.

## At a glance

| Topic | Current implementation |
|:---|:---|
| Mod id | `yuushya` |
| Source target | NeoForge / Minecraft 26.1 |
| Creative content tabs | `extra_blocks`, `wood`, `stone`, `extra_shapes`, `window`, `furniture`, `fabric`, `lighting`, `electrical_appliance`, `living_being`, `signs`, `catering`, `store`, `infrastructure`, `traffic`, `structure` |
| Misc item tab | `item` (tools, blueprints, hats) |
| Blueprint crafting | Stonecutter-style menu opened by blueprint items; recipes are generated by the data generator at build time |
| Tools | `yuushya:form_trans_item`, `yuushya:blockstate_update_item`, `yuushya:pilatory` |
| Entity | `yuushya:ride_entity` (invisible chair) |
| Data components | `yuushya:structure`, `yuushya:mode` |
| Client config | `showCheckScreen`, default `false` |
| Commands | none registered |

::: note
The mod reads its block/item catalog from `data/yuushya/register/*.json`. Recipes are produced by the common data generator and are not committed as static JSON in the current 26.1 checkout, so this guide describes the generated stonecutter workflow without hard-coded recipe IDs.
:::
