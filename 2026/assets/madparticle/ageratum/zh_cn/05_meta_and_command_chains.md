# 元参数与指令链

## 串联粒子

在一段完整 `/mp` 后写入字面量 `expireThen`，再接下一段 `/mp` 参数，可以让前一粒子寿命结束后生成子粒子。设计器把每段显示为指令串列表，并从后向前组装父子关系。

链可以继续延长，但每一段都包含完整固定参数。链越深，网络包、内存与后续生成量越难估算；如果父粒子一次生成多个，每个父粒子都可能继续产生自己的子链。

## meta 的位置

所有固定参数之后可以追加 `whoCanSee`，再追加一个 SNBT 复合标签作为 `meta`。没有 meta 时模组使用空标签及各项内部默认值。只有提供可见玩家选择器后，命令树才接受 meta，因此需要 meta 时不能省略选择器。

meta 键名区分大小写。字符串表达式要使用 SNBT 字符串，例如 `dx:"sin(t*6.283)"`；布尔项使用 `true`/`false`，整数项不要加引号。

## 当前 meta 键

| 键 | 类型 | 当前作用 |
|:---|:---|:---|
| `life` | 整数 | 寿命随机误差百分比，缺省为 `10` |
| `dx` / `dy` / `dz` | 字符串 | 按生命周期表达式追加三轴位移 |
| `light` | 字符串 | 按生命周期表达式给出 `0` 到 `15` 的光照 |
| `disappearOnCollision` | 正整数 | 达到指定碰撞次数后消失 |
| `preCalculate` | 布尔 | 预先模拟并记录整条轨迹 |
| `tenet` | 布尔 | 预先模拟后反向播放轨迹 |
| `halfPrecision` | 布尔 | 网络中用半精度传输大量浮点字段 |
| `indexed` | 布尔 | 在支持条件下使用索引化指令传输 |
| `tada` | 布尔 | 让执行结果从命令源玩家手持喷口发射 |
| `pulse` | 布尔/整数 | 制作喷花筒时标记为脉冲模式 |

## 表达式与预计算

位移和光照表达式支持归一化生命周期变量 `t`。源码最多为表达式准备 `min(lifetime, 100)` 段采样，因此极长寿命不会得到同等数量的独立样本。

`preCalculate` 会在创建时模拟整个寿命并保存轨迹，运行时再播放；`tenet` 则把记录倒序。两者会按寿命分配轨迹数组，不能在超长寿命和海量粒子上无预算使用。

## 索引化传输

`indexed` 旨在减少重复长指令的网络传输。当前代码只在特定专用服务器路径启用，并需要客户端与服务器共同维护索引；开发环境、单人游戏或不匹配客户端不应假定它一定生效。粒子计数器的调试选项可以高亮未使用索引传输的指令。

::: warning
`expireThen`、预计算、反向轨迹和高 `amount` 会相乘放大成本。先用短寿命、单粒子验证，再逐步增加规模。
:::
