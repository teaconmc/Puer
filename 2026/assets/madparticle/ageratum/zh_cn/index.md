# 疯狂粒子

MadParticle 是一套面向地图、数据包和服务器场景制作的粒子工具。它复用已有粒子纹理，通过长参数指令控制生成位置、速度、碰撞、颜色、透明度和大小，并提供可视化设计器、粒子指令链与喷花筒。

## 阅读路线

1. [开始使用](01_getting_started)：确认依赖、打开设计器并生成第一条可执行指令。
2. [设计器工作流](02_designer_workflow)：使用预览、粒子浏览器、参数面板和命令方块入口。
3. [指令基础参数](03_command_parameters)：理解 `/mp` 的固定参数顺序、生成范围和可见玩家。
4. [运动、碰撞与外观](04_motion_collision_and_appearance)：调整物理行为、颜色、透明度、大小和渲染类型。
5. [元参数与指令链](05_meta_and_command_chains)：使用 meta SNBT、表达式、继承和 `expireThen`。
6. [喷花筒](06_tada)：制作脉冲型或连续型喷花筒，并复制其内部指令。
7. [自定义粒子纹理](07_custom_particles)：从本地 PNG 注册单帧或多帧粒子纹理。
8. [性能与兼容性](08_performance_and_compatibility)：配置实例化渲染、并行计算、半透明和光照缓存。

## 快速说明

| 项目 | 当前实现 |
|:---|:---|
| 主要指令 | `/mp`，长名 `/madparticle` |
| 指令权限 | 游戏管理员权限 |
| 默认设计器按键 | `Alt+M` |
| 重建设计器按键 | `Ctrl+M` |
| 固定注册物品 | `madparticle:tada` |
| 生存配方 | 无 |
| 必需依赖 | T88 |

::: warning
这不是只装在服务端即可使用的纯服务端模组。粒子渲染、设计器、配置界面和喷花筒表现都依赖客户端安装；客户端与服务器应使用匹配版本。
:::
