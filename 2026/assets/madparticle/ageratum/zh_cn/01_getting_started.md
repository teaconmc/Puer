# 开始使用

## 环境与用途

当前源码面向 Minecraft `26.1.2` 和 NeoForge，并把 T88 声明为必需依赖。MadParticle 同时包含服务端指令与客户端渲染、网络包和界面，因此多人环境的客户端、服务端都需要安装。

模组没有传统内容循环。它的主要产物是一条 `/mp` 指令，适合放入命令方块、函数或管理员脚本中；喷花筒则把这种指令封装为可持有的演出道具。

## 打开设计器

默认按 `Alt+M` 打开 MadParticle Designer。界面会把视角切到背面第三人称，关闭时恢复此前视角。按键可在原版控制设置中重新绑定。

`Ctrl+M` 会丢弃当前设计器实例并新建一个。界面状态异常或希望彻底清空当前工作区时再使用它；普通打开会继续复用现有实例。

## 第一条可用流程

1. 打开设计器，在粒子浏览区选择一个已有粒子纹理。
2. 在右侧参数区填写持续时间、数量、位置、速度和外观。
3. 让左侧发射周期保持为正数，观察世界内预览。
4. 使用复制按钮取得完整指令。
5. 由有权限的玩家在聊天栏或命令方块中执行。

预览只在本地客户端生成，不等于服务器已经执行指令。正式使用前应在目标位置和目标玩家范围内再次测试。

## 指令权限

`/mp` 与 `/madparticle` 都要求游戏管理员命令权限。未授权玩家不能直接执行，也不能通过设计器向服务器请求制作喷花筒。

命令方块、函数或 `execute ... run mp ...` 仍受各自命令源权限影响。喷花筒保存的是 MadParticle 指令，不是任意命令执行器。

## 登录欢迎页

服务器会在玩家登录时发送欢迎页请求。客户端配置 `noWelcomeScreen` 为 `false` 时，界面会等待其他屏幕关闭后出现；点击“不再显示”会把该配置设为 `true`。这只隐藏欢迎页，不会禁用设计器。
