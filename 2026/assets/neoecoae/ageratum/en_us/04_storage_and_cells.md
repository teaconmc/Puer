# Storage and cells

## The storage multiblock

The simplest of the three systems, and the one to build first:

| Block | Tiers | Role |
|:---|:---|:---|
| **`storage_system`** | `l4` / `l6` / `l9` | the controller |
| `storage_interface` | — | access point |
| `storage_vent` | — | heat exit |
| `storage_casing` | — | structural filler |
| **`eco_drive`** | — | holds ECO cells |

The blockstate list reveals something about how it renders: there are **directional storage-array controller variants** for down, north, south, up and west, each with a plain and an `_s` form. So a storage array's appearance reflects its orientation and state, which makes a large array readable at a glance.

## ECO cells

The addon defines its own cell family with a full type system — a cell type, a cell handler, a basic cell item interface, and a storage cell interface. That is the same shape AE2 uses for its own cells, which is what lets ECO cells sit in AE2 drives and be handled by AE2 tooling.

Six **`ae2:storage_cell_disassembly`** recipes ship with the addon, so ECO cells can be broken back down into their parts exactly as AE2's own cells can.

⚠️ **The most recent fix in the mod's history is `fix cell stack npe crash`.** If you are running an older build than `1.3.4`, cell stack handling is where the known crash was.

## Chemical cells are registered in the language file but not in the game

The Chinese language file contains four keys that the English file does not:

- `eco_chemical_cell_housing`
- `eco_chemical_storage_cell_16m`
- `eco_chemical_storage_cell_64m`
- `eco_chemical_storage_cell_256m`

The English file is **generated by datagen from the actual registry**, and it does not contain them. So **chemical storage cells are not registered in this build** — those four keys are leftovers for content that is planned or was removed.

Do not look for a chemical cell. It does not exist yet, however convincing the Chinese translation file looks.

The same applies to two upgrade keys, `aluminum_alloy_upgrade` and `black_tungsten_alloy_upgrade`, which appear only in Chinese and therefore correspond to nothing registered.

## Energy cells

`energy_cell` comes in the same three tiers — `l4`, `l6`, `l9`. One of the addon's mixins targets AE2's stored-energy-amount display, which is how the addon's larger capacities show correctly in AE2's own readouts rather than overflowing them.

## IO port integration

Two mixins target AE2's IO Port — one on the block entity, one on the menu. That is what makes ECO cells work in the IO Port for bulk transfer, instead of being cells that AE2's own tooling cannot move.

A further mixin touches AE2's internal inventory, which is the plumbing underneath.

## Practical notes

- **Build storage before crafting.** It is the least demanding multiblock and gives you somewhere to put everything else.
- **Use the IO Port.** The integration is deliberate; bulk-moving ECO cells through it is supported.
- **Cells disassemble.** You are not locked into a tier choice — six disassembly recipes exist.
- **Watch orientation.** The directional controller blockstates mean a misoriented array is visually obvious once you know to look.
