# 进食与危险

## 五种食物有自己的伤害类型

模组注册了**五种伤害类型**，每种都以致害之物命名：

| 伤害类型 | 由什么造成 |
|:---|:---|
| **`spicy`** | 辛辣食物 —— 已在**生辣椒**上确认 |
| **`monster_food`** | 怪物分类的菜品 |
| **`pow_cake`** | 能量蛋糕 |
| **`candy`** | 糖果 |
| **`taffy`** | 太妃糖 |

注册为伤害类型而非普通效果，意味着**死亡信息是具体的**。每种都有自己的 `message_id`（辛辣那种是 `crockpot.spicy`），所以日志会记录「被辣椒杀死」而不是「受到致命伤害」。

### 辛辣伤害类型的细节

```json
{
  "exhaustion": 0.1,
  "message_id": "crockpot.spicy",
  "scaling": "when_caused_by_living_non_player"
}
```

疲劳值很低，而其**缩放只在「由非玩家生物造成时」生效**——因此那种会用于生物攻击的难度缩放**不适用于你吃辣椒**。吃一个的代价是固定的，与难度无关。

## 生吃辣椒确实扣血，已确认

模组的消耗品定义写得很明确：辣椒消耗品带有**「食用时通过辛辣伤害类型造成 1.0 点伤害」**的效果。

所以 `peppers` 是一种你种来**做菜**的作物，而不是拿来当零食的。1 点伤害不危险，但它是真的——**而且它是这个模组「把食物当作有后果之物」最清楚的信号。**

## 甜食同样不是免费的

`candy`、`taffy` 与 `pow_cake` **各有自己的**伤害类型（而非共用一个），这是刻意选择。这意味着每一种都能独立调整，也各自产生自己的死亡信息。

**能量蛋糕值得单独警告。** 在《饥荒》里它是那个玩笑食物：技术上能吃，实际上没用。这里它被注册为带伤害类型的东西，**请把它当作危险物而非应急口粮。**

## 怪物菜品是一场交易

`monster_lasagna` 与 `monster_tartare` 建立在 `crockpot:monster` 分类之上，而 `monster_food` 是一种伤害类型。设计意图很明确：**怪物食材有用途，而用它要付代价。**

这正是原作的平衡方式，也是怪物分类之所以存在的原因——见 [02 食材分类](02_food_categories)。

## 进食速度有五档

消耗时长是逐食物的属性，共五级，以相对原版默认值的偏移表示：

| 档位 | 相对原版偏移 |
|:---|:---|
| **超快** | **−0.8 秒** |
| 快 | −0.4 秒 |
| 普通 | 原版默认 |
| 慢 | +0.4 秒 |
| **超慢** | **+0.8 秒** |

已确认的分配：

| 食物 | 档位 |
|:---|:---|
| **爆米花** | **快** |
| **干燥食物** | **快** |
| 芦笋、玉米、茄子、熟茄子、大蒜、洋葱、番茄 | 普通 |

**干燥食物属「快」档正是烘干架值得建造的原因**——见 [05 烘干、鸟与交易](05_drying_and_other_stations)。**烘干不只是保存，它让食物更快吃完，而这在战斗中有意义。**

±0.8 秒这两档相对原版默认值是 40% 的摆动。**一样「超慢」的食物在压力下真的很难吃下去。**

## 实用建议

| 情形 | 建议 |
|:---|:---|
| 战斗中 | 带**干燥食物**或**爆米花** —— 快档 |
| 探索下界 | 猪鼻可正常烹熟；怪物菜品要扣血 |
| 食物短缺 | **不要**退而依赖能量蛋糕、糖果或太妃糖 |
| 种辣椒 | 拿去做菜，绝不要生吃 |
| 建宴会厅 | 菜品是方块 —— 见 [04 菜品](04_the_dishes) |
