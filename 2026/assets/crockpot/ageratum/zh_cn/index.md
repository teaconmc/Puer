# 烹饪锅（Crock Pot）

把《饥荒》的烹饪锅移植到 Minecraft，由五人团队制作——Si_hen、idyllicbean、Whyte_V、MalayP、SeraphJack。

**它不是一张配方表。你把食材丢进去，锅自己算出你做出了什么**：把食材按十种食材分类打分，再匹配到一棵需求树上。搞错了，你会得到一坨湿泥（Wet Goop）。

## 它不依赖任何东西

元数据只声明了 **NeoForge** 与 **Minecraft**。没有库模组、没有声明任何可选集成——你可以把它丢进任何整合包。

（它随包一整套含**七个配方分页**的 JEI 集成，而要读懂它们，JEI 实际上是必需的。见[请安装 JEI，以及其他须知](08_technical_and_limits)。）

## 烹饪究竟如何判定

每种食材在十个分类中都带有**小数值**——肉、蔬菜、水果、鱼、蛋、乳制品、甜味剂、冷冻、怪物、不可食用。每道菜声明对这些**总量**的**需求**，锅会挑出你所满足的那道菜。

以真实的辣椒炖菜（Hot Chili）为例：

| 字段 | 值 |
|:---|:---|
| 需求 | 肉 **≥ 1.5** 且 蔬菜 **≥ 1.5** |
| 烹饪时间 | 200 刻 |
| 锅等级 | 0 |
| **优先级** | **10** |

**优先级是让整套系统运转起来的那个字段。** 同一组食材可能同时满足多道菜；**优先级最高的那道胜出**。这正是「多放一样东西结果全变了」的原因——**而游戏内对此毫无说明**。

| **食材分类** | **10 个，且是数据包注册表** —— 整合包可以添加 |
| 配方 | 7 种类型，其中 4 种是模组自有 |
| 战利品表 | 70 |
| 进度 | 42 |
| **战利品修改器** | **7** —— 青蛙、疣猪兽、草丛与下界要塞的新掉落 |
| **伤害类型** | **5** —— 有些食物会伤害你 |
