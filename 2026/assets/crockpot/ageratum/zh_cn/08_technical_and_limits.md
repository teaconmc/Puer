# 请安装 JEI，以及其他须知

## ⚠️ JEI 实际上不是可选的

::: danger
**玩这个模组之前请先装 JEI。**

烹饪锅根据**需求树与带小数的分类数值**来决定你得到什么——那就是这个模组的全部玩法。而 JEI 正是让这些变得可读的地方：模组提供了**七个 JEI 分类**，其中两个纯粹用于展示信息（食物数值、鹦鹉下蛋）。

**没有 JEI，模组的核心系统就变成不可见的。** 你将在完全没有游戏内参考的情况下猜测分类阈值。

模组在技术上确实能独立运行、也不会崩溃——但那不是现实可行的玩法。请把 JEI 当作必需项。
:::

## 模组包含什么

| 配方类型 | 数量 | 覆盖内容 |
|:---|--:|:---|
| **食物数值** | **87** | 每种材料如何被分类 |
| **烹饪锅烹饪** | **60** | 菜品本身 |
| 喂鹦鹉 | 13 | 投喂鹦鹉 |
| 晾晒 | 8 | 晾晒架 |
| 原版合成 / 烟熏 / 熔炼 | 20 | 普通配方 |
| 猪灵交易 | 1 | 一条交易条目 |
| 爆炸合成 | 1 | 一条爆炸配方 |

所以是 **87 条材料分类支撑 60 道菜**——分类层比菜品清单还大，这正是「理解分类」比「背配方」更要紧的原因。

## 食物分类可以用数据包扩展

十个食物分类是一个正规的数据包注册表，每个条目只含一种颜色。加上食物数值同样是数据，**整个材料分类层都能用数据包编辑，完全不需要写代码**。

如果你想为整合包添加自己的材料、或重新划分现有材料的分类，那就是官方支持的入口。见[食物分类](02_food_categories)。

## ⚠️ 繁体中文不完整

::: warning
**在繁体中文（`zh_tw`）客户端上，大约每六条字符串就有一条显示原始文本**，而不是可读名称。

英文与简体中文都是完整且对等的。繁体中文缺约 44 条，因此你会在物品名与提示文本里零星看到未解析的键。

一切功能仍然正常——这只是显示缺口。如果你介意，用简体中文或英文游玩就能完全避开。
:::

模组没有提供其他语言；其余语言都会回退到英文。

## 模组刻意没有的东西

| 缺席项 | 为什么没问题 |
|:---|:---|
| **配置文件** | 没有任何服主需要调整的东西 |
| **命令** | 锅本身就是全部交互界面 |
| **世界生成** | 作物来自草与普通耕种 |
| **自定义实体** | 鸟笼里装的是原版鹦鹉 |

::: info
没有配置文件这一点值得正面看待：**这个模组没有隐藏开关。** 你在 JEI 里看到什么，它在每一次安装中就做什么。
:::

## 小结

| 检查项 | 原因 |
|:---|:---|
| **安装 JEI** | 否则需求树与分类数值无法阅读 |
| 用英文或简体中文游玩 | 繁体中文有显示缺口 |
| 先读[食物分类](02_food_categories) | 分类比配方更要紧 |
