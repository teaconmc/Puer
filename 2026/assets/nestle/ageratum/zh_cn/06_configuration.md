# 服务端配置

贴贴注册的是服务端配置，并在加载与重载配置时重新解析距离档位和实体列表。

## 主要设置

| 键 | 默认值 | 用途 |
|:---|:---|:---|
| `far_away_nestle_value` | `1` | 不同维度、任一方死亡或超过所有距离档位时的每次增量 |
| `damage_apportion_require` | `360000`（有效值） | 附近玩家加入伤害分摊的阈值，同时控制攻击扣除量与普通贴贴增加量 |
| `bound_damage_value_scale` | `1.0` | 绑定参与者每次分摊后扣除贴贴值的倍率 |
| `nestle_free_require` | `720000` | `Z` 免费贴贴的单向贴贴值阈值 |
| `nestle_radius` | `5` | 普通贴贴目标距离及多种效果/附近分摊的基础半径 |
| `entities_not_spread_damage_by_default` | `[]` | 需要额外效果条件才默认参与附近分摊的实体类型列表 |
| `nestle_lead_avoid_entities` | `[]` | 设计上用于禁止贴贴拴绳的实体类型列表 |

实体列表只接受可解析的实体 ID，例如 `minecraft:cow`。

## 距离档位

`nestle_value_by_distance` 使用 `距离:每秒增量` 字符串，并在配置加载后按距离排序。默认值为：

| 最大距离 | 增量 | 最大距离 | 增量 |
|---:|---:|---:|---:|
| `1` | `100` | `129` | `25` |
| `2` | `50` | `513` | `20` |
| `5` | `45` | `1025` | `15` |
| `10` | `40` | `2049` | `10` |
| `17` | `35` | `4097` | `5` |
| `65` | `30` | 超出 | `far_away_nestle_value` |

代码比较的是实际距离平方与档位距离平方，等于档位边界时仍使用该档位。

## 当前源码中的配置问题

::: warning
源码先把伤害分摊阈值以 `damage_apportion_require = 720000` 定义，随后又把“攻击扣除量 / 使用贴贴增加量”字段以同一个路径定义为 `360000`。后一次定义覆盖配置规格中的该路径，因此新配置的有效默认值是 `360000`，两个 `ConfigValue` 也会读取同一个键。当前没有独立的 `damage_player_value_reduce` 键，这三个用途不能分别配置。
:::

此外，`nestle_lead_avoid_entities` 的交互检查误用了**使用拴绳的玩家类型**，而不是被点击目标的类型。默认空列表不受影响；在修复前，加入 `minecraft:cow` 等目标类型并不能可靠阻止对应目标被连接。

修改服务器配置前应备份文件，并在重载后实测阈值与实体列表。调整 `damage_apportion_require` 时，应同时评估伤害分摊门槛、直接攻击扣除量和普通贴贴增加量。
