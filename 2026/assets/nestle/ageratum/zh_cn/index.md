# 贴贴

贴贴记录每名玩家对其他玩家的单向贴贴值，并围绕这些数值提供冲刺、拴绳、伤害分摊、状态效果、功能方块与药水。

## 阅读路线

1. [贴贴值与指针](01_nestle_value)：理解数值如何增长、查看统计，并使用免费贴贴快捷键。
2. [主动道具](02_active_items)：使用贴贴与贴贴拴绳主动接近目标。
3. [伤害分摊与绑定](03_damage_sharing)：了解附近分摊条件和贴贴绑定的跨距离规则。
4. [效果与方块](04_effects_and_blocks)：认识四种效果及红石控制的方块。
5. [酿造与配方](05_brewing_and_recipes)：查看当前实际酿造链与工作台配方。
6. [服务端配置](06_configuration)：调整距离档位、阈值、半径和实体列表。

## 核心关系

| 系统 | 主要用途 |
|:---|:---|
| 贴贴值 | 按在线距离定期增长，解锁免费贴贴并参与玩家伤害分摊 |
| 贴贴指针 | 指向附近生物，打开玩家贴贴值与距离统计 |
| 贴贴 / 贴贴拴绳 | 短时冲向玩家，或把两个生物拉向中点 |
| 贴贴绑定 | 让快捷栏中的绑定关系跨距离参与伤害分摊 |
| 效果与方块 | 拉近、吸引、推开或阻止部分贴贴机制 |

::: tip
先阅读贴贴值页，再决定使用普通贴贴物品还是积累到免费贴贴阈值。伤害分摊规则比表面效果复杂，服务器管理员应同时阅读配置页。
:::
