# 生效范围

舌战群儒是为 TeaCon 展台设计的，因此整个模组被限制在一个矩形 X/Z 区域内。在区域之外，模组实际上处于关闭状态。

## 区域如何定义

该区域是由四个配置键设定的轴对齐矩形，默认 X 从 -100 到 100、Z 从 -100 到 100。

有两个属性很容易搞错：

- **边界不含端点。** 位置必须在两个轴上都严格大于起点且严格小于终点。正好站在 X = 100 或 X = -100 上算作*范围外*。游戏内配置标签甚至明确写为「范围起始点（不含）」。
- **没有 Y 轴限制。** 只检查 X 与 Z，因此该区域是一根无限高的柱体——只要水平位置在内，模组在基岩层和高空都同样生效。

该矩形也与维度无关：没有任何逻辑检查你所处的维度，因此同一个 X/Z 窗口在所有维度中都处于激活状态。

## 范围限制了什么

| 行为 | 范围内 | 范围外 |
|:---|:---|:---|
| 口水条 HUD | 显示 | 隐藏 |
| 吐唾沫 | 可用 | 被拒绝，提示*「不在本mod展览范围内，无法使用。」* |
| 口水耗尽时的聊天阻止 | 生效 | 不生效——你可以自由聊天 |
| 从水中喝水 | 可用 | 客户端根本不会发送请求 |
| 自然恢复 | 运行 | 不运行 |
| 过度蓄力窒息 | 适用 | 不适用 |
| 已在飞行中的唾沫 | 继续飞行 | 立即销毁 |

请注意最后一行：弹射物每刻都会检查自身位置，一旦离开区域就自我删除。因此你无法把唾沫吐出展台，靠近边界发射的一发也可能在飞行途中消失。

另请注意，聊天的 **1 点口水消耗与范围无关，始终生效**——只有客户端「太渴了不能说话」的阻止受范围限制。在展台之外说话仍会让你变干，只是永远不会真正拦住你。

## 客户端与服务端各持一份副本

服务端总是直接读取配置。客户端保有自己缓存的四条边界，由服务端在玩家登录时发送一次。

这意味着：

- 登录进来的玩家会获得正确的范围。
- 如果管理员在玩家在线时修改范围，这些玩家会保留旧边界直到重新连接。此后他们的 HUD 可见性与客户端检查将与服务端的权威检查不一致。

在运行中的服务器上更改范围后，请让玩家重新加入，以使客户端与服务端保持一致。

## 搭建展台

1. 确定你想要的矩形，记住边界不含端点——每边都比可玩空间多留一格。
2. 设置 `availableRange.start.x` / `.z` 与 `availableRange.end.x` / `.z`。
3. 重启，或让玩家重新连接以使其客户端接收新边界。
4. 走进去验证：口水条出现是可靠的「在范围内」指示。
