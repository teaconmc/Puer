# 工具与它们的门道

本模组有几件工具使用了不直观的操作方式，而提示文本是唯一记录它们的地方。本页把它们集中起来。

## 面粉筛 —— 拿在副手

```
tooltips.bakeries.flour_sieve_0 = 副手持有时筛主手中的物品
```

**筛子放副手、材料放主手** —— 与大多数工具的预期相反。把这个拿反，是新玩家断定「筛子坏了」的最可能原因。

模组知道有人会去筛不该筛的东西，于是准备了三条逐级递进的拒绝：

| 提示 | 文本 |
|:---|:---|
| `flour_sieve_1` | *你在干什么？* |
| `flour_sieve_2` | *这个筛不了！* |
| `flour_sieve_3` | *我没这个本事，你知道的吧？* |

::: tip
这三条值得当作一组来读——它们是关于「试图筛不可筛之物」的刻意玩笑，从困惑一路升级到筛子推卸责任。看到它们说明**操作方式是对的，而材料错了**。
:::

## 面包刀 —— 切你正看着的东西

```
tooltips.bakeries.bread_knife = 使用时切割准星指向的物体
```

**刀作用于你的准星目标**，而不是某个物品栏槽位。它有 5 条自有类型的配方，因此切割是真实的生产步骤而非装饰性动作。

## 模具 —— 长按脱模，且需持刀

```
tooltips.bakeries.mould = 副武器为刀时长按右键可脱模
```

两个条件同时成立：**副武器位有刀** *且* **长按右键**。单独任何一个都无法脱模。模具方块有两个（`mould`、`mould_two`）。

## 吐司机 —— 左手启动

```
tooltips.bakeries.toaster_0 = 用左手右键开始烘烤
tooltips.bakeries.toaster_1 = %s 并右键取出物品
```

**启动用左手**；取出用一个按键组合，提示文本在运行时填入。与筛子一样，这是刻意的副手驱动交互。

## 饮料 —— Enjoy 效果可提升

```
tooltips.bakeries.drink = Enjoy 效果可以被增强至 %s
tooltips.bakeries.shake = 右键摇晃
```

饮料施加一个 **Enjoy** 效果，其强度可以提高——提示文本会填入可达到的等级。`shake`（「右键摇晃」）表明有一个摇晃交互，推测作用于饮料容器。

## 永恒法棍 —— 它是武器

```
tooltips.bakeries.eternal_baguette = 对实体施加强制击退与缓慢效果
```

**强制击退加缓慢。** 在文言文里它叫 **亙久芳司棍饢**。一个面包模组有一件玩笑武器是合理的，而提示文本诚实地说明它作用于实体而非只是装饰。

## 「吃」与「喝」

```
tooltips.bakeries.repeat_eat_item_eat   = 吃
tooltips.bakeries.repeat_eat_item_drink = 喝
```

模组区分这两个消耗动词，而键名（`repeat_eat_item_*`）暗示重复进食是被显式处理的——这与[语言与须知](05_localization_and_technical_notes)里那份「容易被忽略」清单相呼应。

## 不直观操作汇总

| 工具 | 人们最容易弄错的部分 |
|:---|:---|
| 面粉筛 | **筛子在副手**、材料在主手 |
| 面包刀 | 作用于**准星目标** |
| 模具 | 需**副武器有刀** *且* **长按** |
| 吐司机 | **左手**启动 |
| 饮料容器 | 右键**摇晃** |

这些除了提示文本与 Patchouli 手册之外没有任何地方记载——这再次说明了模组为何在登录时就要你安装 Patchouli。
