# 语言与须知

## 三种语言，包括文言文

本模组可用**英文**、**简体中文**，以及少见的**文言文**游玩。

英文与简体中文都是完整的：你在游戏里看到的一切在这两种语言下都有翻译。

## 文言文的译法值得一看

若你把语言切到文言文，烘焙词汇会被重新创造而非音译：

| 物品 | 英文 | 文言文 |
|:---|:---|:---|
| 烤炉 | Oven | **焙爐** |
| 可颂 | Croissant | **朔月饢**（新月面包） |
| 法棍 | Baguette | **芳司棍饢** |
| 贝果 | Bagel | **韌環饢** |
| 恰巴塔 | Ciabatta | **鞾饢**（靴形面包） |
| 佛卡夏 | Focaccia | **中爐饢** |
| 菠萝包 | Pineapple Bun | **鳳梨饢** |
| 永恒法棍 | Eternal Baguette | **亙久芳司棍饢** |
| 指南书 | Baking Guide | **《行饢記》** |

连完美火候的说明也用古文重写了：

> **简体**：拥有完美火候词条的烘焙食物，在玩家饥饿值满时也能食用
> **文言文**：全美火候之焙食者，飢滿亦可食之也。

::: warning
**文言文是部分完成的。** 用它游玩时，仍有相当一部分物品与界面会回退成英文——它覆盖了模组的一部分而非全部。

请把它当作主题化游玩时的风味选项，而不是一份完整翻译。英文与简体中文才是两种完整支持的语言。
:::

## 容易被忽略的地方

把最容易让人意外的行为集中列在一处：

**按最低温度烘焙永远得不到完美火候。** 提示文本给的是下限，不是目标区间。见[烤炉与完美火候](02_oven_and_perfect_temperature)。

**面粉筛要拿在副手。** 材料放主手。见[工具与它们的门道](04_tools_and_quirks)。

**模具需要「有刀」加「长按」两个条件。** 单独任何一个都脱不了模。

**吐司机用左手启动。**

**永恒法棍是武器。** 它会击退实体并使其缓慢，所以别把它放在容易误按的快捷栏位置。

**作物会被动物啃食。** 本模组的作物在这方面与原版一致，所以请给农田围上栅栏。

**有些食物会伤害你。** 生辣椒吃下去会扣血，另有几道菜带自己的伤害类型——死亡消息会具体点出是哪一种。

## 游戏内到哪找帮助

模组会在你登录时提示安装 **Patchouli**，这个建议值得听：**Baking Guide** 那本书才是详细记载温度区间、配方链与工作站用法的地方。本组页面讲的是系统，那本书讲的是具体数值。
