# 获取开始

## 登录消息就是第一条说明

装了 Bakeries 进入世界时，模组会打印：

```
[Bakeries] Install Patchouli to obtain the mod tutorial book
```

请当真。模组随包 **43 个 Patchouli 手册文件**，而它的核心机制是数值化的——没有手册你只能猜温度区间。游戏内物品名为 **Baking Guide**（`bakeries:baking_guide`）。

## 四个创造分页

模组把内容分到四个分页而不是一个，这个划分本身就告诉你该怎么读物品列表：

| 分页 | 内容 |
|:---|:---|
| Bakeries | 主要内容 |
| 半成品 | **中间产物** —— 各种面胚、饼皮、生坯 |
| 兼容物品 | 为跨模组用途存在的物品 |
| Bakery compat | 第二组兼容分类 |

::: info
**「半成品」分页是早期就值得知道的那个。** 这里的烘焙是多阶段的——面粉变面胚、面胚变生坯、生坯变成品——而每个中间产物都有自己的物品。那个分页正是它们的集中地，因此它同时是一张生产链地图。
:::

## 材料从哪来

三个来源，全都能在普通生存中走通：

**世界生成** —— 3 个世界生成文件，因此部分投入物是找到的而不是合成的。

**村民交易** —— **模组自有命名空间 5 条，另加 1 条添进 `minecraft`**。后者值得注意：模组往原版村民职业的交易里注入了内容，因此**一个普通村庄就能供应本模组的东西，无需存在任何 Bakeries 方块**。

**合成** —— 26 条有序 + 25 条无序原版配方，另有 2 条熔炼与 1 条营火。**全部 107 条配方中约有一半用的是原版类型**，所以在你建造任何工作站之前，模组的很大一部分就已可接触。

## 第一条该建的链

1. **面粉筛** —— 把原料变成面粉（4 条配方）。它是手持工具而不是方块；见[工具与它们的门道](04_tools_and_quirks)。
2. **面胚制作台** —— 面粉变面胚（8 条配方）。
3. **烤炉** —— 面胚变面包，温度由你选定（15 条配方）。[完美火候](02_oven_and_perfect_temperature)就发生在这里。

搅拌机（14 条）与饮料站（6 条）分支向饮品；面包刀（5 条）用于切割成品。

## 模组没有的东西

| 功能 | 状态 |
|:---|:---|
| 配置文件 | **无** —— 零处 `ModConfigSpec` |
| 命令 | **无** |
| 必需依赖 | 除 NeoForge 与 Minecraft 外**无** |
| 流体 | 无 `fluid.bakeries.*` 键 |
| 实体 | 无 `entity.bakeries.*` 键 |

因此没有东西要配置，也没有东西要先装。一切都能通过玩法到达。
