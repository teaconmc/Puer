# Bakeries

**Bakeries**（模组 ID `bakeries`，作者 Renyigesai、1-weibai-1、NeptuneTADASHI、zhifan）是一套完整的烘焙内容扩展：六个自定义工作站、71 个方块、65 个物品，以及一套**把火候控准就能在饱食状态下进食**的温度系统。

按资源数量计它是本批最大的内容模组之一——512 个模型与 299 张贴图——并随包一整套 Patchouli 手册，外加一份**文言文（`lzh`）本地化**。

## 它的独特之处

**一套真正的温度机制。** 烤炉不是计时器——你用鼠标滚轮设定温度，落在正确区间就能产出带**完美火候**词条的食物。这类食物有着普通食物没有的好处：饥饿值满时也能吃。

**六个各司其职的工作站**而不是一台什么都干的机器：烤炉、搅拌机、面胚制作台、面粉筛、面包刀与饮料站各有自己的配方类型。

**一份文言文翻译。** 除 `en_us` 与 `zh_cn` 外，模组还随包 `lzh`，且译法很有创造性：可颂成了**朔月饢**、法棍成了**芳司棍饢**、指南书成了**《行饢記》**。

::: tip
**请安装 Patchouli。** 模组自己就这么说——登录时它会打印「[Bakeries] Install Patchouli to obtain the mod tutorial book」。有 43 个手册文件、而核心机制建立在数值温度区间之上，游戏内手册确实是首要参考。本组页面讲的是这套系统与围绕它的源码层面事实。
:::
