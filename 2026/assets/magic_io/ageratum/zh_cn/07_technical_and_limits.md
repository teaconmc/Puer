# 须知

## 有配置文件——但它什么都不做

::: warning
**MagicIO 会生成一份含四个选项的配置文件，而它们都不影响任何你在游戏中能观察到的东西。**

它们只控制写进日志的内容。配置界面会用正规标签显示这些选项，让它们看起来很有意义——实际上不是。

如果你打开配置是想找调整模组行为的办法：没有这种选项。「法术」如何运作是固定的。
:::

## 有一处界面标题没有翻译

**在英文客户端上，JEI 里「阵」配方分类的标题会显示原始内部名称**而不是可读文字。中文客户端则显示正常。

除此之外两份翻译都完整——16 种元素、6 个层级、37 个功能名全部齐备。

## `/magicio tags` 在任何语言下都用中文回复

模组唯一的命令会把物品标签导出为 JSON 参考文件。它的三条回复消息是**直接写死的中文**，背后没有任何翻译机制。

所以无论你用什么语言设置，运行这条命令看到的都是中文提示。功能本身完全正常；受影响的只有消息文字。

它还是一条**客户端命令**——不需要权限等级，服务端也无法限制。

## 能与哪些模组协作

| 模组 | 你会得到 |
|:---|:---|
| **JEI** | 「阵」配方的专属分类 |
| **Jade** | 看方块与物品时显示其法术属性 |

两者都是可选的；不装它们一切照常，只是少了这两种视图。

## 一处不是问题的文件现象

`zh_cn.json` 开头带一个字节顺序标记（BOM），某些外部工具会因此把它标为无效 JSON。

::: info
**Minecraft 读这个文件毫无问题** —— 全部键都正常加载。如果某个检查工具抱怨它，请无视那个工具；不要去「修」这个文件。
:::

## 小结

| 项 | 状态 |
|:---|:---|
| 配置文件 | 存在但**在游戏中不起任何作用** |
| JEI 阵分类标题 | 英文客户端显示原始文本 |
| `/magicio tags` 的回复 | 恒为中文，功能正常 |
| 英文 / 中文覆盖 | 除那一处标题外全部完整 |
