# 损坏阶段

与原版铁砧一样，木砧会随使用而劣化。不同之处在于，本模组提供了自己的一套阶段链。

## 阶段链

每种形态恰好三个阶段，磨损每次向下走一步：

```
<木材>_anvil  →  <木材>_chipped_anvil  →  <木材>_damaged_anvil  →  （毁坏）
```

去皮形态拥有自己平行的链——**去皮状态会贯穿损坏保留下来**。缺角的去皮橡木砧会劣化为破损的去皮橡木砧，绝不会变回带皮的。

方块的**朝向在每一步都被保留**，因此砧在磨损时不会转向。

## 实现方式

`AnvilBlockMixin` 注入原版 `AnvilBlock.damage` 的**头部**，当状态属于 `WoodenAnvilBlock` 时取消原版路径，改为返回本模组自己的下一级状态：

```
if (WoodenAnvilBlock.isWoodenAnvil(state)) {
    cir.setReturnValue(WoodenAnvilBlock.damageWoodenAnvil(state));
}
```

由于该注入是替换返回值而非另设一套机制，木砧的磨损**触发条件与概率都与原版铁砧完全一致**。没有独立耐久、没有额外配置，也没有任何办法让它磨损更快或更慢。

`damageWoodenAnvil` 在 `DAMAGE_MAP` 中查找当前方块并返回映射到的下一级状态，若无条目则返回 `null`。返回 `null` 正是原版用来表示「砧已消失」的信号——因此破损阶段就是最后一级。

## 破损阶段是一条死路

三个事实在此叠加，合起来比单独任何一条都重要：

- **`DAMAGE_MAP` 每种形态只含两条链接**（基础 → 缺角、缺角 → 破损）。破损阶段没有出边，因此映射为 `null`，方块被毁坏。
- **缺角与破损阶段没有任何配方。** 全部 24 个配方只产出基础阶段的砧。
- **不存在任何形式的修复机制**——没有锻造、没有合成、没有手持材料右键、也没有命令。

因此磨损过的木砧无法复原。你可以把它挖起来换个地方放（阶段会保留），但要回到完好的砧只能重新合成一个。

::: tip
破损木砧并非一无所值——它仍是一台能正常工作的铁砧，而且作为燃料的价值分毫不减。参见[标签、工具与燃料](05_tags_tools_and_fuel.md)。
:::

## 每个阶段都是能用的铁砧

三个阶段都继承 `AnvilBlock`，也都以自己的显示名打开铁砧界面。破损砧的附魔与修复效果与全新砧**完全相同**；阶段纯粹是磨损计数器加一套贴图，对功能没有任何影响。
