# 与其他模组一起玩

本模组除 NeoForge 与 Minecraft 之外什么都不需要，但与另外五个模组共存时表现更好。这里没有任何一项是必需的——它们都只是「你恰好装了就有」的加成。

## 季节类模组：让你的葡萄进入它们的历法

支持两个不同的季节模组，且各按其术语对接：

**SereneSeasons** —— 果实与藤蔓属于不同季节：

| 植物 | 季节 |
|:---|:---|
| 葡萄作物 | **秋季** |
| 葡萄藤架 | **春季** |

**节气（Ecliptic Seasons）** —— 全部六个生长方块都被登记为**中等湿度作物**，覆盖普通、冰霜与黄金三种的作物与藤架。

::: tip
**两者可以同时运行。** 它们问的问题不同——SereneSeasons 问「哪个季节？」，节气问「湿度多少？」——而本模组用各自的语言分别作答，而不是强行统一成一种分类。

节气也是本届比赛的参赛作品，所以如果你在玩比赛整合包，你的葡萄会自动正确接入它的湿度系统，无需任何设置。
:::

## Diet：葡萄算作水果

四种葡萄——普通、冰霜、黄金与青葡萄——都在 **Diet** 中登记为水果，因此它们会计入那个模组的营养分类，你什么都不用配置。

## Carry On：酒馆方块被刻意锁住

::: info
**如果你在用 Carry On 而拿不起某个酒馆方块，那是有意为之。**

Carry On 通常允许你整体抬起并搬走方块实体。本模组把自己的方块排除在外——沙发、招牌、威士忌方块、画作、葡萄作物等等。

对一间酒馆而言这是正确的选择：否则来客可以直接搬走你正在发酵的酒桶或你的家具。请改用正常的破坏与重放方式。
:::

## Ponder：四段动画教程

如果你安装 **Ponder**，本模组会提供四段游戏内动画场景：

| 场景 | 展示 |
|:---|:---|
| **酒桶** | 酒桶如何工作 |
| **压榨桶** | 压榨如何进行 |
| **葡萄种植** | 怎么种葡萄 |
| **葡萄野生生成** | 葡萄如何自然出现 |

::: tip
**这四段场景是本模组唯一的可视化文档。** 如果你想*看到*酒桶成排堆叠时如何附着、或野生葡萄如何生成，安装 Ponder 就是办法——动画展示得比文字清楚得多。

没有 Ponder 一切仍然正常，只是没有这些教程。
:::

## 不需要任何模组的原版加成

有两件事通过原版系统开箱即用：

| 物品 | 行为 |
|:---|:---|
| **葡萄藤** | 可作燃料 —— **200 刻**，约与木板相当 |
| 葡萄、黄金葡萄、青葡萄 | **50% 可堆肥** —— 且**村民会使用它们** |
| 葡萄藤 | 25% 可堆肥 |

::: info
果实上的「村民可堆肥」为真，意味着**村庄的堆肥桶会消耗你的葡萄**。如果你在村庄附近种田并疑惑收成去哪了，这一点值得知道。
:::

## 哪些模组值得加

| 模组 | 你会得到 |
|:---|:---|
| **Ponder** | 四段动画教程 —— 体验提升最大的一项 |
| SereneSeasons *或* 节气 | 葡萄遵循季节或湿度 |
| Diet | 葡萄计入营养 |
| Carry On | 不需要，但装了会被尊重 |
| Jade | 方块提示正常工作 |
