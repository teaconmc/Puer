# 进阶雪傀儡

进阶雪傀儡是一个可搭建、可装备、可切换模式的盟友。它是模组中最有深度的系统，而全部操作都由物品而非 GUI 驱动。

## 召唤

把**智能雪块**放在两个堆叠的雪块之上，即生成一个**进阶雪傀儡**（`bsf3lite:bsf_snow_golem`）—— 与搭建原版雪傀儡形状相同，只是头换成模组的方块。

| 实体 | 最大生命 | 跟随范围 | 速度 |
|:---|:---|:---|:---|
| `bsf_snow_golem` | 15 | 60 | 0.3 |
| `hostile_snow_golem` | 15 | **100** | 0.3 |
| `bsf_dummy` | `Float.MAX_VALUE` | 60 | **0** |

三者尺寸均为 0.7 × 1.9 格。两种傀儡都免受细雪影响。

敌对变体不只是换皮：它的跟随范围是 100，而友方傀儡是 60，所以敌对傀儡会在远超你自家傀儡反应距离之外就发现并交战。

## 装备

用你想让它携带的物品右键傀儡：

| 右键使用 | 效果 |
|:---|:---|
| 武器或雪球储存罐 | 装备它 |
| 空手 | 取下储存罐 |
| 潜行 + 空手 | 取下武器 |
| 原版雪球 | 切换傀儡皮肤 |

::: warning
进阶雪傀儡只能使用**雪球大炮或雪球霰弹枪**，而且只能从**储存罐**开火。给它步枪或机枪，或者给散装雪球而不是装满的罐子，它就只会站在那里无法射击。这一点写在智能雪块自己的提示文本里，也是新搭好的傀儡毫无动作的最常见原因。
:::

装备成功会播放模组的 `snow_golem_equip` 粒子，所以交接是否成功一眼可见。

## 行为模式

**雪傀儡模式调节器**用来配置傀儡。它在数据组件中保存两个独立模式，各自用修饰键加鼠标滚轮循环：

**行为**（5 个值，`tweaker_status_mode`）：

| 模式 | 含义 |
|:---|:---|
| 待机 | 原地不动、不行动 |
| 跟随 | 跟随主人 |
| 护卫 | 跟随**并**攻击 |
| 巡逻 | 攻击但不跟随 |
| 炮台 | 原地不动并射击 |

**目标**（2 个值，`tweaker_target_mode`），配合 HUD 报作 Target / Aim 的瞄准选择器：

| 选择器 | 含义 |
|:---|:---|
| 无 | 不选目标 |
| 怪物 | 敌对生物 |
| 指定 | 某个被标记的特定目标 |
| 对手 | 敌对队伍 |
| 全部 | 所有生物 |

用调节器右键傀儡即应用设置，HUD 以「Mode imported successfully」确认。每次循环都会播放原版发射器的点击声，因此不看屏幕也能数步数。

## 治疗

傀儡靠喂食维护，而不是靠修理物品：

| 喂食 | 效果 |
|:---|:---|
| 光滑雪球、雪块、细雪 | 恢复生命 |
| 冰 | 授予再生效果 |

再生的授予带有**增益冷却期**，HUD 报作「Cooldown period for buffs」，所以你无法靠连续喂冰获得永久再生。

## 运输与创造工具

| 物品 | 作用 |
|:---|:---|
| `snow_golem_container` | 收纳与释放进阶雪傀儡 |
| `creative_snow_golem_tool` | 切换强化模式，并复制/粘贴傀儡 |

容器把傀儡装在 `snow_golem_data` 组件里 —— 一整个实体装进一个物品，因此配置好的傀儡能被带着穿越整个世界。

创造雪傀儡工具的**强化模式**让傀儡每刻回复、提升抗性、削减核心冷却，并停止消耗弹药与武器耐久。它还能复制一个傀儡的完整配置，并通过右键方块重新生成该副本 —— 这是组建成建制小队的既定方式。

::: info
强化模式明确是创造/测试便利功能。处于强化模式的傀儡永远不会耗尽弹药，因此它不能作为衡量生存傀儡表现的公平基准。
:::

## 假人

`bsf_dummy` 是训练靶：`Float.MAX_VALUE` 生命、`Double.MAX_VALUE` 击退抗性、移动速度 0。它杀不死、推不动、也不会移动 —— 正是测试雪球伤害与 `snowball_damage_trigger` 判据所需的东西。
