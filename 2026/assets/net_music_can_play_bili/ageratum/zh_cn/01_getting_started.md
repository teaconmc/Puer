# 入门

## 前置条件

| 需要 | 状态 | 说明 |
|:---|:---|:---|
| **NetMusic `[1.5.1,)`** | **必需** | 这是附属模组，在 NetMusic 之后加载 |
| Curios `[12,)` | 可选 | 让耳机与眼镜可占用头部槽位 |
| Iris | 可选 | 通过带守卫的兼容层处理 |
| 网络连接 | 实际必需 | 一切都从 B 站获取 |

没有仅客户端或仅服务端的限制：两个必需依赖都声明为 `side="BOTH"`。

## 出声的最短路径

本附属的核心承诺是：NetMusic 原有的流程现在接受 B 站链接。

1. 取一个 **B 站视频 ID 或 URL** —— `BV…` 号、`av…` 号，或完整链接。
2. 用 NetMusic 自己的刻录机把它写到**音乐 CD** 上。
3. 在 NetMusic 的播放器或本附属的**现代化唱片机**中播放。

模组会把 ID 解析成真实音频流、解码并播放。**你从不需要自己处理流地址。**

## 直播用另一种前缀

如果要播直播而不是录播，输入格式变了：

> `live:<直播间 ID>`

在**广播喇叭**中输入即可播放该直播间的音频。它走的是与视频不同的解析器，因此行为也是直播式的——不能跳转、没有固定时长。

## 不能从哪里开始

**不要粘贴直链流地址。** 模组会明确识别并拒绝 B 站原始媒体 URL。解析必须走正规路径，这样请求签名、CDN 选择与白名单才都能生效。**粘贴 CDN 链接会被当作「被禁止的直链」而不是捷径。**

## 登录是可选的，但有后果

匿名使用对普通内容是可行的。登录解锁的是你账号能访问的范围——尤其是更高画质档位与 Dolby 音频流。

登录方式是**扫码**：模组向 B 站请求一个登录二维码，你用 B 站手机 App 扫描，模组轮询直到成功，随后保存你的会话 Cookie。

**登录之前请先读 [08 技术说明与限制](08_technical_and_limits)。** 该 Cookie 以明文写入磁盘，而这对分享配置、整合包与日志有实际后果。

## 在服务器上，请预期有白名单

如果服务器启用了链接白名单，只有被批准的 B 站资源才能播放；尝试其他内容会得到一条指明「你试图做什么」的拒绝消息。请求可由管理员复审批准。

它在**六个**独立位置强制执行——刻录唱片、唱片机、NetMusic 自己的播放器、MP4 播放与同步、以及平板播放——**因此没有侧门**。详见 [07 审核与权限](07_moderation_and_permissions)。

## 先造什么

| 目标 | 造这个 |
|:---|:---|
| 只想听 | **现代化唱片机**，或用 NetMusic 自己的播放器 |
| 听但不打扰别人 | **隐形耳机**（或**猫耳耳机**） |
| 让整个房间有声音 | 连到音源的**扬声器** |
| 不只听，还要看 | **视频投影仪** |
| 想看歌词 | **歌词投影仪** —— 它用的是 B 站字幕 |
| 随身带音乐库 | **平板**，可装 64 张唱片 |
| 边走边看 | **MP4** 播放器，或**全息眼镜** |
| 管理链接与绑定 | **媒体管理工具** |

以上每一件都在 [02 设备](02_devices) 中说明。

## 关于两个方块的警告

**扬声器与歌词投影仪没有战利品表。** 破坏任何一个都会**永久销毁**它，生存与创造模式一致。只有现代化唱片机与视频投影仪会掉落自身。
