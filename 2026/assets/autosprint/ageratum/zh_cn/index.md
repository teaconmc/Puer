# Orga's AutoSprint（自动疾跑）

Orga's AutoSprint 为 Minecraft 加入了 MMORPG 风格的自动奔跑：按一个键，角色就会自行持续向前移动，直到你接管或取消。它是一个**纯客户端**便利模组——没有物品、没有方块、没有命令，也不向服务端发送任何内容。

## 快速说明

| 项目 | 值 |
|:---|:---|
| 模组 ID | `autosprint` |
| 版本 | `0.org-itk.0.1` |
| 许可证 | CC0 |
| 作者 | luoxueyasha |
| Minecraft | 26.1.2 |
| NeoForge | 26.1.2.55-beta |
| 端 | **仅客户端**（`dist = Dist.CLIENT`） |
| 按键绑定 | 切换自动行走 — 默认**鼠标按键 5**，仅游戏内生效 |
| 按键分类 | `autosprint:category` |
| 配置 | COMMON（`autosprint-common.toml`），2 个选项，支持游戏内配置界面 |
| 物品 / 方块 / 实体 / 配方 / 命令 | 无 |
