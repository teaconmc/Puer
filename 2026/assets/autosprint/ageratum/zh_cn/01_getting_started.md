# 开始使用

整个模组只有一个按键绑定。没有任何需要合成的东西，也没有任何需要放置的方块。

## 按键绑定

| 属性 | 值 |
|:---|:---|
| 翻译键 | `key.autosprint.auto_run` |
| 默认绑定 | **鼠标按键 5** |
| 分类 | `autosprint:category` |
| 冲突上下文 | 仅游戏内 |

可在 选项 → 按键控制 中重新绑定。由于该绑定注册时带有「仅游戏内」冲突上下文，当界面或聊天框获得焦点时它不会触发。

请注意，模组 README 写的默认键是「Mouse-4」。源码绑定的是 `GLFW_MOUSE_BUTTON_5`，Minecraft 显示为**鼠标 5**。请以游戏内按键列表为准，而不是 README。

## 切换自动行走

按一次按键开始自动行走，再按一次停止。自动行走期间：

- 你的角色会自行持续按住前进键。
- 默认为**疾跑**而非行走（可配置，见 [03 配置](03_configuration)）。
- 每次开启或关闭时，聊天栏会出现一条随机提示消息。

你不需要按住任何键。转向与视角操作正常工作，因此可以在自动行走时控制方向。

## 停止

结束自动行走有三种方式，且它们并不等价：

| 操作 | 结果 |
|:---|:---|
| 再次按下自动行走键 | 完全停止移动 |
| 按下**前进**键（W） | 自动行走结束但你**继续移动**——只是改由你手动接管 |
| 按下**后退**键（S） | 完全停止移动 |

前进键这一情形最实用：轻按 W 即可把控制权交回自己，而不中断移动。精确规则见 [02 自动行走行为](02_auto_move_behaviour)。

## 仅客户端

模组声明为纯客户端，且从不与服务端通信。这意味着：

- 你可以在任何服务器上使用它，服务器无需安装任何东西。
- 它不会出现在任何服务端模组列表要求中。
- 它所做的一切只是按住你自己的前进键并设置你自己的疾跑标记，就像你亲手按键一样。
