# 移动任务与网络

## 服务端移动任务管理器

位移型技能不会让客户端任意传送玩家。服务端通过 `MovementManager` 按实体 UUID 分配一个 `MovementTask`：

- 只有优先级规则与替换保护允许时，新任务才能替换现有任务。
- 死亡、离开维度、服务端拒绝与外部取消都会结束当前任务并发送校正。
- 玩家主动任务会保护自己不被外部取消。
- 等待任务超时为 240 tick（12 秒）。

## 客户端模拟流程

火箭重拳、上勾拳自身推进、辅助撤离自身位移、裂地重拳与毁天灭地下落都由服务端发送 `olru:start_movement`，内含任务 UUID、任务类型、速度、最大距离、可选碰撞伤害与结束速度标志。客户端本地模拟移动，完成后发送 `olru:movement_result`：

- `taskId`：必须与当前服务端任务一致。
- `claimedPosition`：必须距任务起点不超过 `maxDistance + 8` 格。
- `hitEntityIds`：每个实体必须是同一维度的存活实体，且距回报的碰撞位置不超过 16 格。
- `wallHit` 与 `facing`：决定冲击类型与锥形方向；朝向会归一化为水平方向，无效时回退到服务端玩家的当前视线。
- `elapsedTicks`：裂地重拳用它计算滞空伤害。

服务端在回报命中附近附加 2.75 格溅射范围收集有效目标，然后把玩家传送到被接受的回报位置并完成任务。任务被取消或超时时，`olru:stop_movement` 会让客户端停止并校正位置。

## 移动任务类型

| 客户端任务 | 来源技能 |
|:---|:---|
| `ROCKET_PUNCH` | 传世经典·火箭重拳 |
| `ENTITY_PUSH` | 上勾拳自身、辅助撤离自身位移、被击飞的生物 |
| `SEISMIC_SLAM` | 传世经典·裂地重拳 |
| `METEOR_HOVER` | 传世经典·毁天灭地瞄准阶段 |
| `METEOR_FALL` | 传世经典·毁天灭地下落 |

毁天灭地悬停是“客户端模拟”的例外：服务端权威控制玩家高度、水平半径与碰撞状态，客户端只在该范围内移动。专用状态载荷会标记悬停激活，让客户端把左键重定向为 `olru:movement_task_action`（`PRIMARY_ATTACK_PRESSED`）提前下落。

## 技能数据包

模组在网络版本 `"1"` 下注册 7 个数据包：

| 方向 | ID | 用途 |
|:---|:---|:---|
| 客户端 → 服务端 | `olru:gauntlet_skill` | 普通攻击、技能二、技能三、终极技；技能一不走此载荷 |
| 客户端 → 服务端 | `olru:movement_result` | 模拟移动完成与命中回报 |
| 客户端 → 服务端 | `olru:movement_task_action` | 运行时动作，如毁天灭地提前下落 |
| 服务端 → 客户端 | `olru:start_movement` | 开始客户端模拟移动任务 |
| 服务端 → 客户端 | `olru:stop_movement` | 停止并校正移动任务 |
| 服务端 → 客户端 | `olru:movement_task_state` | 毁天灭地悬停状态 |
| 服务端 → 客户端 | `olru:gauntlet_effect` | 视觉效果：火箭蓄力、流星落点、撤离光束、镇静、纳米激励 |

视觉载荷会广播给效果原点 96 格内的玩家；毁天灭地落点标记还会直接发给施法者。

## 权限边界

- 左键、技能键与终极技只是请求动作。服务端处理器检查主手仍持有 `AbstractGauntletItem`，技能方法也会先复查自身状态再消耗。
- 瞬发命中、锥形与手雷爆点都由服务端计算；这些技能不接收客户端目标列表。
- 移动碰撞是唯一由客户端提供的命中列表，每个声明的实体在造成伤害前都会按距离与维度重新校验。
- 客户端发送的 `elapsedTicks` 在位置校验范围内被信任，并直接影响裂地重拳伤害缩放。
- 技能状态同步使用玩家附件；客户端镜像不运行冷却，也不拥有授权。

**注意：** 辅助撤离在服务端收到右键开始时就会消耗冷却，而不是等释放完成。除非初始就绪检查失败，否则被打断的蓄力仍然会花费技能。
