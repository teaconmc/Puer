# 中键标点（Middle Key Ping）

中键标点（模组 ID `middle_key_ping`）是一个客户端驱动、服务端转发的协作标记模组。按下或按住鼠标中键可以创建可见的标点，也可以从滚轮中选择「通用 / 警告 / 前往 / 敌人」。标点经服务器转发给其他玩家，在世界中显示为带距离标签的彩色标记，并伴随类型专属音效与聊天消息。

模组不注册物品、方块、实体、配方或命令，完整功能面只有按键绑定、两个网络载荷、客户端配置与渲染。

## 速览

| 项目 | 当前实现 |
|:---|:---|
| 模组 ID | `middle_key_ping` |
| 默认按键 | 鼠标中键（统一标点） |
| 标点类型 | 统一、通用、警告、前往、敌人 |
| 标点持续时间 | 300 tick（15 秒） |
| 默认最大距离 | 200 格 |
| 默认最大同时标点数 | 6 |
| 配置 | 通过配置界面的客户端 TOML |
| 注册的物品/方块/实体/配方/命令 | 无 |
| 网络载荷 | `middle_key_ping:position_inspection_state`、`middle_key_ping:entity_inspection_state` |

**注意：** 标点创建发生在客户端，但标记必须经服务器转发。位置标点会到达同维度所有玩家；实体标点只到达正在追踪该实体的玩家（如果实体本身是玩家，也包含其本人）。
