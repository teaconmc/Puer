# Getting Started

Everything this mod adds is reachable from one creative tab; there are **no crafting recipes**.

## Creative tab

The tab is registered as `lanfasie_benderson:main`, titled "Lanfasie: Chapter Benderson", with the Aggro Up icon (`aggro_up_icon`) as its tab icon. It contains:

- `deep_latent_caller`
- `ominous_orb`
- `provoking_stick`
- `sword_of_dawnwaiter`
- `shalloway_sword`
- `shalloway_shield`
- `mundane_praiser_bow`
- `mundane_praiser_cane`
- `mundane_praiser_rapier`
- `mundane_praiser_mana_foci`
- `dawnwaiter_totem`
- `end_guardian_statue`
- the five Unforgiven spawn eggs

Some registered items are deliberately **not** listed in the tab, including `aggro_up_icon` (used as the effect icon), `sword_of_dawnwaiter_tainted`, `claymore_of_hei_power` and `deep_latent_block`.

## Blocks

| Block | Notes |
|:---|:---|
| `deep_latent_block` | Destroy time 2, light level 2, explosion resistance 20, **no loot table** (drops nothing). |
| `deep_latent_caller` | Destroy time 5, light level 2, explosion resistance 1000. This is the block the Ominous Orb is used on. |
| `end_guardian_statue` | Strength 3.0 / 5.0, destroyed by pistons. Its item is a double-high block item. |

## Preparation checklist

1. Get a `deep_latent_caller` and place it with **at least one empty block above it**.
2. Get an `ominous_orb`.
3. Make sure no Benderson already exists nearby — the orb refuses to fire if one is within a 48 x 18 x 48 box.
4. Clear space: the arena defaults to a radius of **24** blocks around the summon point.

See [Starting the fight](02_starting_the_fight.md) for the exact summon rules.
