# 旗帜

旗帜是模组中体量更大的建造功能：你用方块搭出一个实体矩形，再把它缝合成一面可编辑的整旗。

**请记住三样部件都无法合成**——旗杆、旗布与缝合工具都没有配方，因此除非管理员发放，这套系统只能在创造模式使用。详见 [01 开始使用](01_getting_started)。

## 两种方块

| 方块 | 硬度 / 抗性 | 音效 | 说明 |
|:---|:---|:---|:---|
| 旗杆 | 2.0 / 6.0 | 金属 | 支撑框架 |
| 旗布 | 0.5 | 羊毛 | 旗面 |

两者都不遮蔽光照，因此不会让相邻方块变暗，也不会隐藏相邻方块面。

## 搭建一面合法的旗

结构规则很严格，而且模组会明确告诉你违反了哪一条。以下全部条件必须同时满足：

1. **平面**——旗布必须只有一格厚。两格厚的布块会被拒绝。
2. **完整矩形**——矩形的每一格都必须填满。缺角、开洞与 L 形都会被拒绝。
3. **四角由旗杆支撑**——矩形的各个角必须靠在旗杆上。
4. **尚未被缝合**——已经绑定到某面成品旗的布块不能重复使用。

任一检查失败时你会收到针对该条的具体聊天提示，而不是笼统的错误，这让排查大型旗帜变得很直接。

## 缝合

手持缝合工具右键**旗布**——不是旗杆。右键其他任何东西都会提示你要对准布块。

- 若该布块**尚未缝合**，工具会尝试缝合整个结构，并报告成功或你违反的具体规则。
- 若该布块**已属于某面缝合好的旗**，同样的右键会转而打开**旗帜编辑器**。这个工具既是建造者也是钥匙。

缝合工具有 50 次使用次数。

缝合完成后，结构会获得一个存储旗帜数据的控制器。请注意该控制器方块实体挂在**旗布**上，而非某个独立的机器方块——不存在需要放置或寻找的单独控制器方块。

## 旗帜编辑器

这个编辑器比横幅的更丰富：

| 控件 | 用途 |
|:---|:---|
| 名称 | 旗帜名称 |
| 旗帜文字 | 显示的文字 |
| 字体 | 在已注册字体中选择 |
| 颜色 | 文字颜色 |
| 对齐 | 左、中或右 |
| 预览 | 实时预览效果 |
| 重载字体 | 无需重启即可重新扫描字体 |
| 保存 | 提交修改 |
| 文本 / JSON | 在纯文本与原始组件 JSON 间切换 |

**JSON 模式是宽容的。** 若你输入的不是合法的组件 JSON，编辑器会提示你，并继续使用上一个有效版本，而不会清空旗帜或崩溃。你可以放心试验而不丢失成果。

**「重载字体」之所以存在**，是因为模组自行构建字体图集，而不只依赖原版字体。若你在游戏运行中添加了字体，这个按钮能让它生效。

## 旗帜与横幅的取舍

两者都显示带样式的文字，因此真正重要的是实际差异：

| | 街头横幅 | 旗帜 |
|:---|:---|:---|
| 构成 | 单个物品，作为实体放置 | 用方块搭出的矩形 |
| 可合成 | 是 | **否** |
| 放置方式 | 在两个锚点间点三次右键 | 先搭建，再缝合 |
| 编辑器 | 颜色、文字、缩放、对齐 | 以上全部，另加名称、字体、预览、JSON 模式 |
| 持久化 | 实体 | 带存档数据的方块结构 |

想在墙上快速立个牌子就用横幅；想要大面积、可控字体的表面，且你能拿到部件，就用旗帜。
