# Good to Know

## One config option: Sage resurrection is off by default

The whole config is a single switch:

| Option | Default |
|:---|:---|
| **Sage resurrection** | **Off** |

::: tip
If you want Sage's resurrect ability available, turn `sage_resurrection` on in the config. It ships disabled, so do not assume the mod is broken when you cannot find it in game — **it is switched off until you enable it.**
:::

## ⚠️ On a Chinese client, one hint and some subtitles are untranslated

::: warning
**Eleven strings are missing from Chinese**, and two of them matter:

- **The barrier rotation hint** — the line telling you how to rotate Sage's wall shows raw text instead of instructions. That one is worth knowing before your first fight.
- **Ten sound subtitles** across Sage, Phoenix, Clove and Jett, if you play with subtitles on.

Everything else — every item name, screen and message — is fully translated. The mod runs perfectly; these are display gaps only.
:::

## The creative tab reads "Example Mod Tab" on English clients

The tab's English name was never changed from the development template, so **English players see the placeholder name** while Chinese players correctly see 无畏契约.

The items inside are named properly either way — only the tab label itself is affected.

## Where the ability icons went

You may notice the skill bar has no icons. The mod actually ships **twenty icon images for the abilities**, but they were never wired up, so they sit unused inside the jar.

Nothing you can do in game changes this; it is purely a missing connection on the author's side.

## It needs exactly Minecraft 26.1.2

The mod accepts **one version only**. Any other 26.x build refuses to load it.
