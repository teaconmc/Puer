# Valorant

This mod brings **five VALORANT agents' abilities** into Minecraft as usable items, driven by a dedicated skill bar with its own keybinds. Twenty abilities, forty voice and effect sounds, and a set of custom screens.

## Read this first

**Every ability is creative-only and single-use.** The mod ships **no data pack at all** — no recipes, no loot tables, no tags — so nothing can be crafted or obtained in survival, and most abilities **consume the item when used**. Treat it as a creative or minigame toolkit, not a progression mod.

**One ability is disabled by default.** Sage's Resurrection is behind a config switch that ships **off**. See [05 Good to know](05_technical_notes).
