# 开始使用

## 技能从哪里来

只有一个来源：创造模式物品栏。模组**不附带配方、战利品表与标签**，因此任何技能物品都没有生存获取途径。

分类位于战斗分类之前。请注意它的名字可能出乎你意料：

::: warning
**英文分类名仍是模板占位文本。** 它在英文下显示为 **"Example Mod Tab"**，因为那条翻译值从未被替换。中文下则正确显示为「无畏契约」。

该分类的内部注册名也是 `example_tab`，因此完整 ID 是 `valorant:example_tab`。两者都只影响外观，但英文玩家去找名为「Valorant」的分类是找不到的。
:::

## 技能是消耗品

这是决定其余一切的平衡设计：**使用技能会消耗物品**。

虚缈、逢春、凌空、逐风、飓刃与整蛊在使用时都会从堆中减去一个。飓刃在创造模式下跳过消耗，并且还有真正的冷却——见 [04 特殊机制](04_special_mechanics)。

再加上没有任何配方，这意味着**每个技能都是有限资源，用完必须回创造菜单再拿**。请多带几叠。

## 你需要的按键

模组注册了自己的按键分类 **VALORANT**，共六个绑定：

| 按键 | 动作 |
|:---|:---|
| **G** | 打开技能栏界面 |
| **Z** | 使用技能槽 1 |
| **X** | 使用技能槽 2 |
| **V** | 使用技能槽 3 |
| **B** | 使用技能槽 4 |
| **C** | 旋转贤者屏障的方向 |

Z / X / V / B 对应无畏契约本身的技能布局，因此肌肉记忆可以直接迁移。六个绑定都可在「按键控制」中重设。

## 最初五分钟

1. 打开创造模式，找到**战斗分类之前**的那个分类（英文下名为 "Example Mod Tab"）。
2. 拿几个同一名英雄的四个技能——贤者或捷风是最平缓的起点。
3. 按 **G** 打开技能栏并把它们分配到槽位。
4. 按 **Z / X / V / B** 使用。

有些技能在按键之后还需要第二个动作——贤者的屏障要等一次点击来放置，幻萦的整蛊会打开一张地图。这些在 [04 特殊机制](04_special_mechanics) 中说明。

## 这里没有什么

明确说清，因为模组的名字容易引发过高期待：

- **没有枪械、没有射击、没有经济系统、没有回合。** 只有技能。
- **没有英雄实体或模型**——你不会变成某位英雄，你只是以物品形式携带他们的技能。
- **没有成就、没有命令、没有权限门槛。** 任何拿到物品的人都能使用一切。

技能集本身确实有深度——二十个技能配四十段专属音效——但它是加装在普通 Minecraft 上的工具箱，而不是一个游戏模式。
