# 技能一览

二十个技能，每名英雄四个。下面的表格描述的是实现与其音效阶段所确立的内容；源码未明确固定的具体数值不予陈述。

## 雷兹

四种爆炸物，也是模组中开发得最完整的英雄——每一个都有完整的音效循环。

| 技能 | 物品 ID | 行为 |
|:---|:---|:---|
| 彩雷飞溅 | `leizhibomb_item` | 投掷手雷；**先蜂鸣、再爆炸** |
| 惊喜翻腾 | `blastpack_item` | 投掷式炸药，会**粘在落点**、发出嗡鸣、随后爆炸 |
| 花车巡游 | `boombot_item` | 部署式机器人，会**自行移动**，随后爆炸 |
| 晚安烟火 | `bigbomb_item` | 发射型弹体；终极技能，爆炸范围最大 |

惊喜翻腾会粘附而不是弹开，这是实战中最要紧的细节：你可以把它贴在墙上或天花板上，它会留在那里。

::: warning
**雷兹的命名不一致，读文件时会把你搞混。** 内部名是 **`leizhi`**——音效目录是 `sounds/leizhi/`、物品是 `leizhibomb_item`、字幕键是 `subtitles.valorant.leizhi.*`。

与此同时，音效字幕使用官方英文名（"Raze throws Paint Shells"），但**物品显示名用的是内部名**：`leizhibomb_item` 显示为 **"Leizhi Bomb"**、`bigbomb_item` 显示为 **"BigBomb"**，而不是 "Paint Shells" 与 "Showstopper"。

因此同一个技能会因你读的是物品还是字幕而有两个不同的名字。资源包作者必须使用 `leizhi`。
:::

## 贤者

| 技能 | 物品 ID | 行为 |
|:---|:---|:---|
| 逢春 | `sage_heal_item` | 治疗目标 |
| 玉城 | `sage_barrier_item` | 放置一道实体墙，一段时间后**消散**；有**两种朝向** |
| 薄冰 | `sage_slow_item` | 投掷；**炸开**成减速区域 |
| 再起 | `sage_resurrection_item` | 复活——**默认禁用** |

其中两个需要单独说明：屏障的朝向控制与复活的配置开关。两者都在 [04 特殊机制](04_special_mechanics)。

## 不死鸟

| 技能 | 物品 ID | 行为 |
|:---|:---|:---|
| 闪光曲球 | `phoenix_curveball_item` | 投掷闪光，**炸开**成强光 |
| 手感火热 | `phoenix_hot_hands_item` | 投掷火焰，燃烧一片区域 |
| 火冒三丈 | `phoenix_blaze_item` | 一道**持续存在、随后结束**的火墙——它有循环音效与明确的结束音 |
| 再火一回 | `phoenix_run_it_back_item` | 终极技能；自我复活 |

火冒三丈拥有「循环 + 结束」这一对音效，说明它是**持续型效果**而非瞬时效果，因此可以预期一道能依靠一段时间、然后失效的墙。

## 捷风

| 技能 | 物品 ID | 行为 |
|:---|:---|:---|
| 瞬云 | `jett_cloudburst_item` | 投掷烟雾 |
| 凌空 | `jett_updraft_item` | 把你向上弹起；**消耗物品** |
| 逐风 | `jett_tailwind_item` | 两段式——**就绪**，然后**冲刺**；消耗物品 |
| 飓刃 | `jett_blade_storm_item` | 投掷飞刀；**单发或全发**，且是唯一带真实冷却的技能 |

逐风的两段式很要紧：激活它是给冲刺上膛，冲刺本身是第二个事件。飓刃在 [04 特殊机制](04_special_mechanics) 中有进一步说明。

## 幻萦

机制上最不寻常的一名英雄——四个技能中有三个在做普通物品不会做的事。

| 技能 | 物品 ID | 行为 |
|:---|:---|:---|
| 整蛊 | `clove_ruse_item` | 打开一张**地图界面**；点击地图即可远程放置烟雾 |
| 虹吸 | `clove_meddle_item` | 投掷；先上膛（**就绪**），再**爆开**成衰减区域 |
| 逢春（幻萦） | `clove_pick_me_up_item` | 带一个**触发（proc）**——它由条件触发而非由使用触发 |
| 化蝶 | `clove_not_dead_yet_item` | **仅能从死亡界面**使用 |

整蛊与化蝶都在 [04 特殊机制](04_special_mechanics) 中完整说明。

| 使用即消耗 | 说明 |
|:---|:---|
| 幻萦 虹吸 | |
| 幻萦 逢春 | |
| 幻萦 整蛊 | 从物品栏任意位置取用 |
| 捷风 凌空 | |

其余技能未被确认为会消耗，因此不要假定一叠能一直用——请针对你打算依赖的那个技能实测。

## 音效设计是真正的强项

每名英雄都有自己的音效目录——**五名合计四十个文件**——而模组为它们全部注册了规范的字幕键，包括为手雷的*蜂鸣*、*爆炸*与*粘附*阶段各自设条目。飓刃甚至有三个随机投掷音。

这是模组中最精致的部分，值得把字幕打开来看技能状态随施放被逐一命名。请注意**其中十条字幕在中文翻译中缺失**——见[05 须知](05_technical_notes)。
