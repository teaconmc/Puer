# 设备方块

## 目录

16 个功能设备石加 1 个参考范例。**包名**就是文言脚本用来寻址该设备的名字。

| 方块 ID | 名称 | 包名 | 用途（取自其提示文本） |
|:---|:---|:---|:---|
| `projectile_spawner_block` | 投射石 | `「投射」` | 發射投射實體 |
| `elemental_block` | 元素石 | `「元素」` | 調用元素 |
| `world_interaction_block` | 交感石 | `「交感」` | 與世界進行交互 |
| `entity_manipulation_block` | 移形石 | `「移形」` | 移動附近實體 |
| `note_block_function_block` | 音符石 | `「奏」` | 操控音符聲響 |
| `read_write_block` | 符咒讀寫石 | `「讀寫」` | 讀寫手持物品 |
| `naming_block` | 命名石 | `「命名」` | 命名目標物件 |
| `particle_block` | 微塵石 | `「塵」` | 生成粒子效果 |
| `dye_block` | 染色石 | `「染」` | 對目標進行染色 |
| `marker_block` | 標記石 | `「标」` | 標記位置資料 |
| `entity_status_block` | 實體狀態石 | `「愈」` | 修改實體狀態 |
| `entity_spawn_block` | 實體召喚石 | `「召」` | 召喚指定實體 |
| `potion_block` | 藥水石 | `「藥」` | 施加藥水效果 |
| `block_edit_block` | 天地土木石 | `「地」` | 修改方塊狀態 |
| `enchant_block` | 附靈石 | `「靈」` | 對物體進行附魔 |
| `storage_rune_block` | 符咒收納櫃 | `「納」` | 存储符咒数据 —— 见 [03 存储与数据](03_storage_and_data) |
| `example_block` | 範例石 | `「example」` | 仅作参考范例 |

16 个功能方块全部是普通简单方块，**强度 2.0**，音效按主题区分——多数为石头，音符石与符咒讀寫石为木头，命名石为铁砧，微塵石与藥水石为玻璃。地图颜色各不相同，便于放置后辨认：移形石、實體召喚石与微塵石为紫色，染色石与實體狀態石为红色，附靈石为黄色，藥水石为青色，標記石为浅灰，音符石与符咒讀寫石为木色，命名石为金属色。

只有符咒收納櫃拥有方块实体，其余 16 个自身不保存任何状态。

## 方块形态与物品形态不是同一批

设备的能力被注册了两遍——一遍针对放置的方块，一遍针对携带的物品——而**两份名单并不一致**。

| 包名 | 作为放置方块 | 作为携带物品 |
|:---|:--:|:--:|
| `「投射」` `「元素」` `「交感」` `「讀寫」` `「命名」` `「移形」` `「奏」` `「塵」` `「愈」` `「召」` `「藥」` `「地」` `「靈」` `「标」` | ✔ | ✔ |
| **`「納」`**（符咒收納櫃） | ✔ | **–** |
| **`「染」`**（染色石） | ✔ | **–** |

也就是说 14 个设备两种方式都能用，但**符咒收納櫃与染色石只支持方块形态**。把它们放在物品栏里并不会向脚本暴露其包名——必须放置出来。

## 標記石的包名用的是简体字

其余每个包名都使用与方块名一致的繁体形式——`讀寫`、`靈`、`納`、`藥`、`實體`。標記石打破了这个规律：它的方块名是**標記石**（繁体「標」），但包名注册为 **`「标」`**（简体「标」）。

脚本必须使用简体形式。这是一处内部不一致，无法绕过——请写 `「标」`。

## 範例石是代码示例，而且它同时挂在基岩上

`example_block` 的存在是为了向附属作者展示能力注册的写法。它的处理器包名字面就是 `「example」`，其唯一处理器只往日志里写一句 "example" 然后返回空值。源码在该方块处附有注释，要求读者绝不要修改它。

更令人意外的是：同一份范例注册被挂到了**两个**方块上——`wenyan_addon:example_block` **与原版 `minecraft:bedrock`**。因此世界中任何基岩也会向文言脚本暴露 `「example」` 包。

这几乎肯定是在演示「你可以把设备能力挂到不属于自己的方块上」，而不是有意的玩法设计；但它确实是生效的行为：**在本附属中基岩是一个文言设备**。请不要依赖它——它正是 README 警告过「可能更改或消失」的那类东西。

## 实用提示

- 放置没有朝向，也没有需要管理的方块状态；设备只有「在」与「不在」两种情况。
- 由于多数设备也能作为物品使用，紧凑的脚本布置可以把它们放在物品栏里而不必盖一间机器房——但那两个仅限方块的除外。
- 这里没有任何东西消耗耐久、能量或燃料；所有设备都没有磨损机制。
