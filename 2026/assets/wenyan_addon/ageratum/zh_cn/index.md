# 吾有一術：新秩序（Wenyan Addon）

「吾有一術：新秩序」是 WenyanTeam 的 TeaCon 2026 参赛作品，模组 ID `wenyan_addon`，组 ID `org.wenyan.wenyan_addon`，版本 `1.0.0`，采用 **MIT** 许可，面向 Minecraft 26.1.2 / NeoForge 26.1.2.71，需要 Java 25。其游戏内创造分页就名为 **吾有一術：新秩序**。

## 它无法独立运行

这是一个**附属模组，不是独立模组**。其元数据声明 **`wenyan_programming` `[1.0.0,)` 为必需依赖**——即「文言编程」模组（WenyanNature），一个让你用文言文给 Minecraft 编程的模组。没有它，游戏根本不会加载。

`middle_key_ping` 被声明为**可选**依赖。

## 它到底是什么

项目 README 对自身定位说得异常直白，本文档也照此表述：

> 本附属是新功能的试验场，可能包含不稳定代码。功能之后可能被并入核心模组，也可能在任何时候被移除或更改。

它明确警告 **API、玩法细节、数据格式与存档兼容性都可能在版本之间破坏**。请把这里的一切都视为实验性内容。

## 一个模组，两套内容

尽管只有一个模组条目，这个 jar 却输出了**两个资源命名空间**：

| 命名空间 | 内容 |
|:---|:---|
| `wenyan_addon` | 17 个设备方块与数据磁盘 —— 真正的文言集成部分 |
| `pong` | 一套自成体系的香槟模块：酒瓶、军刀、酒杯、瓶塞、酒架，外加一种流体与醉酒效果 |

`pong` 没有自己的模组条目——它是由同一个模组容器注册的第二命名空间，其物品出现在 `wenyan_addon` 的创造分页里。

## 注册了什么

| 注册表 | `wenyan_addon` | `pong` |
|:---|:---|:---|
| 方块 | 17 | 3 |
| 物品 | 17 个方块物品 + `data_disk` | 5 |
| 方块实体 | 1（`storage_rune_block`） | 1（`champagne_rack`） |
| 创造分页 | 1（两套内容共用） | — |
| 状态效果 | — | 1（`drunk`） |
| 流体 / 流体类型 | — | 2 流体 + 1 类型 |
| 实体 | — | 1（`plug`） |
| 粒子 / 声音 | — | 1 / 1（已注册） |
| 配方 | **无** | 5 |
| 战利品表 | 17 | — |
| 命令 / 配置 / Mixin | **无** | **无** |

请注意这处不对称：**17 个设备方块与数据磁盘完全没有合成配方**，而每个 `pong` 物品都有。
