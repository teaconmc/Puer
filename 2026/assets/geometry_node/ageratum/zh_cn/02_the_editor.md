# 编辑器

编辑器是一个 ModernUI 界面，用 **G** 打开。它是一块常规的节点画布，而其功能完整度超过多数 Minecraft 脚本类模组。

## 构成要素

| 元素 | 是什么 |
|:---|:---|
| 节点 | 一次操作，带输入与输出**端口** |
| 连接 | 两个端口之间的连线 |
| 转接点 | 用于把连线走得整齐的中转点 |
| 框 | 画在节点周围的带标签方框，用于整理 |
| 节点组 | 折叠成单个节点的子图 |

## 节点组才是硬功能

框是装饰性的——它把节点框在一起并带一个标签。**节点组是结构性的**：它把一组选中的节点折进一个可复用的节点，并用**虚拟端口**代表那些跨越组边界的连接。

你可以添加与移除这些虚拟端口、重命名它们，并在组节点上设置属性。**解散**一个组会把它重新展开并恢复原有连线。

从实现中可以看出这有多核心的两点观察：成组与解散以很大差距是**代码库中最大的两个编辑器操作**，而且它们是唯一需要跨边界重建连接的操作。若编辑器里有什么会出现意外行为，这里是首先该看的地方。

## 一切都可撤销

画布上的每一次改动都经过一个命令对象，共有**二十二个**：

| 分组 | 操作 |
|:---|:---|
| 节点 | 添加、移除、移动、设置位置、粘贴 |
| 连接 | 连接、断开、在连接上插入转接点 |
| 分支 | 添加分支、移除分支 |
| 框 | 添加、移除、成框、设置属性 |
| 节点组 | 成组、解散、添加/移除虚拟端口、重命名端口、设置属性 |
| 数值 | 修改输入值 |
| 层级 | 更改父级 |

由于每一项都是离散命令而不是直接改写状态，整个编辑器统一支持撤销与重做——包括复杂的成组与解散操作。

**在连接上插入转接点**值得单独了解：你不需要删掉一条线再画两条新的，而是把转接点丢到已有连接上，它会就地一分为二。

## 端口带类型

端口是有类型的，而模组为端口准备的翻译键数量仅次于节点——英文 78 条，另有 53 条只存在于中文。类型包括数值、向量、颜色、实体、容器与世界引用。

连接不兼容的端口会被拒绝，这也是连接操作体量较大的原因：它在连线之前先校验。

## 资源浏览器

编辑器内含一个资源浏览器，带可配置的**快速访问路径**——指向磁盘上存放你的图的文件夹的快捷方式。图是文件，因此你可以把草稿留在本地并用文件夹整理。

::: warning
随包配置中的快速访问路径是**原作者本人的文件夹**，其中包含一条指向其 IDE 工程目录的绝对路径，以及 `C:\`、`D:\`、`E:\`。在你的机器上第一条指向的是不存在的位置。

请把它们替换成你自己的路径——见 [05 技术说明](05_technical_notes)。
:::

## 外观设置

有两个装饰性数值是可配置而非硬编码的：画布**网格尺寸**（默认 15）与节点方框的**圆角半径**（默认 1.5）。两者与快速访问路径位于同一份 JSON 配置中。

## 远程图

编辑器并不限于本地文件。模组附带用于**从服务器列出并下载图**的网络数据包，以及配套命令——因此服务器可以托管一个图库，供玩家拉取到自己的编辑器中。见 [04 让图在世界中运行](04_graphs_in_the_world)。
