# 几何节点

几何节点是一套面向 Minecraft 的**可视化脚本系统**。它不添加物品、方块或生物——而是给你一个节点图编辑器、一份约 **295 种节点**的目录，以及把你搭好的图挂到世界上的手段。

如果你用过 Blender 或某个游戏引擎里的节点编辑器，这个模型会很熟悉：把节点拖到画布上、把它们的端口连起来、成组，图就会运行。

## 请先读这一条

::: warning
**英文翻译只覆盖了模组的约四分之一。** 语言文件中有 **138 个英文键对 543 个中文键**，而差额几乎全是**节点名称与说明**——其中 275 条只存在于中文。

由于节点目录*就是*这个模组的内容，英文客户端会在本应显示节点名的位置显示原始翻译键。**在当前状态下，本模组在中文环境可用，在英文环境则大面积无标签。** 见 [05 技术说明](05_technical_notes)。
:::

**需要另外两个模组**，且两者都已正确声明：**ModernUI**（仅客户端——整个编辑器由它绘制）与 **Architectury**。

## 快速说明

| 项目 | 值 |
|:---|:---|
| 模组 ID | `geometry_node` |
| 版本 | 1.0.0 |
| 许可证 | **保留所有权利（All Rights Reserved）** |
| 必需依赖 | **ModernUI**（客户端）、**Architectury** |
| 节点种类 | 约 295 |
| 物品 / 方块 / 实体 | **均无** |
| Minecraft | `[26.1.2]`——单一精确版本 |

约五万行的体量使它以很大差距成为本区间最大的模组，而这份重量几乎全部来自节点目录。

## 你能用它做什么

| 领域 | 能力举例 |
|:---|:---|
| 事件 | 响应玩家、实体、方块、物品、物品栏或世界事件 |
| 动作 | 移动、伤害、生成、给予、放置、展示——共 111 个动作节点 |
| 数据 | 读取实体属性、容器、数值、类型 |
| 逻辑与数学 | 分支、比较、向量与颜色运算 |
| 对话 | 搭建分支会话 |
| 商店 | 定义交易条目 |

## 本文档的覆盖范围

这个模组大到逐个记录每个节点会写成数百页。因此这些页面覆盖的是**框架、编辑器与目录结构**——每个类别及其规模——而不是逐一说明每个节点的端口。

若某个子系统的行为无法从名字猜出（对话、蓝图、商店编辑器），它会获得独立章节。
