# 开始使用

## 依赖

需要另外两个模组，且两者都已在元数据中正确声明：

| 模组 | 侧 | 用途 |
|:---|:---|:---|
| **ModernUI** | **仅客户端** | 绘制整个节点编辑器 |
| **Architectury** | 双侧 | 平台抽象层 |
| NeoForge、Minecraft | 双侧 | |

ModernUI 仅限客户端这一点透露了有用的信息：**编辑器是一个客户端程序**。专用服务器会运行图，但从不需要编辑界面。

Minecraft 范围是**单一精确版本** `[26.1.2]`，因此其他任何 26.x 都不会加载。

## 创造模式里什么都找不到

模组**不注册物品、方块、实体，也不注册创造分类**。在创造菜单里搜索任何名为「GeometryNode」的东西都不会有结果，而这是正确行为，不是安装损坏。

它向游戏注册的唯一东西是一个内部附着类型。你所交互的一切都是界面。

## 打开编辑器

按 **G**。

这是模组唯一有默认绑定的按键，位于它自己的按键分类中。它会以完整的 ModernUI 界面打开节点编辑器。

## 十个蓝图按键默认未绑定

除编辑器按键之外，模组还在第二个分类中注册了**十个「蓝图技能」按键**——而**每一个出厂时都没有默认绑定**。

这是有意为之而非损坏，但它带来一个值得直说的后果：**开箱状态下没有任何按键能运行一张图。** 在你去「按键控制」里分配之前，蓝图只能由其图所监听的事件触发。

若你打算把图当作主动技能使用，绑定这十个按键是你必须自己完成的一步设置。

## 关于英文文本

::: warning
大多数节点名称没有英文翻译。模组附带 **138 个英文键对 543 个中文键**，而缺失的部分绝大多数正是节点目录本身——275 条节点条目只存在于中文。

实际表现是英文客户端会在节点浏览器中显示形如 `geometry_node.node.…` 的原始键。编辑器能用、图能跑，但**你将靠位置与形状而不是靠名字来选择节点**。

如果你能读中文名，把游戏语言切到简体中文会让本模组好用得多。这是当前构建最重要的一条可用性事实。
:::

## 一次现实的首次上手

1. 与模组一同安装 ModernUI 与 Architectury。
2. 按 **G** 打开编辑器。
3. 添加一个**事件**节点——某个会触发的东西，例如一个玩家事件。
4. 添加一个**动作**节点，把事件的输出连到它上面。
5. 保存该图，然后绑定它或把它挂到世界上——见 [04 让图在世界中运行](04_graphs_in_the_world)。

目录是按类别而非字母顺序组织的，这在名字不可读时帮助很大。[03 节点目录](03_node_catalogue) 列出了每个类别及其规模，好让你知道该往哪里找。
