# Roads

Roads is currently a Road Builder rendering prototype, not a completed road system. This guide follows the current registries and implementation of `roads` 1.0.0.

## Reading Order

- [Road Builder Prototype](01_road_builder_prototype): obtaining the block, placement facing, and orange spline curves.
- [Current Limits and Project Status](02_current_limits_and_project_status): unavailable interactions, survival progression, and placeholder resources.

## Available Content

The mod registers only one Road Builder block, its block item, and a block entity with the same ID. Placing it displays four orange curves built from random control points, providing a test of the curve algorithm and block entity renderer.

::: warning
"Build roads!" is the project goal, not a claim that this version lays roads. The current block has no GUI, interaction tool, road blocks, generated collision, or control-point editor.
:::
