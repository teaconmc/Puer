# 当前限制与项目状态

## 尚未实现

当前源码没有以下玩家功能：

- 道路建造机 GUI 或右键操作。
- 选择、拖动、连接或删除控制点的工具。
- 实际道路、路基、路口、路面碰撞或车辆。
- 与 x3d Map 联动的规划界面。
- 道路相关命令、按键或有效配置项。
- 生存配方、战利品或自然生成。

项目的 `plan.md` 描述了打包机、多方块、道路与地图规划等设想，但这些条目仍标记为未完成，不能作为当前玩法说明。

## 注册表边界

生成资源中还残留 `example_item` 和 `example_block` 的语言、模型及方块状态文件，但 Java 注册表没有注册它们。不要尝试用命令获取这些 ID，也不要据此制作配方或文档绑定。

配置类目前构建的是空配置规范。虽然客户端能打开通用配置屏幕，但里面没有 Roads 可调整的实际选项。

## 显示与语言问题

英文语言文件把创造分页标题写成了 “Example Mod Tab”，这是占位翻译；它不表示存在另一个示例模组。中文生成语言把该分页显示为 Roads。

::: warning
道路建造机适合用于观察当前曲线渲染实验，不适合生存服道路建设。保存重要世界前，不要把计划中的控制、碰撞或掉落行为当成已实现功能。
:::
