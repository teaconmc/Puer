# Roads

Roads 当前是一个道路建造机渲染原型，而不是已经完成的道路系统。本套文档依据 `roads` 1.0.0 的当前注册表和实现编写。

## 阅读路线

- [道路建造机原型](01_road_builder_prototype)：获取方块、放置方向与橙色样条曲线。
- [当前限制与项目状态](02_current_limits_and_project_status)：尚未实现的操作、生存流程和占位资源。

## 当前可用内容

模组只注册一个道路建造机方块、对应方块物品和一个同 ID 的方块实体。放置后会显示随机生成的控制点所形成的四段橙色曲线，用于验证曲线算法与方块实体渲染。

::: warning
“Build roads!” 是项目目标，不代表当前版本会铺设道路。现有方块没有 GUI、交互工具、道路方块、碰撞生成或控制点编辑功能。
:::
