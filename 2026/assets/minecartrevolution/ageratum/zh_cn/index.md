# MinecartRevolution（矿车革命）

MinecartRevolution（模组 ID `minecartrevolution`，版本 1.0.0）——「更多矿车，更多乐趣！」——新增一大批矿车变体，并带有一个把方块与物品转变成可用矿车的转变系统。由 Ryan100C、Liuyue_awa、Mulatram_UwU 与 Yakon0705 开发（MIT 许可），目标环境为 Minecraft 26.1.2 / NeoForge（`26.1.2.75`）。

## 模组内容

- **扳手与转变** —— `minecartrevolution:wrench` 结合 `@MinecartMapper` / `MinecartTransformManager` 提供方块到矿车的转变流水线，并可配置矿车行为。
- **丰富的矿车目录** —— 容器矿车（木桶、箱子、铜箱、陷阱箱、潜影盒、末影箱、发射器）、工作台矿车（铁砧、信标、附魔台、工作台、锻造台、切石机、织布机、制图台、砂轮、唱片机）、流体矿车（水、岩浆、传送门）、红石矿车（红石块、中继器、压力板、活塞）等，各有对应的 `minecart_<方块>` 物品。
- **矿车链** —— 用链条（`MinecartChainManager`、`chain` 实体）把矿车连成一列，牵引整支车队。
- **实用与趣味** —— 磁铁（磁石）、拾取、沙发、羊毛、脚手架、生物头颅、门/活板门矿车，以及信标矿车、传送门矿车等特殊类型。
