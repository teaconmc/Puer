# Configuration and compatibility

## Configuration

The mod registers a COMMON config (`Config.SPEC`). Linked containers persist per server via `LinkedContainerManager` (saved on level save, loaded on server started).

## Networking

Payloads are registered through a `PayloadRegistrar` under the `minecartrevolution` channel: `JukeboxUpdateS2CPacket`, `BabelScramblePacket`, `EnderPortalShakePacket`, `MinecartCollisionPacket` (client) and `ForceCompatRegisterPacket` (server). The server keeps a `FORCE_COMAPTERS` list of players who opted into force-compat mode (managed by the force-compat register packet).

## Datagen

Advancements are generated by `MRAdvancementProvider`; recipes by `MRRecipeProvider` (both client and server `GatherDataEvent` runners). There is an `access transformer` (`META-INF/accesstransformer.cfg`) and a mixin config.

## Compatible rendering

`CompatFriendlyBlockMinecartEntity` / `CompatFriendlyBlockMinecartRenderer` are designed to render fine alongside other block-display mods, so carts stay consistent in mixed modpacks.
