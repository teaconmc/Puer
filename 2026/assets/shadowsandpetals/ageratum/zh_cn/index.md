# 织影落花（Shadows And Petals）

为 Minecraft 26.1.2 的 NeoForge 模组，带来一套日式和风庭院与室内装潢工具。将石头塑造成多方块石山、把沙砾耙成枯山水砂纹、用三种自定义木材搭建居所，并用炉、灯具、风铃、铜茶壶等装点房间。

## 阅读路线

- [快速开始](01_getting_started) — 雕刻你的第一座石山、耙出第一片砂纹，并开始建造。

## 快速说明

| 类别 | 内容 |
|:---|:---|
| 模组 ID | `shadowsandpetals`（织影落花） |
| 创造标签 | `织影落花`（主）、`织影落花：自然`、`织影落花：农业` |
| 工具 | `hammer`（锤子：将石头雕刻为石山）、`chisel`（凿子：副手持雕刻辅助）、`harrow`（耙子：将沙砾耙成砂纹） |
| 材料 | `bauxite_ore` / `deepslate_bauxite_ore` 铝矿、`raw_bauxite` 粗矾土、`aluminum_ingot` 铝锭、`aluminum_block` 铝块、锭堆 |
| 木材组 | 樱花木、枫木、银杏木——各含原木、木板、木柱、楼梯、台阶、栅栏、树苗、树叶与树篱 |
| 庭院方块 | `rockery` 石山、`samon` 砂纹、`shishi_odoshi` 竹鸣（添水）、`orange_tree` 蜜柑树 |
| 居所陈设 | `irori` 炉（带容器界面）、灯具、`wind_chime` 风铃、`copper_teapot` 铜茶壶、座位 |
| 实体 / 菜单 | `seat`（隐形坐椅实体）/ `irori` 炉菜单 |
