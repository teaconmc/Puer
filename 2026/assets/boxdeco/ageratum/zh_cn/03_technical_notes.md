# 须知

## ⚠️ 破坏栏杆就会让它消失

::: danger
**玻璃栏杆无法合成，破坏时也不会掉落自身。**

这个模组只有一个方块——装饰性玻璃栏杆——来自创造分页或 `/give`。一旦放下，**挖它什么都不会返还**，所以你拆掉的每一节栏杆都永远消失了。

**放置前想清楚，或在创造模式里备好余量。** 如果你在装饰一座大型建筑，请不要把已放置的栏杆当作可回收的。
:::

## 栏杆的手感像普通石头，不像玻璃

这个方块没有配置任何特殊材质属性，因此：

| 行为 | 预期 |
|:---|:---|
| 挖掘速度 | 与普通石头相同，而不是像玻璃那样快 |
| 偏好工具 | 没有任何工具被特别优待 |
| 爆炸抗性 | 普通值，而非玻璃类 |
| 踩上去的声音 | 通用方块声，而非玻璃声 |

它的**外观**是对的，光线也会按细长形状正确穿透、不会投出整块方块的阴影。只有物理手感与外观给人的预期不同。

## 材质包会改变它的玻璃部分

栏杆的玻璃面板复用的是**原版浅灰色染色玻璃**贴图；只有金属框是模组自己的图片。

::: info
**所以换了浅灰染色玻璃贴图的材质包，也会同时改变你的栏杆。** 这可以是优点——自动匹配你的材质包——也可能是在你没料到的地方出现的变化。
:::

## 中文客户端看到的是英文名

模组没有中文翻译。由于英文是回退语言，中文客户端会显示「BoxDeco」与「Glass Railing」这两个可读的英文词，而不是原始内部文本。

任何语言下功能都正常；只是除了这两个名字之外没有翻译。

## 里面真的只有这些

这个模组确实只有一个方块，再无其他：

- 该方块没有合成配方
- 没有实体，除栏杆本身外没有任何物品
- 没有可用的配置选项（设置界面能打开但是空的）
- 没有命令

如果你在寻找更多装饰件，当前构建里就只有这一套。
