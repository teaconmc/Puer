# Blocks and modules

## Core blocks

- **`crafting_block`** — a crafting machine (with `crafting_block` entity).
- **`pedestal`** — a display/base block (`pedestal` entity).
- **`writing_block`** — write scripts onto paper (`writing_block` entity).
- **`logic_furnace`** — a "furnace" that runs logic (`logic_furnace` entity).
- **`power_block`** / **`creative_power_block`** — power sources (with block entities).
- **`cloud_beacon`** — a beacon-like block (`cloud_beacon` entity).
- **`float_note`** — a floating note item.

## Additional module blocks

- **`formation_core`** — formation core module.
- **`lock`** — lock module.
- **`screen`** — screen module.

## Built-in module blocks

Bit/logic, math, vec3, random, string, collection, item, block, entity, world/information, explosion, blocking queue, and piston modules (plus a decorative piston head). Together they let a running program compute, store, and affect blocks, entities and the world.
