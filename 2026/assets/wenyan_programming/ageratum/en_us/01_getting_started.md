# Getting started

Wenyan Programming lets you write **文言 (classical Chinese)** programs and run them in Minecraft. All content sits in the **`wenyan_programming`** creative tab (icon: the RUNNER_0 hand runner).

## Runners

- **Hand runner** (`RunnerItem`) — a tiered item you hold to run a program.
- **Thrown runner** (`ThrowRunnerItem`) — a throwable runner; thrown programs travel as the `throw_runner` entity (0.25×0.25, MISC, tracking 4, update interval 10).
- **Block runner** (`RunnerBlock`, with `RunnerBlockEntity`) — a placed block that runs a program, tiered like the items.

## Paper and ink

Programs are written onto paper:

- **Paper** — `bamboo_paper`, `cloud_paper`, `starlight_paper`, `frost_paper`, `phoenix_paper`, `dragon_paper`.
- **Ink** — `bamboo_ink`, `cinnabar_ink`, `starlight_ink`, `lunar_ink`, `celestial_ink`, `arcane_ink`.

Higher-tier paper and ink unlock more advanced script and spellwork.

## First steps

1. Write a 文言 program on paper.
2. Choose a runner and load the program into it.
3. Run it and watch it act on the world.
