# 吾有一術（Wenyan Programming）

Wenyan Programming（模组 ID `wenyan_programming`，版本 `1.0.1`）由 indi.wenyan（GNU LGPLv3）开发，让你用**文言文**在 Minecraft 中编写程序。它内置文言编译器与运行时（`judou`，jarJar 打包），配合 Minecraft 解释器把文言程序变成世界中的魔法——用手持、投掷或方块**执行器**运行。

## 模组内容

- **执行器** —— 手持执行器（`RunnerItem`）、投掷执行器（`ThrowRunnerItem`，含 `throw_runner` 实体）与方块执行器（`RunnerBlock`，tier 化 `RUNNER_0` 起），都在 `wenyan_programming` 创造页。
- **纸与墨** —— `bamboo_paper`、`cloud_paper`、`starlight_paper`、`frost_paper`、`phoenix_paper`、`dragon_paper`；`bamboo_ink`、`cinnabar_ink`、`starlight_ink`、`lunar_ink`、`celestial_ink`、`arcane_ink`。
- **核心方块** —— `crafting_block`、`pedestal`、`writing_block`、`logic_furnace`、`power_block`、`creative_power_block`、`cloud_beacon`、`float_note`、`throw_module`。
- **模块** —— 附加模块方块（`formation_core`、`lock`、`screen`）与内建模块：位/逻辑、数学、vec3、随机、字符串、集合、物品、方块、实体、世界、爆炸、阻塞队列与活塞。
- **编译器与配方** —— 文言编译器/运行时、配方问答系统、村民交易、配置与数据生成。
