# 推流、平台与须知

## ⚠️ 向 OBS 推流只在 Windows 上可用

::: danger
**视频输出功能仅存在于 Windows。**

在 macOS 或 Linux 上模组正常运行，但**推流选项干脆不存在**——不会崩溃，也不会弹警告。如果你全部设置完毕却没有任何画面到达 OBS，**请先检查你的操作系统，再检查你的设置。**
:::

在 Windows 上还有一件事可能出错：模组每次启动都会往你的**临时文件夹**写一个小型辅助库。如果你的临时目录被锁定、或所在分区禁止执行代码，加载就会失败。把临时目录指到可写的位置即可解决。

## 仪表盘在一个固定地址

控制仪表盘是游戏内运行的一个小型网页服务器，地址为：

```
http://localhost:23512/
```

::: warning
**端口号无法更改** —— 没有对应的设置项。如果你机器上已有其他程序占用了 23512 端口，这个冲突需要在模组之外解决。

游戏启动时会在日志里和一条可点击的聊天消息中把这个地址告诉你。
:::

## 脚本在任何平台都能跑，包括不能推流的那些

模组的脚本部分使用纯 Java 引擎，因此自定义程序在**所有平台**上行为一致——包括没有 Windows 视频输出的 macOS 与 Linux。

所以以脚本为主的节目在任何系统上都能做；只有「镜头到 OBS」这一步被绑在 Windows 上。

## 两条消息的翻译有小瑕疵

两种语言都完整，但其中有两个细节不太对：倒计时消息的两个版本在一处技术格式上不一致，中文版结尾还有一个不成对的括号。

::: info
正常游玩中两者都不会造成问题。如果倒计时消息显示得有些奇怪，原因就在这里。
:::

## 它只装在客户端

这个模组永远不需要装在服务器上。把它装在做录制的那台客户端即可；服务器两边都不受影响。

## 没有更多可配置的东西

**没有物品、方块、命令与按键绑定** —— 仪表盘就是全部界面。如果你在找游戏内的设置界面，那里没有；一切都在那个网页地址上进行。

## 关于再分发

模组采用 **AGPL-3.0**——带网络条款的强著佐权许可，而本模组恰恰提供网络服务，正是该条款针对的场景。任何再分发或修改它的人，都应先弄清这意味着什么再打包。
