# Config and Accessibility

The mod has separate server and client configuration files. Server settings control connection solving, slide speeds and station behavior; client settings control camera feedback, safety reductions and projection image loading.

## Server config

| Key | Default | Range | Purpose |
|:---|:---|:---|:---|
| `maxConnectionLength` | `64.0` | `2.0` – `512.0` | Maximum solved pipe length in blocks. |
| `captureRadius` | `0.72` | `0.25` – `2.0` | Capture distance from the centerline. |
| `captureVerticalTolerance` | `1.15` | `0.25` – `3.0` | Capture foot-position vertical tolerance. |
| `initialSlideSpeed` | `0.18` | `0.03` – `1.25` | Initial slide speed in blocks/tick. |
| `normalMaxSpeed` | `0.90` | `0.05` – `3.0` | Normal pipe maximum speed. |
| `normalAcceleration` | `0.015` | `0.0` – `0.5` | Normal pipe acceleration. |
| `normalOverspeedDeceleration` | `0.12` | `0.0` – `1.0` | Normal pipe overspeed braking. |
| `accelerationAttributeAcceleration` | `0.14` | `0.0` – `1.0` | Acceleration attribute speed gain. |
| `highwayMaxSpeed` | `4.80` | `0.05` – `12.0` | Highway pipe maximum speed. |
| `highwayAcceleration` | `0.08` | `0.0` – `1.0` | Highway pipe acceleration. |
| `highwayOverspeedDeceleration` | `0.03` | `0.0` – `0.5` | Highway overspeed braking. |
| `branchChoiceMaxSpeed` | `0.22` | `0.03` – `2.0` | Speed cap at an unresolved branch choice. |
| `branchChoicePreviewDistance` | `24.0` | `4.0` – `96.0` | Distance before a branch where choices open. |
| `branchChoiceDeceleration` | `12.0` | `0.0` – `24.0` | Forced braking toward a branch choice. |
| `platformClaimRadius` | `64.0` | `8.0` – `512.0` | Platform claim range from the station. |
| `autoOutOfStationTransferRadius` | `64.0` | `0.0` – `512.0` | Auto same-dimension transfer radius. |
| `farOutOfStationTransferWarningDistance` | `128.0` | `16.0` – `4096.0` | Distance at which transfer confirmation appears. |
| `routePathfinderMaxVisitedNodes` | `16384` | `1024` – `262144` | Pathfinder budget per route section. |
| `stationSlowMaxSpeed` | `0.18` | `0.03` – `2.0` | Speed cap at station dwell. |
| `stationSlowDeceleration` | `0.45` | `0.0` – `4.0` | Forced braking into station dwell. |
| `maxStepDistance` | `6.0` | `0.05` – `16.0` | Maximum slide distance consumed per server tick. |

## Client config

| Key | Default | Purpose |
|:---|:---|:---|
| `shaderpackPipeRenderMode` | `PERFORMANCE` | Pipe renderer used with shaderpack integration; `NATIVE` matches shader effects more closely. |
| `enableSlideCameraFeedback` | `true` | Allows camera pitch/roll and upcoming-turn anticipation. |
| `reduceMotionSicknessRisk` | `false` | Disables camera roll, FOV pushes, fold distortion and strong first-person feedback; mechanics stay the same. |
| `reducePhotosensitivityRisk` | `false` | Removes pulsing brightness, full-bright glow, streak particles, fold flashes and strong highlights. |
| `enableProjectionNetworkImages` | `true` | Allows client-side downloads of projection image URLs. |
| `allowHttpProjectionNetworkImages` | `false` | Allows plain `http://` projection images; HTTPS is always preferred. |
| `projectionNetworkImageCacheSize` | `64` | Decoded image cache size. |
| `projectionNetworkImageMaxBytes` | `4 MiB` | Per-image download limit. |
| `projectionNetworkImageMaxPixels` | `2048 × 2048` | Per-image decoded size limit. |

The first slide opens a safety warning screen; enabling the two safety options writes to the client safety state file, while the client config keeps the permanent values.

## Rendering integration

The build includes optional integration sources for **Sodium**, **Iris** and **Distant Horizons**, gated by Gradle properties (`enable_sodium_integration`, `enable_iris_integration`, `enable_distanthorizons_integration`, all enabled by default). If pipe rendering is wrong with a shader pack, switch `shaderpackPipeRenderMode` to `NATIVE`.

## Current limitations

- No command registration exists in the current source.
- The mod registers no custom entities; sliding uses the player entity directly.
- Direct pipe connections cannot cross dimensions; use dimension fold anchors.
- `broken_anchor_cleaner` is a Creative-only cleanup item and has no recipe.
- `platform_claimer` is generated by the station editor, not crafted.
- The two attribute tools have no recipes; only the consumable coatings are craftable.
- The TODO list still contains cinematic perspective and launching/gliding/ejecting anchors. Those features are not implemented yet and are not documented as available.
