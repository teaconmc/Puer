# Stations and Platforms

A station groups a physical station block, a name, transfer links and the pipe platforms claimed near it. Platforms are the boarding points used by route layouts.

## Station block

Place the station block to create a station group:

<recipe id="superpipeslide:station_block"/>

The station block is a waterloggable, directional block. On placement, the mod names it using the placer's client language and automatically links it to nearby stations in the same dimension.

## Station editor

Right-click the station block to open the station editor. You can:

- Set the primary station name.
- Add one translated name for the alternate language.
- Save without a claimer, or **Save + Claimer** to receive a platform claimer bound to this station.
- Open the out-of-station transfer editor.

If the inventory is full when generating a claimer, the item drops nearby.

## Out-of-station transfers

Transfers connect two station groups so navigation can route between them:

- New stations automatically link same-dimension stations within `autoOutOfStationTransferRadius` (`64` blocks).
- You can add or remove manual links for any station in the editor.
- Same-dimension links farther than `farOutOfStationTransferWarningDistance` (`128` blocks) and cross-dimension links require explicit confirmation.
- The editor shows dimension, distance and estimated walk time for each link.

Cross-dimension transfers rely on your configured physical path (for example a dimension fold); navigation can only estimate and warn about them.

## Platform claimer

The platform claimer item is generated by the station editor and stores the bound station id and name:

- Right-click a pipe segment to claim it as one platform for the bound station.
- The segment midpoint must be within `platformClaimRadius` (`64` blocks) of the station block.
- Branch-managed connections cannot be claimed as platforms.
- Right-click the same platform again to unclaim it.

Claimed platforms get a platform number and length; use the platform editor later to rename them.

## Platform editor

The platform editor appears when a claimed platform is selected in the route editor or station flow. It edits the platform number and display name used by route layouts, maps and projectors.

Removing a station block deletes its station group, transfers and claimed platform stops together.
