# 杂交

## 杂交布局

把三个**作物架**排成一条直线：一个成熟作物架、中间一个空作物架、同一方向两格外再放一个成熟作物架。普通作物架成熟后，每个 tick 都会检查四个水平方向：

1. 隔一格的位置是**没有种子袋**的作物架（中间空位），
2. 隔两格的位置是另一个带有**成熟**种子袋的作物架。

两个条件都满足时，中间的空作物架会收到一个新的种子袋。如果两种已种种子是**不同物品**，杂交配方表可以加入新的产出；如果两者相同，中间空位仍会收到相同种子、属性重新滚动的种子袋。

## 基于配方的结果

杂交会查询 `harvestheritage:hyprid` 配方表（注册表中保留了这个拼写）。配方列出两种输入种子和一种或多种输出种子；实际产出会从该列表随机挑选。

- **常见作物配对**：每对内置作物种子都有一条 `common/` 配方，输出是所有其他作物种子。
- **怪物与材料配对**：固定配方把特定组合变成新种子，例如骨头 + 恶魂之泪 → 铁锭，鸡肉 + 甘蔗 → 粘液球，粘液球 + 紫颂果 → 末影珍珠，或甜浆果 + 青金石 → 红石。
- **葡萄**有种子定义和种子袋配方，但没有杂交配方，因此它仍能用于提升属性，除非数据包补充 `hyprid` 配方，否则不会解锁新产出。

JEI 会显示「杂交」分类，并把作物架作为催化物。

## 结果与属性

结果池是配方输出列表加上两个亲本。有 **20% 概率**结果只是两个亲本之一；否则从配方输出中随机选择（没有匹配配方时回退到亲本）。出现在中间空作物架里的种子袋会从两个亲本滚动**速度**与**产出**：

- 5% 概率：降低 1–2（最低为 1），
- 80% 概率：平均值加 1–2（不超过配置上限），
- 其余情况：恰好取平均值。

每个属性独立滚动，因此一代可能提升了产出，速度却不变甚至更差。

::: note
两个**相同种子**的作物架不会匹配双输入杂交配方，但中间空位仍会收到相同种子、属性重新滚动的种子袋——这就是同种内繁殖的方法。悬挂式作物架不会主动开始杂交，空的悬挂式作物架也不会接收杂交结果。
:::
