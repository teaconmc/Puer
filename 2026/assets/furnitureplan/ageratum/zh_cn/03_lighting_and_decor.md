# 灯具与装饰

## 三类柱体

每个材质家族都生成普通柱、雕花柱和发光柱。柱体检查正上方与正下方是否为任意 `ColumnBlock`，并自动选择：

- 上下都没有：完整单柱模型。
- 只有上方：底座模型。
- 只有下方：顶部模型。
- 上下都有：连接中段模型。

判断不限制材质，也不限制普通、雕花或发光类型，因此混搭柱体仍会连成一根柱。发光柱默认处于点亮状态并发出亮度 `15`；当前类没有提供右击切换逻辑。

## 台灯

台灯必须放在能支撑中心点的方块上。空手右击会在 `off` 与 `on` 两种状态间切换，开启时发出亮度 `15`。移除下方支撑后，台灯会在方块存活更新中变为空气。

## 两种吊灯

`lantern_pattern_1` 与 `lantern_pattern_2` 必须悬挂在上方支撑方块下。它们默认熄灭，手持打火石右击可切换点亮状态，亮度同样为 `15`。没有上方支撑时，吊灯无法存活。

## 彩色花架

花架只为 16 种混凝土颜色生成，高两格并提供三个花盆位置。

1. 对准一个空位使用原版花盆。
2. 再对准同一位置使用可进入原版花盆的方块物品。
3. 空手右击该位置会先掉出植物。
4. 再次空手右击会掉出空花盆。

花架使用原版花盆注册表判断植物，普通方块物品并不一定能放入。上半部的中间交互区会转发给下半部保存的容器。破坏花架会掉出三个位置中的植物与花盆。

花架底部需要支撑，上下两部分都支持含水状态。它还向 NeoForge 物品能力暴露内部位置，可供兼容的物品传输系统访问。

::: danger
放置前必须自行清空上方一格。当前实现不会检查上方空间，而会无条件把上半部写入该位置；已有方块会被直接替换，且不会按正常破坏流程掉落物品。
:::
