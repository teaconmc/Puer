# 家具计划

家具计划是一个 Alpha 阶段的 NeoForge 家具模组。当前 `0.1.00` 源码面向 Minecraft `26.1.2`，围绕大量原版材质生成座椅、桌面、柱体和储物家具，并加入灯具、花架及可展示食物与药水的餐具。

## 阅读路线

1. [开始使用](01_getting_started)：创意分页、命名规律与当前取得方式。
2. [座椅与桌子](02_seating_and_tables)：乘坐、占用规则和自动连接桌面。
3. [灯具与装饰](03_lighting_and_decor)：柱体、台灯、吊灯和三层花架。
4. [储物家具](04_storage)：柜子、橱柜、容量、开启条件和自动化。
5. [餐具与食物](05_tableware)：铁锅、盘子、玻璃杯、药水与拆装流程。
6. [目录与当前限制](06_catalog_and_limitations)：数量、材质家族、杂项和未实现内容。

## 规模概览

当前生成资源中有 `2619` 个 `furnitureplan` 物品定义，其中包含 `108` 套材质家族、`1836` 种柜体外观和 `16` 色花架。数量很大，但交互规律按家具类型保持一致。

::: warning
当前源码没有生成或附带任何配方，配方生成器也是空的。请先从“开始使用”了解取得方式；本目录不会引用不存在的配方 ID。
:::
