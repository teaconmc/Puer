# Ether Craft（以太工艺）

Ether Craft（模组 ID `ether_craft`，版本 `0.2.1`）是**基于物品运输与槽位放置**的模组——「Ether Craft is a mod based on item transportation and slots placement.」由 xypp 与 Yuia 开发（MIT），项目位于 `studio.fantasyit.ether_craft`，目标 Minecraft 26.1.2 / NeoForge（`26.1.2.61-beta`），集成 JEI 与 GuideMe。

## 模组内容

- **以太资源** —— 从 `ether_ore` / `deepslate_ether_ore` / `nether_ether_ore` 与 `ether_dust`、`ether_ingot`、`ether_crystal`、`ether_block` 组成的全新材料链，另有 `inactivated_ether` 与奶酪。
- **物品运输设备** —— `ether_stream_emitter`（流发射器）、`ether_process_factory`（处理工厂，4 级）、`ether_adapt_node`（适配节点，3 级）在各槽位间搬运物品资源流。
- **芯片与配方** —— `process_chip` 与 `direct_input` 芯片，以及 5×5 / 7×7 / 9×9 配方答案物品；自定义 `NodeProcessRecipe` / `EtherProcessFactoryRecipe` 配方类型。
- **工具与方块** —— `wrench` 扳手、装饰用 `ether_glass`、`ether_block`、食物 `cheese`，以及世界生成的以太矿石。
