# 配置

配置可以从模组列表中的配置按钮打开，也会写入 `config/advanced_clover-common.toml`。当前源码的实际默认工作模式是 `whitelist`，即使配置注释中仍有一处旧文字把默认值写成了黑名单。

## 工作模式

| 配置项 | 默认值 | 作用 |
|:---|:---|:---|
| `Working Mode` | `whitelist` | 在 `whitelist` 与 `blacklist` 之间切换 |
| `whitelist_items` | TeaCon 整合预设列表 | 只保留匹配的物品 |
| `blacklist_items` | 危险或特殊物品列表 | 排除匹配的物品 |
| `mobSpawnChance` | `10` | 全局实体概率，范围 `0` 至 `1000` |

名单条目由 Java 正则表达式编译，并用**完整匹配**检查 `namespace:path`。它们不是普通 glob：

- `minecraft:diamond` 只匹配钻石。
- `minecraft:.*_ingot` 匹配原版命名空间中以 `_ingot` 结尾的物品。
- 单独的 `*` 不是合法正则；匹配任意字符应使用 `.*`。

无效正则可能阻止物品池刷新，因此编辑后应先检查日志。

## 实体概率

`mobSpawnChance` 以千分比记录：`0` 表示关闭全局实体结果，`10` 表示 `1%`，`300` 表示 `30%`，`1000` 表示必定尝试生成实体。物品自带的 `entity_list.chance` 会覆盖此值。

## 何时生效

随机物品池会缓存在内存中，源码没有监听配置热重载。若在游戏运行中修改名单或工作模式，最可靠的生效方式是保存配置后重启客户端或服务端。

::: tip
修改名单后，用低价值材料制作少量魔法四叶草测试。若来源命名空间没有任何有效候选，使用会失败并返还普通四叶草。
:::
