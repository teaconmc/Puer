# 进阶四叶草

进阶四叶草会在多种地表生物群系生成三叶草与稀有四叶草。四叶草既能制作幸运炖菜，也能与任意物品合成魔法四叶草，从指定模组的物品池中抽取随机结果。

## 阅读路线

1. [寻找三叶草](01_finding_clovers)：了解生成生物群系、植株数量和采集方式。
2. [转换与迷之炖菜](02_conversion_and_stew)：在两种三叶草间转换，并制作幸运或霉运炖菜。
3. [制作魔法四叶草](03_crafting_magic_clover)：用任意材料选择随机物品的来源命名空间。
4. [随机物品与实体](04_random_items_and_entities)：理解右键后的判定顺序、失败返还和安全事项。
5. [配置](05_configuration)：调整黑白名单及实体生成概率。
6. [组件与发射器](06_components_and_dispensers)：为命令物品指定列表，并了解自动化差异。

## 快速说明

| 项目 | 当前实现 |
|:---|:---|
| 注册物品 | 三叶草、四叶草、魔法四叶草 |
| 注册方块 | 三叶草、四叶草 |
| 默认工作模式 | 白名单 |
| 默认实体结果 | 1% 概率生成苦力怕 |
| 配置类型 | 通用配置 |
| 命令与按键 | 无模组专用命令或按键 |

::: warning
魔法四叶草可能直接在玩家身边生成敌对生物。第一次尝试新的实体列表或高实体概率时，请在开阔、安全的区域进行。
:::
