# 封存一枚胶囊

## 如何获得

模组随包 **2 个配方**与 **8 份战利品表**——每个方块一份，因此每个风化阶段被挖掘时都掉落自身。物品形式 `time_capsule:time_capsule` 与方块形式在生存模式下都可获得。

## 封存界面

右键已放置的胶囊打开**时间胶囊**菜单。它比普通容器多出不少东西：

| 元素 | 用途 |
|:---|:---|
| **25 个槽位** | 要封存的内容（5 × 5 网格） |
| **留言框** | 占位文字为「封存一段话语……」 |
| **六个时间字段** | 年、月、日、时、分、秒 |
| **模式切换** | 在**游戏时间**与**现实时间**之间切换 |
| **封存时间胶囊** | 提交以上全部内容 |

物品、留言、模式与解锁时间这四项一起存放在单个数据组件 `time_capsule:time_capsule_data` 中。

::: info
六个时间字段是分开的输入框而不是一个时长框，这意味着你设定的是**一个时刻**，而不是「从现在起一小时」。这个时刻相对于什么来度量，完全取决于模式——见[游戏时间与现实时间](02_game_time_vs_real_time)。
:::

## 封存之后

提示文本成为你唯一的状态读数，它有两种状态：

| 提示文本 | 含义 |
|:---|:---|
| **已封存** + `剩余时间：N 天 N 小时 N 分 N 秒` | 仍在倒计时 |
| **等待启封** | 时刻已过 |

倒计时是实时的，因此一枚已封存的胶囊同时也是一个可见的计时器。

## 提前打开

做不到。与已封存的胶囊交互会随机打印五条消息之一，然后什么都不发生：

```
这段回忆还没到该启封的时刻……
你觉得还不是时候。
或许……可以再等等？
你想了想，最后还是把它放了回去。
但是它拒绝了。
```

模组里**没有任何命令、没有配置项、也没有创造模式的绕过手段**——它随包零命令、零配置项。越过一枚已封存胶囊的办法只有两个：等，或者失去里面的内容。

## 一套实用流程

1. 把胶囊放在不会被扰动的地方。
2. 放入你想留存的东西，写好留言。
3. **先**选好模式——它会改变那些数字的含义。
4. 填入从年到秒的各项。
5. 按**封存时间胶囊**。
6. 别再碰它。好奇时看提示文本。

::: warning
**在封存之前决定模式，而不是之后。** 模式是被封存组件的一部分；模组没有编辑已封存胶囊的界面，因此一枚用错模式封存的胶囊只能等下去。
:::

## 涂蜡固定外观

使用蜂巢会把胶囊转为它的涂蜡变体，从而停止风化。就封存而言这纯属外观——**涂蜡不影响倒计时**——但它能把外观固定在你喜欢的那个阶段。见[风化、涂蜡与技术说明](03_weathering_and_technical_notes)。
