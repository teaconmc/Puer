# 时间胶囊

**时间胶囊**（模组 ID `time_capsule`，版本 `1.0.0-indev`，MIT，作者 mrqx0195）让你把物品与一段留言封存在某个时刻之后。在那一刻到来之前，胶囊会拒绝打开——而且它会用五种不同的说法告诉你。

这是一个做得很仔细的小模组：**八个方块构成完整的铜式风化链**、25 格容器、两种彼此独立的时间模式，且完全没有配置项。

## 它实际做的事

把物品放进胶囊、写一段话、选定一个时刻，然后封存。此后胶囊的提示文本显示**已封存**并附带实时倒计时——`剩余时间：%s 天 %s 小时 %s 分 %s 秒`。若提前尝试打开，会随机得到五种拒绝之一：

> 这段回忆还没到该启封的时刻……
> 你觉得还不是时候。
> 或许……可以再等等？
> 你想了想，最后还是把它放了回去。
> **但是它拒绝了。**

时刻过去之后，提示文本变为**等待启封**。

::: tip
最后那句拒绝是对原版不死图腾提示的刻意致敬。五种说法是随机挑选的，因此反复去戳一枚已封存的胶囊，读起来就像它对你渐渐失去耐心。
:::

::: warning
**在挖掘一枚已封存的胶囊之前，请先读[风化、涂蜡与技术说明](03_weathering_and_technical_notes)里关于战利品表的那一节。** 方块的战利品表复制了四个原版组件，但**并未列入本模组自己的 `time_capsule_data` 组件**，而留言、模式与解锁时间正是存在那里面。
:::
