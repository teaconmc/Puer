# 野稻与秧苗

<block id="ashihara:wild_rice"/>

野稻会加入平原类群系，生成稀有度参数为 `30`。收获野稻能取得稻谷，这是当前最可靠的稻米起点。先保留一部分稻谷用于扩种，另一部分可以直接进入稻堆与研钵加工链。

## 获得秧苗

把稻谷种在普通耕地上，会先形成未成熟稻株。等待其成熟并收获，才能得到用于水田的秧苗。秧苗应种在水田方块，而不是普通耕地；水田还必须维持足够水位才能继续生长。

当前存在两条不要混淆的路线：

- **可食用路线**：野稻 -> 稻谷 -> 稻堆 -> 研钵加工 -> 糙米与白米。
- **水田展示路线**：稻谷 -> 普通耕地育苗 -> 秧苗 -> 水田稻株 -> 稻穗 -> 晒干的稻穗。

第二条路线目前在晒干后断开，没有配方把晒干的稻穗变成可烹饪米。水田仍可用于体验种植系统，但生存食物应优先依赖野稻掉落。
