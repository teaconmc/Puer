# Mortar and Cutting Board

<block id="ashihara:mortar"/>

<recipe id="ashihara:mortar"/>

<recipe id="ashihara:pestle"/>

The Mortar has `4` item slots and `16000 mB` of fluid capacity. Insert ingredients matching a recipe, then interact repeatedly with a Pestle to advance processing. Current normal rice recipes require `6` pestle actions. Other tool actions may select different processes; the interface or a recipe viewer shows the actual requirement.

<block id="ashihara:cutting_board"/>

<recipe id="ashihara:cutting_board"/>

The Cutting Board holds up to `4` input items. Interact with a tool in the `#c:knife` tag to perform cutting, or use an empty hand to remove the contents. Place ingredients first and then switch to the knife. If nothing happens, verify the knife tag and input quantity.

::: note
Mortar and cutting processes use custom recipe types. This page displays only standard crafting recipes for the equipment and tool; use a compatible recipe viewer for individual processing recipes.
:::
