# Miniature Building Components

Ashihara's hundreds of beams, posts, tiles, and ornaments do not each become an independent block. Multiple components are stored inside one composite block with their shape, position, and material, allowing very fine architectural detail inside a single block space.

## Basic building workflow

1. Establish the building axes and floor height with full blocks.
2. Select a component and place it in shared space with grid snapping.
3. Inspect collision and orientation from several angles before adding another component.
4. Aim at one component with the Wooden Hammer or Chisel and interact to remove that targeted part rather than the whole block space.

The Wooden Hammer and Chisel currently have identical removal behavior, so switching between them is unnecessary. Component material can also upgrade according to an internal priority. Test an upgrade on a sample before applying it broadly so detailed work does not acquire an unintended material.

::: warning
Offhand furniture or component placement may fail while the main hand is occupied. Empty the main hand for precision work, or place the component in the main hand.
:::
