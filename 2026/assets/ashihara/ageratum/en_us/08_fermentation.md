# Fermentation

<block id="ashihara:wooden_basin"/>

The Wooden Basin has `4` item slots, `16000 mB` capacity, and a maximum parallel size of `16`. It can run the current koji and soaked-soybean fermentation recipes. Its inherited lid state cannot be toggled, however, so air-required cucumber pickling cannot run in a Basin.

<block id="ashihara:fermentation_vat"/>

The Fermentation Vat has `8` slots, `128000 mB` capacity, and maximum parallel size `128`. Use an **open** Vat for recipes that require air. After loading it, verify the lid and fluid amount before waiting for the process.

<block id="ashihara:large_fermentation_vat"/>

The Large Fermentation Vat has `16` slots, `1024000 mB` capacity, and a theoretical maximum parallel size of `1024`, but no registered fermentation recipe currently supports it. It cannot process the existing recipes.

::: warning
The Basin, Vat, and Large Vat all lack crafting recipes. Even when obtained from Creative mode, the Large Vat currently has no recipe use.
:::
