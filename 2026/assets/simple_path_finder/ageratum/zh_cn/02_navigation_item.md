# 导航物品

`simple_path_finder:navigation` 是单格堆叠的工具。它把破坏速度覆盖为 0，无法破坏方块。右键方块时作用于点击面外侧一格的位置，也就是预期的步行层。

## 模式

| 模式 | 行为 |
|:---|:---|
| 默认 | 不执行服务端修改，保留当前导航结果供显示。 |
| 添加导航 | 解析所点击的区块并创建可步行图层。使用玩家当前的 `player_block_distance` 数据，标记存档数据为脏并同步该区块。 |
| 移除导航 | 移除所点击区块中步行 Y 与点击位置相差不超过 3 的第一个图层。 |
| 添加链接 | 开始或完成一条导航链接；详见[导航链接](04_navigation_links)。 |

物品提示文本会显示当前模式与图层。在添加链接模式下，选好第一个点后物品会出现附魔闪光。

## 图层

图层值是字节，因此设置界面限制为 `-128..127`。默认图层为 `0`；源码注释建议实际使用 `0..9`。每个区块最多保存 `max_layers` 个图层，默认 `37`。添加导航处理器的限制消息把上限写成 `max_layers - 1`，但图层的数值本身并不以该值封顶。

## 设置界面

潜行 + 右键会打开导航点设置界面：

- 模式按钮：默认、添加导航、移除导航、添加链接。
- 图层字段：数字图层值。
- 添加链接模式下的链接类型按钮：普通、传送、载具。
- 保存：把模式和图层写入 `simple_path_finder:navigation_mode` 组件并发送 `simple_path_finder:update_item_properties`。
- 方块距离配置：打开玩家专属距离编辑器。

潜行 + 滚轮可以在不打开界面的情况下循环模式。修改物品设置本身不受创造模式限制；创造模式限制会在服务端图形操作执行时检查。

## 权限

当 `require_creative_mode` 为 `false`（默认值）时，添加导航、移除导航与添加链接在任何游戏模式都允许。设为 `true` 后，这些操作要求创造模式，否则服务端会发送 `simple_path_finder.nav.creative_required`。打开设置界面和保存物品组件仍不受限制。
