# 导航笔刷与导航屏障

## 导航笔刷

`simple_path_finder:nav_brush` 把设置保存在 `simple_path_finder:nav_brush` 数据组件中。空中潜行 + 右键会打开导航笔刷设置界面；右键方块会在服务端应用笔刷操作。

笔刷只能编辑已经存在、且在点击位置附近有图层的导航区块。如果没有导航数据或图层，服务端会发送 `no_nav_data` 或 `no_layer_at_pos`，并且不修改任何内容。

| 模式 | 行为 |
|:---|:---|
| 全部边 | 把操作应用到点击位置保存的所有四条水平边。 |
| 单边 | 只把操作应用到点击面对应的轴。 |

| 操作 | 每个目标边上保存的距离 |
|:---|:---|
| 删除 | `-1`（阻挡） |
| 添加 | `1`（可步行，默认成本） |
| 调整权重 | 配置好的权重值 |

界面中的权重输入限制为 `-1..10000`，默认为 `1`。把权重设为 `-1` 会阻挡该边。枚举辅助方法给出的范围是 `1..16`，但当前界面与数据包路径并不使用这个更窄的限制。

笔刷操作受 `require_creative_mode` 控制，默认允许任意游戏模式使用。开启后，非创造玩家会收到 `simple_path_finder.nav_brush.creative_required`。与导航物品不同，当前构建中笔刷没有破坏速度覆盖，因此其左键仍使用物品默认行为。

## 导航屏障

`simple_path_finder:navigation_barrier` 是不可见方块。它不会遮挡、窒息或阻挡视线，并且允许流体替换。它会阻挡导航，因为 `NavUtil` 即使在该方块渲染形状不可见时也把它当作碰撞。

只有交互上下文持有导航屏障或导航物品时，它的选择/碰撞形状才是完整方块，否则形状为空。当本地玩家主手持有导航屏障物品时，客户端会在每个屏障处生成 `minecraft:block_marker` 粒子，让屏障在编辑时可见。

屏障本身没有界面或物品设置。它适合封闭自动安全穿越检查原本会放行的缝隙或路径。
