# 袖里舆图

袖里舆图是一个客户端小地图模组，提供地表与洞穴显示、方向和环境文字、实体雷达及本地地图缓存。本套文档依据 `aleeve_atlas` 0.0.1 的当前源码编写。

## 阅读路线

- [小地图基础](01_minimap_basics)：打开设置、默认显示和地图数据来源。
- [显示、旋转与缩放](02_display_and_zoom)：形状、朝向、尺寸、位置和五档缩放。
- [实体雷达](03_radar)：标记分类、颜色、扫描范围与数量上限。
- [环境信息与洞穴](04_environment_and_caves)：动态光照、地下切换和文字信息。
- [路径点当前状态](05_waypoints_current_status)：生产构建禁用的按键与仍存在的底层代码。
- [命令与故障排查](06_commands_and_troubleshooting)：缓存命令、磁盘数据和功能边界。

## 当前定位

安装在客户端后，小地图直接叠加在游戏 HUD。它不添加物品、方块、实体、配方或服务端玩法，也没有全屏世界地图。

::: warning
语言文件虽然列出了路径点界面文本，但正式生产构建不会注册 `B` 与 `N` 路径点按键。不要把开发环境中可打开的界面当作发布版功能。
:::
