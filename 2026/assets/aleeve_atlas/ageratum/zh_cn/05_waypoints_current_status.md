# 路径点当前状态

## 正式构建中的行为

源码为路径点定义了默认 `B` 管理界面和 `N` 快速创建界面，但两者只在非生产开发环境注册和处理。正常发布的模组 JAR 中，这两个按键不会出现在控制设置，也不能打开对应界面。

因此正式版本没有受支持的游戏内流程来新建、编辑、删除或选择活动路径点。

::: warning
不要仅依据语言文件中的“路径点管理”“快速创建路径点”等文本判断功能可用。生产环境开关明确关闭了这些按键。
:::

## 仍存在的底层代码

模组启动时仍会读取或创建 `config/aleeve_atlas-waypoints.json`。底层数据支持名称、维度、XYZ、RGB 颜色、启用状态和一个活动路径点；渲染器也能在小地图显示同维度点，并在世界中为活动点绘制标记。

这些类主要说明开发中的目标，不构成稳定的手动编辑格式。直接修改 JSON 没有界面校验，错误字段或版本变化可能导致数据丢失或无法加载。

## 当前没有的功能

- 全屏地图上的点击标记。
- 死亡点自动创建。
- 路径点传送。
- 分享、导入导出、分组或多人同步。
- 发布版中的批量管理和快捷导航。

若整合包要开放现有开发界面，需要修改并重新构建模组；资源包本身不能启用被 Java 生产开关禁用的按键。
