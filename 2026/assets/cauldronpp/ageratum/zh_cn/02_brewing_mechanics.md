# 酿造机制

Cauldron++ 重新实现了 Beta 1.9-pre2 的药水模型。这里没有可查询的酿造配方：炼药锅只保存一个 15 位的数字，你投入的每种原料都会翻转这个数字中的某些位。你最终得到的效果，取决于这个位模式恰好满足了哪些条件。

## 药水数据是一个位域

锅中的液体携带一个 `0` 到 `32767` 之间的**药水数据**值（15 位）。每种酿造材料都有一条规则，描述它把哪些位设为 1、清零或取反：

| 材料规则中的符号 | 含义 |
|:---|:---|
| `+n` | 将第 *n* 位设为 1 |
| `-n` | 将第 *n* 位设为 0 |
| `!n` | 将第 *n* 位取反 |

这就是为什么同一种原料可以改善一锅药水，却毁掉另一锅——它并不是在添加效果，而是在编辑一个数字。

## 加水会重置部分位模式

每次向正在酿造的炼药锅中加水时，都会应用规则 `-1-3-5-7-9-11-13`，把全部七个奇数位清零。因此加水是一次部分重置，而不是中性的稀释。水桶、水瓶，以及在锅中已有药水时补满，都会触发这一行为。

## 酿造材料

只有以下物品可作为酿造材料。地狱疣单独处理（见下文）。

| 材料 | 规则 |
|:---|:---|
| 糖 | `+0` |
| 恶魂之泪 | `+11` |
| 蜘蛛眼 | `+10+7+5` |
| 发酵蛛眼 | `+14+9` |
| 烈焰粉 | `+14` |
| 岩浆膏 | `+14+6+1` |
| 兔子脚 | `!8-10+1` |
| 荧石粉 | `+8+3` |
| 红石粉 | `-6-1+0` |
| 金萝卜 | `-5+12!4` |
| 幻翼膜 | `+5+7+11` |
| 黏液球 | `+11-13` |
| 紫颂果 | `!12-4+6` |

这些材料收录于 `cauldronpp:cauldron_brewing_materials/potion` 物品标签，完整集合（材料加类型转化物）位于 `cauldronpp:cauldron_brewing_materials`。

## 地狱疣是特例

地狱疣不使用简单的位规则。它会运行一套专门的重排流程：找出最高的置位，移动整个模式，然后反复平滑相邻的位，直到数值不再变化。实际使用中，地狱疣正是把平淡混合物变成真正有效果的那一步，与 Beta 1.9-pre2 完全一致。

## 这个数字究竟产出什么

一旦炼药锅中存有药水数据，模组就会用两条规则字符串评估每一个已注册的状态效果：

- 一条**需求**规则，决定该效果是否出现，以及持续多久。
- 一条可选的**等级**规则，决定效果等级。

这些规则使用一套小型表达式语言：位测试、`|` 表示或、`&` 表示与、`*` 表示乘数、`=`/`>`/`<` 用于比较置位的数量，`!` 要求某位未置位。或运算先于与运算求值。

持续时间由需求结果推导：数值 *d* 得到 `1200 × (d × 3 + (d − 1) × 2)` 刻。有害效果随后减半，瞬间效果被压缩为一刻。

## 模组可产出的效果

除了 Beta 版原有的效果集（速度、缓慢、急迫、挖掘疲劳、力量、瞬间治疗、瞬间伤害、跳跃提升、恶心、生命恢复、抗性提升、抗火、水下呼吸、隐身、失明、夜视、饥饿、虚弱、中毒）之外，Cauldron++ 还把现代效果加入了表中：

凋零、生命提升、伤害吸收、缓降、饱和、飘浮、幸运、霉运、不祥之兆、黑暗、发光、渗浆、盘丝、蓄风和虫蚀。

## 名称与颜色

药水的显示名称前缀和颜色都由药水数据计算得出，而不是储存的。前缀取自一张 32 个名称的表（粗劣的、朴素的、清澈的、粗制的、浓稠的、强效的、恶臭的等等），颜色则通过提取三组位并异或进 RGB 通道推导。因此，两锅效果相同的药水，外观和名称仍可能不同。

## 什么可以放进炼药锅

只有当炼药锅中含有水或药水时，酿造才会进行。可接受的输入是：

- 水桶、水瓶和玻璃瓶。
- 上表列出的全部酿造材料，以及地狱疣。
- 三种药水类型转化物（见 [03 药水类型](03_potion_types)）。
- 箭，用于制作药箭。

岩浆和细雪无法用于酿造——它们只能装填、倒出和影响实体。
