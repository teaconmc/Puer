# Lights up!

Lights up! adds a single stage spotlight block that projects a translucent cone of light in the direction it faces. It is a rendering-focused mod: the beam is drawn with the mod's own custom render pipelines rather than with ordinary block models.

It is also clearly an early prototype. Read [01 Getting started](01_getting_started) before you try to obtain it — there is no creative tab entry, no model, and no name.
