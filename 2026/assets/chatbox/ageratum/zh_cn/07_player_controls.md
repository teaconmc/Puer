# 玩家操作

对话运行在两种模式之一，而模式决定了你还能碰到多少游戏内容。

## 界面模式与覆盖层模式

| 模式 | 由什么设定 | 行为 |
|:---|:---|:---|
| 界面模式 | `isScreen: true` | 一个真正的 GUI 界面。鼠标驱动对话；正常游玩被阻断。可用调试模式。 |
| 覆盖层模式 | `isScreen: false` | 绘制在 HUD 之上。你可以继续正常游玩，但若干对话交互不可用。 |

模式可以在对话文件中固定，也可以用 `/chatbox command isScreen <true|false>` 实时切换。覆盖层模式适合环境叙事或冒险旁白；界面模式适合需要可靠点击的多选项场景。

## 操作

| 输入 | 效果 |
|:---|:---|
| 右键 | 确认 —— 推进一行，或接受当前高亮的选项 |
| 鼠标滚轮 | 在选项之间移动 |
| Esc | 关闭对话（文件允许时） |
| Ctrl | 快进 |
| F6 | 切换自动播放 |

Esc 受对话文件的 `isEsc` 限制。设为 `isEsc: false` 的文件无法用 Esc 关闭，这正是脚本场景把玩家留在原地的方式。

## 功能按钮

主题最多可放置三个按钮，各自带有内置美术与悬停美术：

| 按钮 | 效果 |
|:---|:---|
| 记录 | 打开历史记录界面 |
| 快进 | 开启快进并关闭自动播放 |
| 自动播放 | 切换自动播放 |

## 快进与自动播放

快进会自行不断推进行。任何左键点击或滚轮输入都会停止它，因此玩家只要碰一下鼠标就能收回控制权。

::: info
点击快进**按钮**并不会停止快进 —— 只有在别处左键点击或滚动才行。源码把这一点记录为已知粗糙之处，而非有意设计。
:::

自动播放在每行结束后等待对话文件的 `autoPlayTick`（默认 `20` 刻，即一秒），然后推进。它只在玩家点击自动播放或快进按钮时关闭，因此不会被普通点击打断。倒计时期间该等待值会被限制为最多 20 刻。

某一行究竟能否被快进，还取决于文件的 `isHistoricalSkip`，这正是阻止玩家跳过尚未看过的文本的机制。

## 历史记录

记录按钮会打开一份可滚动的对话记录。滚动速度来自客户端配置的 `historicalScrollSpeed`。当服务端改写当前行时 —— 例如替换一个名称 —— 对应的历史条目也会被同步改写，因此记录里显示的是玩家实际读到的内容。

## 文本速度

正文按每秒 `charPerSecond` 个字符逐字显示，这是一个取值范围很宽（`1`–`721`）的客户端选项。它属于个人舒适度设置，绝不会改变对话说了什么或存在哪些选项。

## 调试模式

仅在**界面模式**下，`F3` 可切换调试模式。它是为了不手改 JSON 就能排布主题而设计的：

| 输入 | 效果 |
|:---|:---|
| `F3` | 切换调试模式 |
| 按住 Shift | 显示组件边框与光标位置 |
| 按住修饰键 | 显示悬停组件的信息 |
| 修饰键 + 左键拖动 | 移动组件 |
| 修饰键 + 滚轮 | 调整某个属性；按住 Alt 可选择属性 |
| 修饰键 + `C` | 复制悬停组件的信息 |
| 修饰键 + `R` | 重载数据 |

调试模式也是快进在调试期间被抑制的原因 —— 两者会争夺同一批点击。

::: warning
调试重载快捷键的原理是代你发送原版 `/reload` 命令，因此只有当你拥有执行 `/reload` 的权限时才会成功。在没有该权限的服务器上，这个快捷键只是毫无反应。
:::
