# 配置与兼容性

## 客户端配置

ChatBox 只有一份配置，名为 `chatbox_config`，且**仅限客户端**。它没有服务端配置也没有通用配置，因此这里的任何一项都无法被服务器强制。配置由 AutoConfig 管理，用 Cloth Config 界面编辑。

| 选项 | 默认值 | 取值范围 | 含义 |
|:---|:---|:---|:---|
| `historicalScrollSpeed` | `10` | `1`–`200` | 历史记录界面的滚动速度 |
| `soundInterruptionEnabled` | `true` | 开/关 | 没有新音效的一行是否打断仍在播放的声音 |
| `charPerSecond` | `20` | `1`–`721` | 每秒逐字显示的字符数 |
| `portraitWidthPercent` | `100` | `1`–`200` | 应用于图像立绘宽度的缩放系数 |

每个选项都属于表现或舒适度。它们都不会改变存在哪些对话、哪些选项会解锁，或某条命令做什么。

## 加载器

模组由一套公共源码加上很薄的 Fabric 与 NeoForge 适配层构建，因此两个加载器得到完全相同的对话与主题格式、相同的命令和相同的渲染器。差异仅限于各平台如何注册重载监听器、网络与事件。

| 目标 | 版本事实 |
|:---|:---|
| Minecraft | `26.1.2`，接受范围 `[26,27)` |
| NeoForge | 针对 `26.1.2.43-beta` 构建，依赖范围 `[26.1,)`，加载器 `[4,)` |
| Fabric | Fabric API `0.148.2+26.1.2`，加载器 `0.18.4` |

## 必需：Cloth Config

NeoForge 元数据把 `cloth_config` 在两端都声明为 **required**，配置类也是基于 AutoConfig 编写的。请与 ChatBox 一同安装 Cloth Config；模组另外带有一个同时匹配两种模组 id 拼写的运行时检查，因此在类缺失时它会降级而不是崩溃。

## 可选：WaterMedia

视频播放需要 WaterMedia。模组在构建视频组件前会检查它，缺失时直接返回空。

::: warning
没有 WaterMedia 时 `video` 块会被静默丢弃 —— 本行照常播放，只是没有视频，也不会给玩家任何警告。绝不要让视频成为玩家获知关键信息的唯一途径。
:::

## 可选：KubeJS 式脚本

在 NeoForge 上，模组附带一个把 ChatBox 事件暴露给某个 JavaScript 脚本模组的集成层，包含渲染事件、跳转对话事件与通用后初始化事件的挂钩。这是仅 NeoForge 的接口；Fabric 构建不包含它。

MVEL 引擎本身被打包进 jar，因此两个加载器上表达式都无需额外安装即可使用。

## 从其他模组扩展

有两个扩展点面向附属模组开放：

- **事件类型。** 注册一个带客户端动作、可选服务端动作，以及「是否需要通知服务端」的新类型。参见[事件与条件](05_events_and_conditions)。
- **MVEL 方法与属性。** 注册一个具名方法或属性解析器，随后即可在任何表达式中以 `主体.你的方法(...)` 调用或 `主体.你的属性` 读取。

两个注册表都以名称为键，且都必须在模组初始化期间填充才能被数据包看到。

## 资源包覆盖

由于每个视觉元素都通过主题以贴图标识符寻址，资源包可以在不改动任何数据包的前提下重做对话框、选项、按钮与按键提示的外观。模组自带的默认美术位于其 `textures/chatbox`、`textures/options`、`textures/button` 与 `textures/key` 目录下。
