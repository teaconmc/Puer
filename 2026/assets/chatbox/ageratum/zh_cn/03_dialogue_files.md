# 对话文件

```
data/<namespace>/chatbox/dialogues/<name>.json
```

每个文件是一份对话文档。它持有若干具名**组**，每组是一个有序的**行**数组。`/chatbox skip <文件> <组> [下标]` 从指定行开始播放。

## 顶层字段

| 字段 | 默认值 | 含义 |
|:---|:---|:---|
| `dialogues` | 必填 | 组名到行对象数组的映射 |
| `isEsc` | `true` | 是否允许用 Esc 关闭对话 |
| `isPause` | `true` | 对话是否暂停游戏（单人） |
| `isHistoricalSkip` | `true` | 是否允许快进已看过的行 |
| `theme` | — | 本次对话要切换到的主题标识符 |
| `isScreen` | — | `true` 为界面模式，`false` 为覆盖层模式 |
| `animationFPS` | `60` | 组件关键帧的动画帧率 |
| `autoPlayTick` | `20` | 自动播放在一行结束后等待的刻数 |
| `maxTriggerCount` | `-1` | 仅服务端：每位玩家可触发本文件的次数 |
| `criteria` | — | 仅服务端：自动触发本文件的进度判据 |

`maxTriggerCount` 与 `criteria` 在源码中被明确标注为仅服务端有效；客户端从不据此行动。

## 行字段

组数组的每个元素都接受下列键。除了「完全没有可见内容的行只会渲染出一个空框」之外，它们全部可选。

| 字段 | 默认值 | 含义 |
|:---|:---|:---|
| `dialogBox` | `{name:"", text:""}` | 说话者名称与行正文 |
| `portrait` | — | 要显示的立绘列表；每项是主题立绘名，或一个覆盖它的对象 |
| `options` | — | 本行呈现的选项列表 |
| `sound` | — | 本行开始时播放的音效 |
| `bgm` | — | 本行开始的背景音乐 |
| `stayTick` | `0` | 本行在可推进前需保持的刻数 |
| `command` | — | 到达本行时在服务端执行的命令字符串 |
| `backgroundImage` | — | 全屏背景贴图 |
| `video` | — | 视频组件（需要 WaterMedia） |
| `clearOldPortrait` | `true` | 清除上一行遗留的全部立绘 |
| `removePortrait` | — | 不清除时，仅移除这些立绘 id |
| `renderEvents` | — | 附加在行本身上的渲染事件 |

### 立绘条目

`portrait` 的每一项可以是两种形式之一：

- **字符串** —— 激活主题中定义的立绘名称。
- **对象** —— 主题立绘接受的同一组字段，外加 `id`（基于哪个主题立绘）与 `replace`。当 `replace: true` 时，已存在的同 id 立绘会先被移除，因此新定义是取代它而不是叠加。

若主题中不存在所指名称的立绘，该行会记录错误并跳过这一项；本行其余内容照常渲染。

### 选项

| 字段 | 默认值 | 含义 |
|:---|:---|:---|
| `text` | — | 选项标签 |
| `isLock` | `false` | 选项是否初始为锁定 |
| `unlockCommand` | — | 决定选项是否解锁的条件 |
| `next` | — | 被选中时跳转到何处 |
| `click` | `{}` | 点击时触发的事件 `type` 与 `value` |
| `tooltip` | — | 悬停文本 |

`next` 接受三种形态，全部由 `JUMP` 事件处理：

- 留空 —— 前进到下一行，
- 整数 —— 跳到当前组的该行下标，
- 其他字符串 —— 跳到该名称的组（字面量 `this` 表示「原地不动」）。

## 视频

`video` 对象接受 `path`，外加 `canControl`、`canSkip` 与 `loop`（默认分别为 `true`、`true`、`false`）。`path` 先按游戏目录解析，再按普通文件路径，最后按 URI 解析。

::: warning
视频需要 WaterMedia。没有它时视频组件会被静默丢弃 —— 本行照常播放，只是没有视频。请始终把视频当作可选增强，绝不要让它成为脚本流程中的必要环节。
:::

## 音效与音乐

`sound` 在本行开始时触发一次；`bgm` 启动背景音乐。客户端配置项 `soundInterruptionEnabled` 决定「没有新音效的一行」是否打断仍在播放的声音。随包音效事件为 `chatbox:ciallo`。

## 文本能力

行正文不是纯文本。它同时支持：

- 翻译键，因此单个文件可服务多种语言，
- 原版格式化代码，用于颜色、粗体与斜体，
- `@s` 式的玩家名替换，
- 写作 `` `<<expression>>` `` 的内联 MVEL 块，
- 诸如 `` `<player>` `` 与 `` `<target>` `` 的目标占位符，
- 随包演示用于类似注音的旁标文本的 `ruby` 标注形式。

表达式与占位符语法的细节见 [MVEL 与占位符](06_mvel_and_placeholders)。

## 组与判据：一个文件一个组

判据系统绑定在**文件**上，而一个文件可以持有多个组 —— 于是实现把判据绑给组集合中排在最前面的那个组。

::: warning
若你使用 `criteria`，请让该文件恰好只有一个组。存在多个组时，其中只有一个可能被自动触发，而具体是哪一个并不由你控制。源码本身就把这一点记录为已知限制。只靠 `/chatbox skip` 启动的文件不受影响，可以随意持有多个组。
:::
