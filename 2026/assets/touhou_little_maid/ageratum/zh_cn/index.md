# 车万女仆（Touhou Little Maid）

Touhou Little Maid（`touhou_little_maid`）是一个受 LittleMaidReengaged 启发的伙伴模组。女仆实体跟随主人，通过聊天气泡与 AI 聊天系统说话，累积好感度，携带背包与饰品，还可以压缩成便于携带的物品。模组还加入了祭坛合成系统、模型切换方块、女仆床、装饰方块与一系列实用工具。

## 阅读路线

1. [快速上手](01_getting_started)：获取与储存女仆、祭坛、模型切换、装备与命令。

## 快速说明

| 项目 | 当前实现 |
|:---|:---|
| 模组 ID | `touhou_little_maid` |
| 实体 | 女仆、妖精（自然生成）、椅子、扫帚、收纳盒、坐垫、墓碑、钓鱼钩、弹幕、灭火剂、P 点、可投掷 P 点 |
| 方块 | 7 色女仆床、祭坛、雕像、车库套件、女仆信标、模型切换器、野餐垫、五子棋、中国象棋、国际象棋、键盘、书架、电脑、神龛、稻草人、零食柜 |
| 物品 | 女仆/妖精刷怪蛋、3 种背包、博丽/早苗御币、6 种防护饰品与特殊饰品、智能存储板、相机/照片/胶片、狐狸卷轴、侍铃、喇叭、无线 IO、河童罗盘、灭火器、凿子、椅子等 |
| 创造页 | `main`、`garage_kit`（椅子模型）、`chair`（车库套件） |
| 命令 | `/tlm` 及 `pack`、`power`、`maidnum`、`maiddebug`、`aichat`、`maid`、`backup` |
| 配方 | 常规配方，以及由祭坛方块驱动的 `touhou_little_maid:altar` 自定义配方类型 |

::: note
女仆刷怪蛋与妖精刷怪蛋是最直接的入手方式；祭坛方块承载了模组多数物品依赖的自定义配方类型。当前源码还内置表情聊天功能、好感度工具以及面向服务器管理员的备份命令。
:::
