# 与其他模组一起玩

你的女仆能与另外几个模组的仓储协同工作，而**每一项集成都默认开启**——你不需要额外启用任何东西。

## 必需：东方女仆

这是一个附属模组。没有**东方女仆（Touhou Little Maid）**，这里的一切都无法工作。见[开始使用](01_getting_started)。

## 女仆能读懂的仓储系统

| 系统 | 开箱可用 |
|:---|:---|
| **应用能源 2（AE2）** | **可以** —— 女仆能从终端取物 |
| **精致存储（Refined Storage）** | **可以** |
| **通用机械 QIO** | **可以** |
| **Create（机械动力）**仓储 | **可以** —— 集成最深，见下 |
| 原版箱子与木桶 | 可以 |

::: tip
**三大仓储模组都受支持且默认启用。** 如果你在用 AE2、精致存储或通用机械 QIO，你的女仆已经能从它们取物了——没有需要安装的兼容模块，也没有需要打开的开关。

如果你就是想**阻止**女仆使用其中某一个，每一项都有对应的配置开关可以关掉。
:::

## ⚠️ Create 库存管理员：横向范围只有 7

女仆可以在 Create 的库存计数器周围充当**库存管理员**，而两个范围数值差别很大：

| 范围 | 默认 | 可调至 |
|:---|---:|---:|
| **纵向** | **16** | 256 |
| **横向** | **7** | 64 |

::: warning
**库存管理员女仆覆盖的是一根又高又窄的柱体，而不是一片宽阔的平面。**

纵向可达 16 格，而横向只有 **7 格**——所以如果你的 Create 物流是横向铺开的，那个 7 就是会让你踩坑的数字。一个站在宽阔厂房中央的女仆，根本看不到两端。

**如果你的布局是横向的，请提高横向范围**（最高 64），而不是让女仆来回移动。
:::

## 女仆地址，以及冲突时怎么办

每个担任库存管理员的女仆都会按一个模式生成地址。默认是把她的**类型首字母**与**唯一 ID 的四个字符**组合起来。

::: info
**如果你养了很多同类型女仆并开始出现地址冲突**，请在配置里加长 ID 部分——用八个字符而不是四个，能大幅降低撞号概率。

模式共有五个占位符可用，所以你也可以写入完整类型名或完整 ID，用可读性换取长度。
:::

## ⚠️ 有一处配置注释是错的 —— 请信键名，别信注释

::: danger
**控制 Create 库存管理员的那个选项，其注释写的是「Enable tacz recipe support」。**

TACZ 是一个无关的枪械模组，这个选项与它毫无关系。那条注释是复制粘贴留下的。

**选项本身完全按其名称工作**——它控制的就是 Create 库存管理员支持。所以如果你在通读配置文件时被那条注释搞糊涂了，请忽略注释、按选项名理解。
:::

## 配方查看器

**JEI** 与 **EMI** 都受支持，两者的原料请求都能派给女仆。两项都默认开启。

JEI 还额外支持直接转移配方——见[合成引擎](04_crafting_engine)。

## 其他可选模组

| 模组 | 你会得到 |
|:---|:---|
| **Patchouli** | **40 页游戏内手册** |
| **Cloth Config** | 一个设置界面，省去改文件 |
| KubeJS | 脚本支持 |

::: tip
**Patchouli 值得装** —— 对一个系统这么多的模组来说，40 页手册是相当可观的游戏内参考量。
:::
