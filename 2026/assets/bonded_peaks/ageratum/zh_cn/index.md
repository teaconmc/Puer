# 山河同契（Bonded Peaks）

山河同契（模组 ID `bonded_peaks`）是一个服务端队伍模组。玩家用 `/bondedpeaks` 创建命名队伍、邀请他人加入、发送队伍专属聊天，并通过少量命令管理队长与成员。所有数据按世界存储在服务器 `serverconfig` 目录下。

模组不注册物品、方块、实体、配方、进度、音效或网络载荷，完整玩法表面只有命令树与内存/磁盘中的队伍状态。

## 速览

| 项目 | 当前实现 |
|:---|:---|
| 模组 ID | `bonded_peaks` |
| 显示名 | Bonded Peaks / 山河同契 |
| 主命令 | `/bondedpeaks` |
| 聊天快捷命令 | `/bp <消息...>` |
| 队伍名限制 | 1 到 12 个字母或数字，大小写不敏感 |
| 邀请过期提示 | 60 秒 |
| 存储位置 | `<世界>/serverconfig/bonded_peaks/` |
| 注册的物品/方块/实体/配方 | 无 |
| 配置 | 无 |

**注意：** 所有命令都向在线玩家开放，没有操作员权限检查；队伍归属规则在命令处理器内部执行。
