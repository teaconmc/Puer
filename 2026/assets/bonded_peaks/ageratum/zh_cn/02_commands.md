# 命令参考

以下命令都向每名在线玩家注册，均不要求操作员权限等级；队伍归属检查在处理器内部完成。

## 主命令

不带参数运行 `/bondedpeaks` 会打印三条帮助信息，列出子命令、`/bp` 聊天快捷命令以及队伍名规则。

| 命令 | 权限行为 | 结果 |
|:---|:---|:---|
| `/bondedpeaks create <名称>` | 任意玩家 | 创建以执行者为队长的队伍。 |
| `/bondedpeaks invite <玩家>` | 队伍队长 | 向目标玩家发出队伍邀请。 |
| `/bondedpeaks accept` | 任意玩家 | 接受执行者最新收到的邀请。 |
| `/bondedpeaks accept <邀请者>` | 任意玩家 | 接受来自该指定邀请者的邀请。 |
| `/bondedpeaks leave` | 非队长成员 | 让执行者离开当前队伍。 |
| `/bondedpeaks disband` | 队伍队长 | 将队长的解散确认标记为待处理。 |
| `/bondedpeaks confirm` | 队伍队长 | 在有待解散请求时删除队伍。 |
| `/bondedpeaks kick <玩家>` | 队伍队长 | 将成员移出队伍。 |
| `/bondedpeaks transfer <玩家>` | 队伍队长 | 将队长转让给当前成员。 |
| `/bondedpeaks list` | 任意玩家 | 列出所有队伍：名称、人数与队长名。 |
| `/bondedpeaks info` | 任意队伍成员 | 显示执行者本人队伍：队长、人数、成员名单与创建时间。 |
| `/bondedpeaks info <名称>` | 任意队伍成员 | 注册了名称参数，但当前实现忽略该参数，仍显示执行者本人队伍。 |
| `/bondedpeaks chat <消息...>` | 任意队伍成员 | 向在线成员发送队伍专属消息。 |

`/bp <消息...>` 是 `/bondedpeaks chat <消息...>` 的直接快捷命令，没有其他子命令。

## 队伍聊天格式

聊天消息只以系统消息形式发送给发送者队伍中的在线成员，本地化格式为 `[同契·<队伍>] <显示名>：<消息>`。它不会广播给整个服务器，也不会发给其他队伍。

## 命令事实

- 目标玩家使用 `GameProfileArgument`，因此目标必须能解析为服务器已知的唯一玩家。
- 队长始终保存在成员名单第一位。
- `list` 按创建时间排序，再按名称（不区分大小写）排序。
- `info` 的创建时间按存储值格式化，但存在时间单位问题，见[存储与持久化](03_storage_and_persistence)。
