# 工业基石

工业基石提供三套互相衔接的基础网络：机械轴、电力与水管。一个完整的转换链可以是：**小型蒸汽机 -> 传动杆 -> 发电机 -> 电网 -> 电动机 -> 第二套机械轴**。

## 阅读路线

1. [小型蒸汽机](01_steam_engine)：加水、添加燃料并辨认机械与流体端面。
2. [机械网络](02_mechanical_network)：布置传动杆和轴连接器，理解转速、阻力与断杆。
3. [电力网络](03_electric_network)：使用发电机、电动机、导线方块、接线桩和导线卷。
4. [水管网络](04_fluid_network)：连接铁管道与流体储罐，并了解当前水泵状态。
5. [合成配方](05_recipes)：查看当前资源中全部可用工作台配方。
6. [故障排查](06_troubleshooting)：按能量链逐段检查朝向、连接、负载和未完成功能。

## 最短搭建顺序

1. 放置小型蒸汽机，并沿其轴线一端接上传动杆。
2. 让传动杆接到发电机的机械面。
3. 从发电机背面的电气面接出导线方块，或贴上接线桩。
4. 把电网接到电动机背面的电气面。
5. 从电动机朝向面继续接出传动杆。

::: warning
本模组的端面有方向限制。方块看似相邻并不代表网络已经连通；首次搭建时应从蒸汽机开始逐段确认。
:::
