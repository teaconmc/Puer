# 连胜排行榜

## 方块

<block id="shengpi:leaderboard"/>

模组只注册一个方块 `shengpi:leaderboard`（以及同名的方块物品）。放置后会在地块上方生成一组浮空的**文本展示**行；开采时掉落方块本身（可抵御爆炸）。方块由蜂蜜块和铜块纹理渲染，地图色呈金色。

## 显示内容

排行榜在放置时生成，之后每 **40 tick** 刷新一次，渲染 **12 行浮空文本**：

- 一行标题（连胜排行榜），
- 一条分隔线，
- 以及按**最佳连胜**从高到低排列的**前十名**玩家。

每行排名形如 `#1  <名字>  ⧩×<连胜>`. 只有最佳连胜大于 0 的玩家会被列出，所以在有人取得连胜之前，排行榜会保持空白。

::: note
排行榜排名依据的是**最佳连胜**，而不是当前连胜。上榜玩家不必在线也能保留名次，但显示的名字来自在线玩家列表——离线玩家可能以截断的 ID 而不是名字出现。
:::
