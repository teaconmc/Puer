# 圣脾（Shengpi）

圣脾是一个「蜂蜜块占卜」模组。手持**两个或以上蜂蜜块**并右键，把一对蜂蜜块抛向空中；落地时它们的正反面决定三种吉凶结果——圣脉、笑脉或怒脉。掷出正确的组合可以积攒个人连胜，再用浮空的排行榜方块展示你的最佳纪录。

## 阅读路线

1. [蜂蜜块占卜](01_divination)：如何占卜、结果的含义以及如何判定。
2. [连胜](02_streaks)：连胜如何累积、如何被打断，以及如何跨越死亡保留。
3. [连胜排行榜](03_leaderboard)：排行榜方块及其显示的浮空前十名。

## 快速说明

| 项目 | 当前实现 |
|:---|:---|
| 模组 ID | `shengpi` |
| 方块 | `shengpi:leaderboard` |
| 自定义物品 | 无（使用原版 `minecraft:honeycomb`） |
| 配方 | 无 |
| 吉凶结果 | 圣脉、笑脉、怒脉 |
| 每次消耗 | 2 个蜂蜜块 |
| 阻止占卜的条件 | 配置关闭、游泳、在水下、骑乘、旁观、睡觉 |
| 配置 | `enabled`（默认 `true`） |

::: note
占卜使用的是原版**蜂蜜块**（`minecraft:honeycomb`），而不是自定义物品。模组不注册任何自定义物品，也没有配方——照常从蜜蜂那里获取蜂蜜块即可。
:::
