# 喷气助推器

`momentum:jet_booster` 是「动量」注册的唯一物品。

## 物品属性

| 属性 | 数值 |
|:---|:---|
| 堆叠上限 | 1 |
| 稀有度 | 稀有 |
| 可附魔度 | 22 |
| 装备槽位 | 护腿 |
| 护甲 | +5.0（`momentum:jet_booster_armor`，加算，护腿） |
| 护甲韧性 | +2.0（`momentum:jet_booster_toughness`，加算，护腿） |
| 创造分页 | 原版战斗 |

由于它可附魔且占用护腿槽位，它与真正的护腿存在竞争——你获得整套移动能力，但要放弃本可穿在该槽位的护甲，除非改用 Curios 腰带槽位。

游戏内提示文本在运行时注入，内容为：提升移动速度、跳跃高度与上台阶高度；允许在空中闪避；墙跑不会下坠；减少所有摔落伤害。

## 模组如何检测它

每刻，移动上下文按顺序检查：

1. 物品是否在玩家的**护腿**槽位？
2. 否则，若 Curios 已加载，是否有 Curios 槽位持有它？

任一命中都会设置内部 `hasJetBooster` 标志。标志变化时会立即重新应用属性修饰符，因此切换是即时的，无需重生或重新登录。

## 助推器改变了什么

**必须依赖它的能力**——无论配置如何，没有助推器就完全不起作用：

- 水上漂（`enableWaterRun`）
- 缓降（`enableFallSlow`）
- 空中二段跳（`enableAirJump`）
- **在空中**闪避——地面闪避不需要助推器

**它强化的能力：**

- **墙跑**不再下坠。没有助推器时墙跑会持续掉高度；佩戴后会施加向上速度以维持线路。
- **攀墙**获得保证的最低向上速度。
- **摔落伤害**被双重削减：有效摔落距离减少 **12 格**，且伤害倍率减半（**×0.5**）。这与 [05 空中与水中](05_air_and_water.md) 所述的受身减免叠加。
- **体力消耗**按 `boosterStaminaReduction` 打折，默认为 `1.0`——即完全豁免。

## 与饥饿值的关系

服务端选项 `maneuverConsumeHunger` 默认为 **`false`**，因此机动默认免费。管理员启用后，每个机动刻会消耗 `maneuverConsumeHungerAmount`（默认 `0.01`）的疲劳值，助推器的 `boosterStaminaReduction` 折扣在此之上生效。

## Curios 集成

Curios 被声明为**可选**依赖，版本范围不限。兼容层在触碰任何 Curios 类之前先检查 `ModList`，因此没有 Curios 时模组也能干净加载。存在 Curios 时，附带的标签文件把助推器加入腰带槽位，让你能继续穿真正的护腿。
