# AnvilCraft: NekoPLUS!

AnvilCraft: NekoPLUS! (mod id `nekoplus`) is an addon for AnvilCraft that requires `anvilcraft` 1.5.0 or later. It targets Minecraft 26.1.2 / NeoForge 26.1.2.75 and adds its own creative tab, enhancement modules with a dedicated data component, custom recipe types, titanium alloy materials, power and machine blocks, and multi-block structures on top of AnvilCraft's machinery. A common config and a client inspection command are also provided.

## Reading Order

1. [Getting Started](01_getting_started): prerequisites, the creative tab, the titanium alloy material chain, enhancement modules and a first super-heating recipe.
