# 铁砧工艺：猫+!

铁砧工艺：猫+!（模组 ID `nekoplus`）是铁砧工艺（AnvilCraft）的扩展模组，硬依赖 `anvilcraft` 1.5.0 及以上版本。它面向 Minecraft 26.1.2 / NeoForge 26.1.2.75，在铁砧工艺的机制之上加入自己的创造栏、带专用数据组件的增强模块、自定义配方类型、钛合金材料、电力与机器方块以及多块结构，并提供通用配置与客户端检查命令。

## 阅读路线

1. [开始使用](01_getting_started)：前置依赖、创造栏、钛合金材料链、增强模块与第一个超级加热配方。

## 快速说明

| 项目 | 当前实现 |
|:---|:---|
| 模组 ID | `nekoplus` |
| 显示名称 | AnvilCraft: NekoPLUS! |
| 源码目标 | Minecraft 26.1.2 / NeoForge 26.1.2.75 |
| 必需依赖 | 铁砧工艺（`anvilcraft`）>= 1.5.0 |
| 模组版本 | 26.1.1-alpha.1 |
| 创造栏 | `itemGroup.nekoplus.tab`，图标为高能激光 |
| 数据组件 | `nekoplus:enhancement_module` |
| 自定义配方类型 | 已注册（使用铁砧工艺的超级加热等机制） |
| 生成配方（示例） | `nekoplus:advanced_processor`、`nekoplus:battery`、`nekoplus:particle_stabilizer`、`nekoplus:titanium_alloy_ingot_superheating` |
| 配置 | 通用配置 `NPConfig` |
| 命令 | 提供客户端检查命令 |

::: note
NekoPLUS! 建立在铁砧工艺之上。请先安装铁砧工艺 1.5.0 或更高版本；本模组不会替换铁砧工艺的任何内容。
:::
