# 编辑玩家与文字

## 打开编辑器

创造模式玩家对已放置的玩偶普通右击即可打开编辑器。编辑器包含“玩家 ID”和“简短内容”两个输入区，以及“取消”和“完成”按钮。

- **完成**：把两个输入区的当前内容发送到方块并关闭界面。
- **取消**：关闭界面，不发送本次修改。

::: tip
潜行右击用于切换姿势，不会打开编辑器。若只想修改文字，请保持站立状态再交互。
:::

## 玩家 ID

玩家 ID 最多接受 `64` 个字符。保存非空内容后，玩偶会创建一个未解析的玩家档案，并由客户端皮肤缓存查找对应皮肤。

- 使用准确的玩家名称最容易得到预期皮肤。
- 输入空字符串会清除档案，渲染器随后使用默认玩家皮肤。
- 皮肤尚未解析或解析失败时，也可能暂时显示默认皮肤。

玩家 ID 只决定玩家档案与皮肤，不会改变姿势或方块朝向。

## 简短内容

简短内容编辑框最多接受 `16` 行。保存空白内容时，玩偶头顶不会渲染文字。

渲染器会把内容按最多 `100` 像素的文字宽度再次自动换行，因此游戏中显示的行数可能多于编辑框中手动输入的行数。文字以白色绘制在带透明背景的区域中，并同时跟随观察者的水平和俯仰视角。

## 数据保存

玩家档案、当前姿势和简短内容都会写入方块实体并同步给客户端。编辑器只修改玩家档案和简短内容；姿势需要在世界中单独切换。
