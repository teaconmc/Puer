# 展示玩偶

展示玩偶加入了一个使用玩家皮肤的装饰方块。它可以保存玩家档案、切换六种姿势，并在头顶显示始终朝向观察者的简短文字。

## 阅读路线

1. [开始使用](01_getting_started)：取得并放置玩家玩偶，了解创造模式限制。
2. [编辑玩家与文字](02_editing)：设置玩家 ID、简短内容并理解保存行为。
3. [姿势、朝向与复制](03_poses_and_copying)：切换姿势，调整摆放方向并复制皮肤预设。

## 快速说明

| 项目 | 当前实现 |
|:---|:---|
| 内容数量 | 一个物品兼方块：`displaydoll:player_doll` |
| 生存配方 | 无 |
| 编辑权限 | 仅创造模式玩家 |
| 姿势数量 | 六种 |
| 额外用途 | 可装备在头部栏位 |

::: warning
模组目前是创造模式展示工具。生存模式玩家可以放置玩偶，但不能使用编辑器或切换姿势。
:::
