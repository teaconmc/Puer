# 姿势、朝向与复制

## 六种姿势

创造模式玩家潜行右击玩偶，会按固定顺序循环姿势：

1. 默认（Default）
2. 随意挥手（Casual Wave）
3. 欢呼（Cheer）
4. 完美平衡（Perfect Balance）
5. 害羞姿势（Shy Pose）
6. 僵尸（Zombie）

从僵尸姿势继续切换会回到默认姿势。宽臂与纤细手臂皮肤各有一套对应模型，姿势名称和循环顺序相同。

## 姿势与方块朝向

姿势只改变身体模型，不改变方块保存的 `16` 段水平旋转。要让多个玩偶面向不同方向，需要按目标方向分别放置；循环姿势不会旋转底座。

头顶文字独立朝向镜头，因此无论玩偶身体朝向哪里，观察者都能从正面阅读文字。

## 选取方块复制

对已放置的玩偶使用选取方块，会得到一个带有该玩偶玩家档案的物品。这适合快速复制同一皮肤，但复制范围刻意很窄：

| 数据 | 是否复制 |
|:---|:---:|
| 玩家档案与皮肤 | 是 |
| 当前姿势 | 否 |
| 简短内容 | 否 |
| 放置朝向 | 否 |

重新放置复制物后，它会使用默认姿势、空白文字和新的放置朝向。若要制作一组同皮肤但不同动作的展品，先复制皮肤，再逐个设置姿势与文字即可。

::: warning
不要把选取方块当作完整的数据备份。重要的文字内容需要另外记录，姿势也必须重新选择。
:::
