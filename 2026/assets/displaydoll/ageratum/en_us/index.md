# Display Doll

Display Doll adds one decorative block based on player skins. It stores a player profile, cycles through six poses, and can show a short message that always faces the viewer.

## Reading order

1. [Getting started](01_getting_started): obtain and place a Player Doll, and understand the Creative-mode restriction.
2. [Editing players and text](02_editing): set the Player ID and Short Content and understand how changes are saved.
3. [Poses, orientation, and copying](03_poses_and_copying): cycle poses, control placement direction, and copy a skin preset.

## At a glance

| Topic | Current implementation |
|:---|:---|
| Content | One item and block: `displaydoll:player_doll` |
| Survival recipe | None |
| Editing permission | Creative players only |
| Poses | Six |
| Extra use | Equippable in the head slot |

::: warning
The mod is currently a Creative-mode display tool. Survival players can place a doll, but cannot use its editor or change its pose.
:::
