# 多彩水晶

多彩水晶（命名空间 `colorful_crystals`）加入了三种彩色宝石系列：**黄玉**、**红宝石**与**蓝宝石**。每个系列都有一种矿石方块、一种晶簇、三种宝石物品，以及两整套建筑方块。

所有宝石都走同一条三段加工链：**原石**在原版切石机上切割成**粗**宝石，粗宝石再在原版砂轮上打磨成**抛光**宝石。粗宝石与抛光宝石各自拥有一套储存方块、楼梯与台阶，因此每种颜色最终提供两种完整的建筑材料。

模组共注册 **24 个方块**与 **33 个物品**（24 个方块物品加 9 个宝石物品），全部集中在唯一的创造页 **多彩水晶**（`colorful_crystals:tab`）中，页签图标为黄玉晶簇。

> **重要：** 当前源码中**完全没有世界生成**——没有生物群系修改器，没有 configured / placed feature，也没有可生长的水晶母岩方块。矿石方块与晶簇在生存模式中**没有任何自然生成来源**，不要指望挖洞就能找到它们。

## 内容一览

| 分类 | 内容 | 说明 |
|:---|:---|:---|
| 宝石物品 | `raw_topaz`、`unpolished_topaz`、`polished_topaz`（红宝石与蓝宝石同理） | 共 9 个物品，每种颜色三个阶段 |
| 矿石方块 | `topaz_ore`、`ruby_ore`、`sapphire_ore` | 掉落对应的**原石**，受时运影响 |
| 晶簇方块 | `topaz_cluster`、`ruby_cluster`、`sapphire_cluster` | 掉落对应的**粗**宝石，受时运影响 |
| 粗宝石建筑套件 | `unpolished_<gem>_block`、`unpolished_<gem>_stair`、`unpolished_<gem>_slab` | 共 9 个方块 |
| 抛光宝石建筑套件 | `polished_<gem>_block`、`polished_<gem>_stair`、`polished_<gem>_slab` | 共 9 个方块 |
| 创造页 | `colorful_crystals:tab` —— 「多彩水晶」 | 唯一的创造页，图标为黄玉晶簇 |
| 世界生成 | **无** | 没有生物群系修改器、feature 或母岩方块 |
| 战利品表 | 24 个方块战利品表 | 矿石与晶簇使用矿物掉落模板，其余自掉落 |
| 配方 | 36 个配方 JSON 文件 | 合成 + 切石；矿石与晶簇**没有**配方 |

## 兼容性

模组附带一个可选的 JEI 插件，把两个加工步骤显示为配方分类。没有 JEI 时机制完全不变，只是少了游戏内的查询页面。
