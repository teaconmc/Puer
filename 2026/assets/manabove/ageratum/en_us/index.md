# ManAbove

ManAbove (高人一等) is a small player-interaction mod: ride another player, choose where you sit, and fling the player who rides you into the air along your view direction.

## At a glance

| Item | Value |
|:---|:---|
| Mod ID | `manabove` |
| Version | 0.0.3 |
| License | GNU AGPL 3.0 |
| Minecraft | 26.1.2 |
| NeoForge | 26.1.2.36-beta |
| Registries | 2 entity attachments (`manabove:vehicle`, `manabove:ride_pos`) and 2 sound events (`manabove:pretentious`, `manabove:weightlessness`) |
| Keybindings | `R` (Ride Player / Fly Up), `Ctrl+1`–`Ctrl+4` (pose selection) |
| Items / Blocks / Entities / Recipes / Commands | none |
