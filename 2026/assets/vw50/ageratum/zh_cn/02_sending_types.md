# 发送与红包类型

打开发送菜单时，你要在四种属性类型中选择一种。类型决定了领取方式以及礼物如何分配。

## 普通

礼物组会尽量平均地分给所选人数。每位领取者得到大致相同的数量。

## 拼手气

领取结果随机。每位领取者得到 `1` 到约 `2 ×（剩余数量 / 剩余份数）` 个物品，同时保证为其他人至少留下 `1` 个。先到先得的运气决定谁能中大奖。

## 口令

玩家必须在聊天中发送对应的口令才能领取。口令会显示在聊天卡片上，任何人都可以复制并发送。发送口令本身仍是普通的公开聊天消息，同时也会为发送者排队领取。

::: note
以 `/` 开头的口令在组包时会被拒绝。口令区分大小写，并会去除首尾空白。
:::

## 专属

只有指定的唯一一名玩家可以领取。发送时该名字必须对应一名在线玩家（不能指定离线玩家）。

## 过期与退回

每个红包都有一个决定过期行为的选项。默认红包存在 **8 小时**游戏时间后过期。

- **过期退回（默认）**：未领取的物品退回给发送者的背包；若发送者离线，则在其下次登录时送达。
- **过期销毁**：不退回任何物品，未领取的部分丢失。

::: warning
专属红包会把 `playerCount` 强制为 `1`。人数多于物品数、专属目标离线、标题过长或属性值过长，都会在任何领取发生前拒绝发送。
:::
