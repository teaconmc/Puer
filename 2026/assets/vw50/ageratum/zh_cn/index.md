# V我50（VW50）

VW50 在 Minecraft 加入了经典的「红包」。把任意一组物品作为礼物发出，指定可领取的人数，并选择普通、拼手气、口令或专属等类型。领取通过聊天卡片完成，礼物在玩家之间流转，无需任何服务端货币。

## 阅读路线

1. [获取红包](01_sending)：合成空红包并打开发送菜单。
2. [发送与红包类型](02_sending_types)：放入礼物槽、设置人数，并选择普通 / 拼手气 / 口令 / 专属。
3. [领取](03_claiming)：玩家如何领取、排队顺序、过期与退回。
4. [命令](04_commands)：`/vw50` 命令家族与复读限制。

## 快速说明

| 项目 | 当前实现 |
|:---|:---|
| 模组 ID | `vw50` |
| 物品 | `vw50:empty_red_envelope` |
| 配方 | `vw50:empty_red_envelope`（无序合成） |
| 红包类型 | 普通、拼手气、口令、专属 |
| 默认发送冷却 | 30 秒（非游戏管理员） |
| 默认过期 | 8 小时游戏时间 |
| 货币 | 仅物品堆叠，无计分板货币 |

::: note
红包装的是真实的物品堆叠，而不是虚拟货币。普通（非拼手气）红包会把整组物品尽量平均分配，例如 7 个分给 3 人时会得到大致相等的份数。
:::
