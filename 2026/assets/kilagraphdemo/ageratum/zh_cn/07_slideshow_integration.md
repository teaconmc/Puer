# 幻灯机集成

此功能仅在安装了可选的 **`slide_show`** 模组时存在。缺少它时 KilaGraphDemo 的其余部分照常工作，本页不适用。

## 它加入了什么

在 `slide_show` 存在时，KilaGraphDemo 会修补投影仪界面，加入一个 **KilaGraph Shader** 按钮。你可以由此编写着色器图，并把它作为实时特效应用到该投影仪上——所有人可见，不只是你自己。

于是投影仪不再只能显示静态图片或动画序列，而可以显示你所写节点图的输出。

## 工作流

投影仪界面列出**本地作品**与**服务器作品**，各自带标题与描述。

| 操作 | 效果 |
|:---|:---|
| 新建 | 创建一个空白的本地着色器特效 |
| 编辑 | 在图编辑器中打开该特效 |
| 保存元信息 | 把编辑后的标题与描述保存到本地 |
| 上传 | 把该特效发布到服务器 |
| 下载（本地编辑） | 把分享的特效复制到你的本地列表 |
| 用在此投影仪 | 在此投影仪上向所有人展示该特效 |
| 从投影仪清除 | 停止此投影仪上的特效 |
| 删除（本地） | 移除你的本地副本 |
| 从服务器删除 | 永久移除已发布的特效 |

当前正在某处使用的特效会被标注 **（使用中）**，这可以避免你在没注意的情况下删掉某个建筑正依赖的东西。

## 分享规则完全相同

上传着色器特效走的是与全息作品完全相同的发布系统——包括**每位玩家仅一件已发布作品**的限制与全部尺寸上限。详见 [06 分享与限制](06_sharing_and_limits)。

这个共用的限制值得提前规划：你唯一的发布位**同时**覆盖全息作品与幻灯机特效，因此你要在两个功能之间选出一件展品，而不是各选一件。

## 编辑器是同一个

着色器特效使用与全息作品相同的图编辑器，因此同样的条件适用——最重要的是**着色器图无法在启用 Iris 光影包时编辑**。请先禁用光影。详见 [05 全息投影](05_holograms)。

## 它是如何挂接的

该集成实现为一份**独立的、条件式的 mixin 配置**。一个 mixin 插件在加载时决定是否应用它，因此当 `slide_show` 不存在时这些补丁根本不会激活——这正是这个可选依赖安全而非易崩的原因。

补丁挂接到投影仪的方块实体、渲染器、渲染状态与界面。模组还接触了幻灯机模组用于静态图、GIF 与 WebP 的位图提供器，以及它的贴图序列纹理，这正是让一张图能采样投影仪自身当前图像（而不只是外部贴图）的原因。

排查提示：如果没看到 KilaGraph Shader 按钮，说明集成没有加载，而这几乎总是意味着 `slide_show` 不存在或它自身加载失败。
