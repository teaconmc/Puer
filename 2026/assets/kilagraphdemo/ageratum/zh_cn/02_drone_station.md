# 无人机编程站

无人机编程站是你编写、测试与提交无人机程序的地方。它持有一台虚拟无人机并驱动农场运行。

## 搭建

编程站需要一块田。请把**肥沃土壤直接放在编程站方块的正下方**。若忘记，编程站会提示你：

> 编程站下方没有肥沃土壤——请在其正下方放置肥沃土壤。

你放置的土壤就是你用来试验的田地。请注意这块世界内的田地是你的**练习场**——官方分数是在另一块固定田地上计算的，因此你的布局无法影响排名。详见 [04 农场与评分](04_farm_and_scoring)。

## 运行控制

编程站界面有六个按钮加一行状态。

| 控件 | 效果 |
|:---|:---|
| 运行 | 从头开始执行程序 |
| 暂停 | 暂停正在运行的程序 |
| 继续 | 恢复已暂停的运行 |
| 单步 | 精确推进一刻 |
| 停止 | 停止运行并重置无人机 |
| 上传 | 提交当前程序以供评分 |

状态行读作 `状态 · tick N · score N`，因此你可以在程序运行时观察刻计数与已入账分数的攀升。

**单步是让调试成为可能的工具。** 配合打印节点（见 [03 无人机节点](03_drone_nodes)）与日志面板，你可以一刻一刻地推进，看清你的图究竟做了什么决定。

## 四种运行状态

| 状态 | 含义 |
|:---|:---|
| 空闲 | 无程序运行；田地保持你摆放的样子 |
| 运行中 | 正在服务端执行 |
| 已暂停 | 所有者可以继续、单步或停止 |
| 已结束 | 运行达到刻预算并已评分 |

**服务端是权威方。** 客户端只镜像状态用于渲染以及判断哪些按钮可用，因此你看到的始终反映真实运行，而不是本地猜测。

## 暂停的运行不会无限等待

已暂停的运行在 **12000 刻——即十分钟**真实时间后过期，此后编程站会放弃它。

值得向读源码的人指出：该上限旁的代码注释写的是「5 minutes」，但表达式是 `20 * 60 * 10`，按每秒二十刻算是**十**分钟。实际行为是十分钟，注释写错了。

## 两道你可能撞到的保护

**每刻步数上限为 10000。** 在一刻之内，运行时会持续执行*纯逻辑*节点，直到遇到一个*动作*节点。如果某个图在逻辑节点之间循环却从不提交动作，这道上限会阻止它，而不是让服务器卡死。实践中撞到它意味着你的图里有一个不含动作的循环。

**运行日志保留 200 行。** 打印节点会向滚动日志追加内容并显示在界面的日志面板中；超过 200 行后旧行会被丢弃。若你每刻都在打印，只有最近的一段会留存。

## 谁能做什么

编程站归搭建它的人所有，由所有者驱动运行。

**无人机排名展示**是刻意不同的：任何人都可以打开它的查看器来观看某个排行榜条目的回放。它是一块观众屏幕，而不是第二个控制台——详见 [04 农场与评分](04_farm_and_scoring)。
