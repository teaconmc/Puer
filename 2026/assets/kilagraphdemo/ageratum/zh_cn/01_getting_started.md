# 开始使用

## 依赖

| 模组 | 要求 |
|:---|:---|
| `kilagraph` | **必需**——本模组所展示的节点图库 |
| `slide_show` | 可选——启用投影仪着色器特效功能 |
| `neoforge`、`minecraft` | 必需 |

缺少 `kilagraph` 模组不会加载。缺少 `slide_show` 时其余功能照常工作，仅 [07 幻灯机集成](07_slideshow_integration) 不可用。

## 如何获得这些方块

模组**完全不附带 data 目录**——没有配方、没有战利品表、没有标签。两个后果：

- **任何东西都无法合成。** 请使用创造分类 **KilaGraph Mod Tab**，或用 give 命令。
- **任何东西都不掉落。** 没有战利品表，破坏这些方块会摧毁它且不返还物品。请谨慎放置。

## 七个方块

| 方块 | 作用 | 硬度 | 说明 |
|:---|:---|:---|:---|
| 全息投影 | 展示本地着色器图作品 | 2.0 | 发光等级 7 |
| 服务器全息投影 | 向所有人展示服务器存储的作品 | 2.0 | 发光等级 7 |
| 肥沃土壤 | 无人机游戏的可种植场地 | 0.6 | |
| 无人机编程站 | 持有虚拟无人机并驱动运行 | 2.0 | |
| 无人机排名展示 | 回放指定排行榜名次 | 2.0 | 由红石选择 |
| 无人机计分板 | 列出无人机排行榜前列玩家 | 2.0 | |
| 全息点赞计分板 | 列出最受欢迎的分享作品 | 2.0 | |

除肥沃土壤外全部不遮蔽光照，且都带有方块实体。

请注意两个全息方块目前**共用同一套模型与贴图**，肥沃土壤也复用了原版耕地风格的占位模型。它们靠行为区分，而不是外观。

## 两种全息方块的差别

它们外观相同，区别在于作品存放在哪里：

- **全息投影**展示**你自己本地库**中的作品。你看到的就是你下载或创作的东西。
- **服务器全息投影**展示在**服务端**选定的作品，由每个客户端按需拉取。所有人看到同一内容，设置它会影响全体玩家。

自己迭代作品时用普通全息投影；做共享展台时用服务器全息投影。

## 从哪个功能开始

想玩解题就去 [02 无人机编程站](02_drone_station)——你需要一个无人机编程站，且下方放置肥沃土壤。

想做视觉作品就去 [05 全息投影](05_holograms)。
