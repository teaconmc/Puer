# Lend & Regret

Lend & Regret is currently an early NeoForge `0.0.1` development snapshot for Minecraft `26.1.2`.

The line "Borrow me diamonds? Here's a fish in three days" is flavor text. The present source does not yet implement lending, repayment, debt collection, or item exchange, so this documentation covers only content that is registered and verifiable in game.

## Reading path

1. [Current Content](01_current_content): the creative tab, icon item, how to obtain it, and the implementation boundary.

## In one sentence

This version contains one creative mode tab and one ordinary icon item, with no blocks, recipes, commands, keys, configuration, or lending system.
