# 卡牌与战斗

## 战斗准备

战斗开始时——踩到怪物格，或与另一名玩家相遇——会打开**战斗准备**界面。它显示：

| 元素 | 含义 |
|:---|:---|
| **攻击方** / **防守方** | 你处在哪一边 |
| **消耗** | 出这张牌要付什么 |
| **准备就绪** | 锁定你的选择 |

双方各自准备，然后本轮结算。**你在哪一边是有影响的**，因为攻击牌与防御牌会依你的身份做不同的事。

## 攻防各分三个等级

最常见的牌是分级的，等级就写在名字里：

| 牌 | 等级 |
|:---|:---|
| 攻击 (M) / 攻击 (L) / 攻击 (G) | 三档攻击 |
| 防御 (M) / 防御 (L) / 防御 (G) | 三档防御 |

::: tip
**手里要留各档的牌，而不是只留最大的。** 牌有消耗值，因此最高等级并不总是出得起——一手全是重牌可能让你无牌可打。混合手牌能保证你**总有东西**放得下去。
:::

## 多数牌只在战斗中有用

牌会被标记为「仅战斗」或不是。**攻击牌与防御牌属于仅战斗**——你单纯在棋盘上走路时它们什么都不做。其他牌则可以在战斗之外使用。

所以一手看起来很强的牌，在两场战斗之间可能完全闲置；这是预期行为而非故障。

## 目标与射程

每张牌都声明自己如何选取目标、能打多远。有些牌完全不需要目标——直白的攻击与防御牌就属这类，这也是它们成为牌组可靠骨干的部分原因。

## 牌组的其余部分

除攻防之外还有几十张具名卡牌。举一部分：

| 牌 | |
|:---|:---|
| **屏障**、**路障**、**强化路障** | 防护 |
| **狂暴**、**冲锋**、**爆破**、**撕咬** | 进攻 |
| **龙吼**、**灰羽**、**彩羽** | 主题效果 |
| **砖块**、**拆除**、**陷阱** | 干扰 |
| **巧克力蛋糕**、**能量棒**、**过期便当** | 食物 —— 并非都对你有好处 |
| **打起精神**、**命运指引**、**定向增益** | 支援 |
| **全有或全无**、**以眼还眼**、**你有的我也有** | 高风险摇摆 |

::: info
**卡牌名本身就说明了设计取向。** 「过期便当」挨着「巧克力蛋糕」、「全有或全无」挨着「以眼还眼」，这是一副为派对式摇摆而设计的牌组，不是为精算优化设计的。出一张新牌前花一秒看它的提示文本是值得的。
:::

## 会变成实体的牌

有些牌会真的在棋盘上射出东西：

| 实体 | 来自 |
|:---|:---|
| **卡牌弧线弹丸** | 弧线型卡牌攻击 |
| **卡牌激光** | 一道光束 |
| **卡牌落砖** | 砖块牌 |
| **弹弓弹丸** | 弹弓攻击 |
| **雪球攻击弹丸** | 雪球攻击 |
| **高升炮弹丸** | 炮台格的炮弹 |
| **灵魂链接** | 战斗者之间的连接 |

它们是有自己飞行轨迹的真实弹丸，所以战斗中**站位并非纯装饰**。

## 战斗中的角色技能

你角色的主动技能与手牌是分开的——它绑在**使用角色技能**键上，有自己的冷却。共有五种技能效果：

| 效果 | |
|:---|:---|
| **攻击提升** | 提高攻击 |
| **防御护盾** | 提高防御 |
| **暗影斗篷** | 隐蔽 |
| **零食时间** | 食物主题效果 |
| **角色技能状态** | 通用标记 |

::: tip
**技能冷却在打怪与玩家决斗之间是不同的。** 请按你的 PVP 冷却来规划一场决斗，而不是按你在棋盘上走路时习惯的那个 PVE 数字。见[角色](04_characters)。
:::
