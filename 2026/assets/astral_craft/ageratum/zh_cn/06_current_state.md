# 哪些做完了、哪些还没

吉星工艺是一个野心不小的游戏，已经做出了很多，也还有一些部分开着口。这一页告诉你边界在哪，以便你围绕「能用的部分」来安排一局。

## 今天就能用的

| 系统 | 状态 |
|:---|:---|
| **棋盘** | 全部 22 种格子都已实现且可放置 |
| **骰子与移动** | 可用，且支持分叉路径 |
| **卡牌** | 一副大牌组，含等级、消耗、目标与真实弹丸 |
| **战斗** | 攻守双方的准备与结算 |
| **角色** | 32 名已定义，含生命值、技能、羁绊与档案 |
| **技能** | 主动与被动，PVE 与 PVP 冷却分开 |
| **芯片** | 三档稀有度，属性曲线清晰 |
| **服装** | 58 套皮肤、6 档稀有度，带动画预览 |
| **卡背** | 可选择，其他玩家能看到 |
| **快捷短语** | 聊天快捷语可用 |
| **本地化** | **英文与中文都完整** —— 每种语言约 1850 条译文，两者完全对应 |

这是一个体量扎实、可以玩的派对游戏。

## 开长局前要知道的三处边界

::: warning
**1. 随包的棋盘是测试用循环，不是完整地图。**

它自己的说明写着这是供开发测试的最小棋盘图，并说正式地图应当改用结构模板来搭。

**这对你意味着什么：** 你得到一条能演示每种格子类型的短环线——适合学会这个游戏，但尺寸不足以支撑一晚的游玩。想要真正的地图，需要你或资源包作者自己搭一张。
:::

::: warning
**2. 32 名角色中有 26 名没有解锁说明。**

五名默认解锁（**Alana**、**Fanny**、**Komachi**、**Mimi**、**Parunan**），**LingLing** 告诉你要通过 AstralCraft 的冒险找到她。其余 26 名显示为**已锁定**且提示为空。

**这对你意味着什么：** 那些角色是被定义好的——有属性、技能与服装——但游戏没有告诉你怎么获得。请用那六名能拿到的角色来玩。
:::

::: warning
**3. 羁绊的奖励层尚未实装。**

羁绊会显示等级（常见上限为 6），但界面上带有一段明确的占位文字，说该区域预留给好感等级、礼物、契约与契约奖励。

**这对你意味着什么：** 你能看到一个羁绊数字，但目前还没有可以花掉它的地方。不要围绕送礼或契约来安排一局。
:::

## 只有四名角色有潜能

潜能系统——一项可解锁的技能强化——目前为 **Fen**、**Jill**、**Mimi** 与 **Z3000** 四名角色作了描述。其余 28 名有这个页签但没有定义潜能。

**值得一试的是 Mimi**，因为她既默认解锁又拥有潜能。

## 没有任何东西可以合成

吉星工艺的任何物品都没有配方、没有战利品表、也不能烧炼。一切都来自创造分页、`/give`，或棋盘本身。

::: info
**对派对游戏而言这是合理的选择**，不是疏漏——你不会希望为了玩一局桌游而先去刷素材。但这确实意味着**生存服务器需要管理员发放起始装备**，而且不存在「正常玩就能拿到投影仪」的进程路线。
:::

## 现在怎么玩得舒服

1. **在创造模式玩，或让管理员分发装备。**
2. **从六名可用角色里选** —— 想看潜能系统就试 Mimi。
3. **用随包棋盘学会各种格子**，把它当作教学环线。
4. **把重心放在卡牌与芯片上**，这两套是最完整的系统。
5. **把羁绊当作一个显示值**，而不是目标。

棋盘、牌组、战斗与芯片经济都是真正做完了的——那已经是一个完整的派对游戏。围绕它们的解锁层与羁绊奖励层，是还在建设中的部分。
