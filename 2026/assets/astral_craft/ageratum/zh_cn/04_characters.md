# 角色

共有 **32 名角色**。每人都是一个独立身份，有自己的生命值、技能、羁绊进度与衣橱。

## 怎么选

打开**角色设置**，使用**角色选择**界面：

| 按钮 | 作用 |
|:---|:---|
| **使用角色** | 扮演他们 —— 之后显示**使用中** |
| **归还玩家** | 变回你自己 |
| **角色详情** | 他们的完整档案 |
| **已锁定** | 你还没有这个角色 |

## 你开局就有哪些

**五名角色立即可用**，他们的提示写着「默认解锁」：

- **Alana**
- **Fanny**
- **Komachi**
- **Mimi**
- **Parunan**

另有一名告诉了你获取方式：

- **LingLing** —— 「通过 AstralCraft 的冒险解锁 LingLing。」

::: warning
**其余 26 名角色没有写明解锁方式。** 他们的解锁提示字段存在但是空的，因此游戏会给你看一个已锁定的角色却不给任何指引。

这不是靠更用心地玩就能解决的——那些信息根本还没写。请把五名默认角色加 LingLing 当作当前可用阵容，并参见[哪些做完了、哪些还没](06_current_state)。
:::

## 角色详情档案

每名角色的档案有四个部分：

| 部分 | 内容 |
|:---|:---|
| **档案** | 他们的背景文本 |
| **技能** | 主动与被动，含冷却 |
| **升级** | 等级成长 |
| **潜能** | 一项可解锁的强化 —— **只有部分角色有** |

## 技能：两个技能，四个冷却

每名角色都有一个**主动**与一个**被动**技能。主动技能绑在「使用角色技能」键上。

容易漏掉的一点是：**每个技能对怪物与对玩家的表现可能不同**，而两个冷却是分别列出的。

::: tip
举例来说，某个角色可能 PVE 冷却 3 回合、PVP 冷却也是 3 回合——但并没有规则要求两者相等。**在决定决斗之前请在角色详情里核对两个数字**，因为你在棋盘上走路时依赖的那个技能，在对抗另一名玩家时不一定同样频繁可用。
:::

## 潜能：只有四名角色有

**潜能**页描述一项可解锁的强化：

> *「这名角色拥有可解锁的潜能。」*
> *「激活后，该角色的技能得到强化。」*

**目前有潜能描述的是四名角色**：**Fen**、**Jill**、**Mimi** 与 **Z3000**。

::: info
Mimi 是值得留意的那一个——她**既是默认解锁又拥有潜能**，因此她是你开局就能实际探索这套系统的角色。
:::

## 羁绊

角色设置里显示**羁绊 x/y**——一条好感度进度，每名角色有各自上限（常见为 6 级）。

::: warning
**羁绊的奖励系统尚未完成。** 界面上带有一段占位文字直接说明了这一点：该区域预留给好感等级、礼物、契约与契约奖励，并注明奖励未来可能以独立卡片形式展示或与物品消耗挂钩。

所以羁绊今天会显示一个数字，但围绕它的「礼物与契约」那一层还没实装。不要围绕刷羁绊奖励来规划一局。
:::

## 服装

共有 **58 套角色皮肤**，分 **6 个稀有度档位**。角色设置里带动画预览，有**播放**与**暂停**，因此你可以在装备前先看一套服装的动画。

皮肤是装饰性的——它改变你角色的外观，不改变他们的能力。

## 生命值因角色而异

每名角色声明自己的基础生命值——例如有一位是 9。**角色在数值上并不相同**，因此换角色会改变你能承受多少打击，而不只是改变技能与外观。
