# 吉星工艺

**吉星工艺**是一款 Minecraft 里的派对棋盘游戏。你掷骰子前进、走过各种主题格子、用一整套卡牌战斗，并扮演 **32 名可收集角色**之一——每人各有技能、羁绊与服装。

可以把它看作三层叠在一起的游戏：**一张要走的棋盘**、**一副要打的牌**、**一个要养的角色**。

## 你会用到的东西

| 部件 | 作用 |
|:---|:---|
| **星象棋盘投影仪** | 铺开一张可玩的棋盘 |
| **星象骰子** | 决定你的移动 |
| **手牌** | 你的牌组 —— 攻击、防御与几十种花招 |
| **芯片** | 提升属性的装备 |
| **角色** | 你扮演谁，各有自己的技能 |

## 四个按键

棋盘之外的一切都在按键上：

| 按键 | 打开 |
|:---|:---|
| **打开角色设置** | 选角色、查看技能、羁绊与服装 |
| **使用角色技能** | 发动主动技能 |
| **打开卡背选择** | 选择其他玩家会看到的卡背 |
| **打开快捷短语** | 游戏中的聊天快捷语 |

它们都在控制设置的 **AstralCraft** 分类下，可自由改键。

::: tip
**在第一局开始前就设好角色，不要开局后再弄。** 角色设置界面才是装备「你扮演谁」的地方——在你设定之前，你就是你自己。**Alana** 与 **Fanny** 等五名角色开局即可用，所以你永远有得选。
:::

::: warning
**这个模组完全没有合成配方。** 其中任何物品都无法在工作台合成、无法烧炼、也不来自任何战利品表——棋盘部件、骰子、卡牌与芯片全都来自创造模式、`/give`，或来自棋盘本身的玩法。

对派对游戏而言这是合理设计，但意味着**生存世界不会主动给你投影仪**。见[你的第一局](01_your_first_game)。
:::
