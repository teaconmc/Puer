# 棋盘

棋盘由 **22 种格子**搭成，每种都是一个可放置方块。踩上去就触发它的效果。这一页是你前几局会想开着的参考表。

## 移动类

| 格子 | 名称 | 作用 |
|:---|:---|:---|
| `platform_start` | **检查点** | 圈数标记 —— 整条环线的锚点 |
| `platform_jump` | **跳跃** | 不按常规步进地送你一段 |
| `platform_move_again` | **急速** | 再走一次 —— 会连锁到你接下来踩到的格子 |
| `platform_teleport` | **传送门** | 把你送到棋盘别处 |
| `platform_teleport_point` | **突袭** | 一个目的地类格子 |

::: tip
**急速是让大回合成为可能的那个格子。** 因为它给你再走一次，踩到它就可能连锁出第二个效果——而一次幸运的「急速接横财」或「急速接彩票」正是一个回合突然翻盘的地方。
:::

## 获得类

| 格子 | 名称 | 作用 |
|:---|:---|:---|
| `platform_gold` | **横财** | 一笔进账 |
| `platform_gift` | **礼物** | 给你东西 |
| `platform_lottery` | **彩票** | 一次抽奖 |
| `platform_destiny` | **命运** | 一个命运结果 |
| `platform_card` | **卡牌弹跳** | 与卡牌相关 —— 补充你的手牌 |

## 消费类

| 格子 | 名称 | 作用 |
|:---|:---|:---|
| `platform_shop` | **商店** | 一般购买 |
| `platform_relic` | **芯片商店** | 购买**芯片** —— 你的装备，见[芯片与装备](05_chips_and_equipment) |

## 冒险类

| 格子 | 名称 | 作用 |
|:---|:---|:---|
| `platform_gamble` | **猜谜** | 一次赌注 |
| `platform_divine` | **占卜** | 一个占卜结果 |
| `platform_event` | **事件** | 触发棋盘事件之一 |
| `platform_gimmick` | **机关** | 一个花招格 |
| `platform_candy_ghost` | **古怪糖果机** | 一个怪东西 |

::: info
**芯片商店是值得为它规划路线的那个格子。** 芯片是永久属性提升且分三档品质，所以「带着钱走到芯片商店」通常比走到普通商店更有价值。见[芯片与装备](05_chips_and_equipment)。
:::

## 棋盘是分叉路径而不是一个圈

格子之间以图的方式相连——每个格子指明接下来通向哪些格子，而有些会指明**不止一个**。所以棋盘不是简单的圆环：你会遇到岔路并需要选方向。

这也是**检查点**重要的原因。无论你走了哪条分支，它都是整条环线回归的固定参照。

::: warning
**模组随包的棋盘是一小段开发用循环，不是成品地图。** 它自己的说明写着这是供开发测试的最小图，并说正式地图应当用结构模板来搭。

实际效果是：你得到一条能展示每种格子机制的短环线——足够学会这个游戏，但不足以支撑一整晚的游玩。想要真正的地图，需要你或资源包作者自己搭。见[哪些做完了、哪些还没](06_current_state)。
:::
