# 芯片与装备

**芯片**是你的装备。它们永久提升你的属性，在**芯片商店**格（`platform_relic`）购买。

## 三个稀有度档位

每个芯片都有稀有度，档位以颜色命名：

| 稀有度 | 位置 |
|:---|:---|
| **蓝色** | 基础 |
| **紫色** | 中档 |
| **金色** | 最好 |

## 档位之间是真实的力量跃升，不是小步递增

以三档都有的拳击手套为例：

| 芯片 | 稀有度 | 攻击 |
|:---|:---|---:|
| 拳击手套（基础） | 蓝色 | **+1** |
| 拳击手套（良好） | 紫色 | **+2** |
| 拳击手套（优秀） | 金色 | **+5** |

::: tip
**看这条曲线：1 → 2 → 5。** 金色不是比紫色好 50%——而是**两倍以上**。从蓝色到金色是同一件装备上的**五倍**跃升。

实际后果是：**攒钱买一个金色芯片，通常胜过买好几个蓝色的。** 如果你能带着真金白银走到芯片商店，请等最高档，而不要图便宜把格子填满。
:::

## 芯片是成套的

芯片以家族形式出现——同一件东西的不同品质。除拳击手套外还有如**摩托头盔**这一系列，每个家族针对特定属性。

由于芯片的属性就写在物品上，你可以在决定购买前准确看到它给什么。

## 购买路线有讲究

芯片商店是 22 种格子之一，所以走到它需要规划：

1. **先搞钱** —— 横财、彩票与命运格是收入侧。
2. **朝 `platform_relic` 走，而不是随便哪个商店** —— 普通商店里没有芯片。
3. **利用急速与传送门格**更快抵达；一次连锁的急速能省下一圈。

::: info
**芯片商店与普通商店是两个不同的格子、名字也不同。** 在棋盘清单里分别写作**芯片商店**与**商店**。在你为金色芯片攒够钱时踩错格子会浪费一个回合，所以要学会分辨两者。见[棋盘](02_the_board)。
:::

## 芯片与卡牌的分工

它们解决不同的问题，而这个差别值得内化：

| | 芯片 | 卡牌 |
|:---|:---|:---|
| 持续性 | **永久属性提升** | 用掉即消耗 |
| 何时有用 | 一直有用 | 多数只在战斗中 |
| 如何获得 | 在芯片商店购买 | 卡牌弹跳格、抽手牌 |
| 代价 | 金钱 | 该牌的消耗值 |

::: tip
**芯片是你的长线，卡牌是你的当下。** 把每一枚钱都花在卡牌上的玩家会手牌很热闹但属性薄弱；把钱攒向金色芯片的玩家会在后面几圈胜出。在一条短的演示环线上，打牌的玩家可能看起来更强——但在长局里，攒芯片的玩家会拉开差距。
:::
