# x3d Map

x3d Map 提供可旋转、缩放的三维地形地图，并包含小地图、路径点与客户端区块缓存管理。本套文档依据 `x3d_map` 的 `1.0.3` 当前源码编写。

## 阅读路线

- [地图操作与图层](01_controls)：打开地图、移动视角并使用两组工具栏。
- [小地图](02_minimap)：HUD 内容、内置设置与客户端参数。
- [路径点](03_waypoints)：创建、编辑、隐藏、分享和传送。
- [区块与本地缓存](04_chunks_and_cache)：地图数据来源、选择工具、保存和删除。
- [性能与兼容模式](05_performance_and_compatibility)：LOD、显存、更新队列和 OpenGL 能力。
- [服务端选项](06_server_options)：区块重发、批处理风险与海平面覆盖。

## 工作方式

- 客户端读取已经收到的区块，并编译方块级地形与远距离高度场。
- 地图按存档或服务器名称和维度分别保存到游戏目录下的 `x3dmap` 文件夹。
- 世界地图与小地图复用同一份地形缓存，但有各自的相机和显示设置。
- 地图不提供洞穴视图；服务器区块重发也不会改变这一限制。

::: warning
地图缓存、路径点和小地图设置是客户端数据，不是服务器世界的权威备份。删除缓存前应确认是否需要备份 `x3dmap` 目录。
:::
