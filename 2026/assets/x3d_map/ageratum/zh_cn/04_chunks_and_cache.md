# 区块与本地缓存

## 地图数据从哪里来

客户端收到区块后，模组把区块加入更新队列；方块变化也会把对应区块重新排队。编译器读取表面高度、可见方块面和颜色，生成近景方块数据与远景高度场。

缓存按存档或服务器名称和维度分开，目录结构为：

`<游戏目录>/x3dmap/<存档或服务器>/<维度命名空间>/<维度路径>/`

路径点和小地图设置作为扩展存储保存在同一维度目录中。

## 更新队列与保存

默认每 `20` tick 从更新队列处理最多 `1000` 个区块。每 `1200` tick，也就是约 60 秒，保存所有维度的脏区域与扩展数据。退出世界或卸载维度时还会执行一次同步保存。

“强制更新”只把玩家当前客户端渲染距离内的区块提交到本地重编译队列，不会让服务器发送尚未收到的区块。

## 框选区块

1. 点击顶部“选择模式”按钮。
2. 在地图地形上按住鼠标左键拖出矩形。
3. 松开按键后，矩形覆盖的区块会加入当前选择集。
4. 选择以下操作之一。

| 操作 | 实际效果 |
|:---|:---|
| 清除选择 | 只清空当前选择，不改缓存 |
| 客户端重绘 | 使用客户端已有区块数据重新编译所选区块 |
| 服务器重发 | 请求服务端加载并发送所选区块；按钮受配置控制 |
| 删除区块 | 从本地地图缓存删除所选区块 |

选择集只在地图界面打开期间存在，关闭地图会清空。

## 删除全部缓存

顶部第一行的红色“删除”按钮不是删除当前选择，而是在确认后遍历并删除当前维度缓存中的全部区块。界面会明确提示操作不可撤销。

删除不会修改服务器世界。之后只有重新收到并编译区块，或者使用允许的服务器重发功能，地图内容才会恢复。

::: danger
删除前关闭地图并备份对应 `x3dmap` 目录最稳妥。路径点属于扩展文件，区块删除与整个目录删除的影响不同，不要直接把两者混为一谈。
:::
