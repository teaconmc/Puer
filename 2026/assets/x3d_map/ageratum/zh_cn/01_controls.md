# 地图操作与图层

## 打开地图

默认按 `M` 打开世界地图。这个按键可以重新绑定；只有玩家已经进入世界且没有其他界面打开时，按键才会创建地图界面。加入世界后，模组会在聊天栏提示当前绑定键。

地图第一次打开时以玩家位置为中心，并采用主相机的朝向。左侧的定位按钮可以随时把地图中心重新移回玩家。

## 相机操作

| 操作 | 输入 |
|:---|:---|
| 平移 | 按住鼠标右键拖动 |
| 键盘平移 | `W`、`A`、`S`、`D` |
| 自由旋转 | 按住鼠标中键拖动 |
| 水平旋转 | `Q`、`E` |
| 缩放 | 鼠标滚轮 |
| 回到玩家 | 点击左侧定位按钮 |

滚轮先在 `5` 到 `90` 度之间改变视场角；达到边界后会改变相机距离。键盘平移速度也会随缩放距离变化，因此远景移动会更快。

## 左侧图层开关

左侧工具栏可以分别显示或隐藏：

- 三维地形。
- 指南针。
- 地面网格。
- 可见在线玩家的头像与名称。
- 相机目标标记。
- 相机附近区块裁剪。
- 调试信息。

“相机附近区块裁剪”会跳过目标附近约 64 格范围的地形，可用于观察被地形遮挡的区域，但它不是洞穴剖面工具。

## 顶部视图参数

顶部第一行包含两种 Y 轴模式：让相机目标高度跟随地形，或者使用固定高度。固定模式旁的数字框允许在当前维度高度范围内输入 Y 值。

同一行还可设置：

- **LOD 距离**：近距离方块级地形切换到更低细节层级的基础距离，默认 `512` 格。
- **加载距离**：地图为视图保留和加载数据的目标距离，界面默认 `1024` 格。
- **强制更新**：把玩家当前客户端渲染距离内的区块提交到本地重编译队列。

顶部第二行由路径点、小地图、区块选择、地图信息等扩展加入按钮。每个图标都有悬停提示，先查看提示再执行删除或服务器请求操作。
