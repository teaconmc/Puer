# 伤害类型与战斗

本页涵盖三种自定义伤害类型、驱动一切「进入战斗」类遗物的战斗状态追踪器，以及模组的战斗物品。

## 伤害类型

| ID | 消息 ID | 消耗值 | 标签 |
|:---|:---|:---|:---|
| `minethespire:orb_lightning` | `lightningBolt` | 0.1 | `is_lightning`、`bypasses_cooldown`、`bypasses_shield`、`avoids_guardian_thorns`、`no_knockback`、`panic_causes`、`always_triggers_silverfish`、`always_hurts_ender_dragons` |
| `minethespire:orb_dark` | `magic` | 0.1 | `bypasses_cooldown`、`bypasses_shield`、`avoids_guardian_thorns`、`always_triggers_silverfish`、`no_knockback`、`panic_causes`、`always_hurts_ender_dragons` |
| `minethespire:bouncing_hit` | `thrown` | 0.1 | `no_knockback`、`panic_causes`、`is_projectile`、`always_triggers_silverfish` |

消息 ID 全部借用原版，因此死亡消息读起来就像受害者死于闪电、死于魔法或死于投掷物；模组没有提供任何专用的死亡消息翻译键。

两种 Orb 伤害类型都绕过无敌冷却与盾牌，这正是 Orb 能在每个被动周期都稳定削减目标、而不受命中时机限制的原因。

## 战斗状态

战斗状态是附加在每个生物身上的同步附件（`minethespire:combat_state`），持有一个剩余 tick 计数器和一组敌对 UUID。它是遗物触发的根本依据。

### 进入战斗

以下任一情形发生时，两个实体会**互相**把对方登记为敌对：

- `AttackEntityEvent` —— 玩家攻击某个生物。
- `LivingIncomingDamageEvent` —— 实体受到伤害，且伤害来源实体（或直接实体）是另一个生物而非自身。

添加敌对会把计数器重置为 `max_combat_ticks`（默认 300 tick = 15 秒）。`onEnterCombat` 回调只在计数器处于最大值**且**上一 tick 的值小于等于 0 时触发，因此在战斗中途新增敌对不会重复触发进入战斗类加成。

### 脱离战斗

计数器每 tick 减 1。有两种方式让它结束：

- 若敌对集合变空、而计数器仍高于 `quick_exit_combat_ticks`（默认 60），计数器会被压到该值——在敌对目标全部消失或死亡后快速收尾。
- 计数器恰好降到 1 的那一 tick，`onExitCombat` 触发，随后敌对集合被清空。

敌对目标也会被惰性清理：任何无法在同一维度解析为存活且未被移除的生物的 UUID，都会在遍历时被剔除；`EntityLeaveLevelEvent` 还会把离场实体从每个敌对方的集合中移除。

### 各时机触发什么

| 时机 | 效果 |
|:---|:---|
| 新增一个敌对 | 弹珠袋 → 对该敌对施加 100 tick 的易伤 II |
| 进入战斗 | 蛇之戒指／静默 面具 → 100 tick 的原版速度 II |
| 进入战斗 | 破损核心／故障 面具 → 引导一个闪电充能球，但仅当你当前持有零个 Orb |
| 进入战斗 | 锚／舷夹板／舵盘 → 把 `prepared_blocking` 加入格挡值 |
| 进入战斗 | 小血瓶 → 恢复 2 点生命 |
| **脱离**战斗 | 赤牛 → 无限时长的活力 VIII |
| **脱离**战斗 | 燃烧之血／铁甲 面具 → 恢复 6 点生命 |
| 受到伤害 | 百年积木 → 100 tick 的原版速度 II |

其中三条与游戏内提示文本不符，而实际运行的是代码：

- **赤牛的提示文本写「战斗前，获得 8 点活力」，但代码是从 `onExitCombat` 调用的。** 你是在战斗*结束*时获得活力，而不是开始时。（在脱离战斗状态下通过 Curios 槽位装备赤牛也会立即授予。）
- **燃烧之血的提示文本写「完胜后，恢复 6 点生命值」。** 源码中根本不存在「完胜」的概念；它在*任何*一次脱离战斗时都恢复 6 点，包括你差点被打死或直接跑掉的情况。
- **蛇之戒指的提示文本写「移动速度提升 30%」，但代码施加的是原版速度 II**，按原版计算是 +40 % 移动速度。已弃用的 `serpent_speed` 效果*确实*包含一个真正的 +30 % 修饰符，但没有任何代码施加它。

另请注意活力会被攻击消耗，因此赤牛给的无限活力 VIII 会在你*下一场*战斗的第一次命中时被花掉。

## 荆棘

`minethespire:thorns` 属性（默认 0，上限 1024）由铜制鳞片提供（+3）。在 `LivingIncomingDamageEvent` 中，若受害者拥有任何荆棘值，伤害来源的**直接实体**会受到等量的原版 `minecraft:thorns` 伤害。

由实现方式导出两个后果：

- 因为读取的是*直接*实体，箭矢或投掷物会代替射手承受这份反伤。
- 因为它运行在来袭伤害事件上，即使这次命中随后被格挡值完全吸收，荆棘依然会触发。

## 战斗物品

### 重刃

一把史诗品质的下界合金级剑：+13 攻击伤害，−3.75 攻击速度。它的 `getAttackDamageBonus` 会在常规伤害之上追加 `6.0 × (力量等级 + 1)`。原版力量本身已提供每级 +3，因此总缩放为每级 9 点——恰好是提示文本所承诺的「力量在这个武器上发挥 3 倍效果」。提示行会实时预览你当前的加成。

### 痛击

一把铁级剑（+5 攻击伤害，−3.35 攻击速度），命中时施加 **80 tick 的易伤 II**，但仅当攻击者的攻击蓄力比例至少为 `0.9`——即一次满蓄力挥击。

两处怪癖：类名是 `PainStrickItem`，提示键是 `tooltip.minethespire.pain_strick.tip`（写作 “strick”），而物品 ID 却是 `pain_strike`。另外由于 `ModItems` 注册它时没有调用 `stacksTo(1)`，这把剑**可堆叠到 64**。

### 弹跳药瓶

一种投掷药瓶，重力 `0.05`，投掷力 `1.35`，寿命 200 tick。

- 命中生物时造成 `0.0` 点 `bouncing_hit` 伤害——这次命中纯粹为了触发伤害事件——随后施加**蛇毒**：目标原本没有蛇毒则等级为 2（蛇毒 III），否则为原有等级 **+3**。
- 它最多可以弹跳两次，因此一次投掷最多命中**三**下，与提示文本「施加 蛇毒III 3次」一致。
- 命中后它会在刚击中的实体周围 8 格内寻找你战斗状态中的另一个敌对目标，并以带前置预判的抛物线弧线飞向它。若没有第二个敌对目标，则重新瞄准同一实体；若完全没有有效实体，则随机选取一个附近点位。
- 同一实体在 8 tick 内不会被重复命中，投掷者在飞行的前 10 tick 内免疫。
- 撞到方块时会沿命中轴反射速度，并缩放至 75 %。

### 暗黑手里剑

暗黑手里剑有两套完全独立的动作。

**右键——投掷。** 以 1.2 的力量生成一个 `dark_shuriken_projectile`，对命中的第一个实体造成 `5.0` 点原版 `thrown` 类型伤害，随后作为物品掉落在地（除非投掷者拥有无限材料）。每次投掷消耗一枚。

**按住左键 20 tick——心灵绽放交易。** 客户端检测到主手持有暗黑手里剑并按住攻击键，会抑制普通攻击、播放物品激活动画并使用吹号角姿势，然后计数到 20。完成后服务端随即：

1. 施加**无限时长**的心灵绽放。
2. 为**每一个装备槽**附上该物品支持的全部附魔，均为最高等级。
3. 消耗一枚暗黑手里剑。

这就是提示文本用绿字和红字宣告的交易：*「最大化附魔所有装备」*与*「你不能再恢复生命」*。考虑到心灵绽放极难移除（见 [04 状态效果](04_effects)），请把它视为永久性的。

那 20 tick 的蓄力计时完全存在于客户端。服务端处理器只重新检查主手物品是不是暗黑手里剑——它并不验证是否真的进行过蓄力，也没有任何冷却。
