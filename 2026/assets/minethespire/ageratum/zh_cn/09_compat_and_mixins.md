# 与其他模组一起玩

除 NeoForge 与 Minecraft 之外没有任何必需项。有两个模组加装后会带来实质差别。

## Curios：两个专用遗物栏

**Curios 是最值得装的那一个。** 装了它你会得到：

| 功能 | 有 Curios | 没有 |
|:---|:---|:---|
| 专用遗物栏 | **两个** | — |
| 右键装备遗物 | **可以** | — |
| 分栏位的提示文本标题 | **有** | — |
| 遗物仍然生效 | 是 | **是** |

::: tip
**遗物两种情况下都能用。** 没有 Curios 时，模组会改为在你的普通装备栏里寻找遗物，因此不会出问题，也不会有哪件遗物变得无用。

你失去的是便利：那两个专设栏位与右键装备的流程。如果你会用到遗物，Curios 会让体验明显顺畅。
:::

若未安装 Curios，服务端会在启动时记录一次说明——那条消息是提示性的，不是报错。

## Jade：提示文本上的格挡值

装了 **Jade** 之后，看向实体时它的提示文本会多出一行**格挡值**。该功能默认开启，无需配置。

这个数字的含义见[格挡值与 HUD](07_hud_and_blocking)。

## JEI：能用，但不额外提供内容

模组注册了 JEI 插件，但它**不贡献任何自定义分类与信息页**。

::: info
模组唯一那条合成配方确实会出现在 JEI 里——但那只是因为它是普通的有序配方，JEI 自己就能收录。**不要指望 JEI 里有讲解宝珠、技能或遗物的页面**；那些信息在本组文档与游戏内，而不在 JEI。
:::

## ⚠️ 那 46 件遗物目前还没有效果

::: danger
**模组含有 46 件目前是惰性的遗物。** 它们确实存在，你能获得并持有，也有名称与贴图——但它们的效果尚未实现。

源码里明确把它们标记为待完成。所以如果你收集到一件遗物却发现什么都没发生，**那是模组当前的状态，而不是你的安装出了问题。**

遗物**系统**——包括上面说的 Curios 栏位——是已建成并可用的。尚未到来的是各件遗物各自的效果。
:::

## 模组刻意不添加的东西

| 项 | 状态 |
|:---|:---|
| 方块 | **无** —— 本模组不添加任何方块 |
| 附魔 | **无** |
| 战利品表改动 | **无** —— 它不修改原版掉落 |

::: info
**宝珠永远不会破坏方块。** 闪电宝珠与暗宝珠里有一段未启用的代码，本会在命中时摧毁松软方块，但它是关闭的——你可以在室内发射宝珠而不损伤自己的建筑。
:::

## 本版本没有的卡牌关键词系统

如果你翻看文件，可能会看到「Ethereal / Innate / Exhaust / Retain」这类名字，但**那整套系统都未启用**。它是为未来版本做的铺垫。

## 小结

| 模组 | 要不要装？ |
|:---|:---|
| **Curios** | **推荐** —— 两个遗物栏与右键装备 |
| **Jade** | 有则更好 —— 实体提示上显示格挡值 |
| JEI | 可选 —— 本模组不提供自定义内容 |
