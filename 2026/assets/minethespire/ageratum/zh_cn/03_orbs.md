# Orb 系统

Orb（充能球）是环绕在你头顶的小型实体，会按计时器自动执行**被动**动作，也可以被消耗掉以触发一次更强的**唤发**效果。它们保存在每个实体的附件（`minethespire:orb_manager`）中，该附件持有一个有序、容量受限的 Orb UUID 列表。

任何 `LivingEntity` 都能拥有 Orb，不限于玩家。

## 四种 Orb

枚举 `OrbType` 恰好有四个值，且源码中首字母大写（`Lightning`、`Frost`、`Dark`、`Plasma`）——这一点对 `/mts orb channel` 的参数很重要。

| 实体 ID | 引导它的物品 | 被动动作 | 唤发动作 |
|:---|:---|:---|:---|
| `minethespire:lightning_orb` | `minethespire:lightning_orb` | 对敌人造成 3 点伤害（仅战斗中） | 8 点伤害的弹射物 |
| `minethespire:frost_orb` | `minethespire:frost_orb` | +5 格挡值 | +20 格挡值，随后消散 |
| `minethespire:dark_orb` | `minethespire:dark_orb` | 蓄能 +3（仅战斗中） | 弹射物，造成等于全部蓄能的伤害 |
| `minethespire:plasma_orb` | `minethespire:plasma_orb` | 无 | 授予可叠加的等离子充能 |

上表中所有伤害与格挡值数值都会经过 `focusAdjusted` 处理：加上 `minethespire:focus` 属性值，并把结果限制在 0 以上。

## Orb 的共通行为

每个 Orb 都是无重力、无碰撞的实体，碰撞箱为 `0.3125 × 0.3125`。它无法被攻击、无法被弹射物击中，`hurtServer` 恒定返回 `false`。

| 属性 | 值 |
|:---|:---|
| 轨道半径 | `1 + 0.15 × sin(球体 tick × 0.07)` 格 |
| 轨道转速 | 每主人 tick `0.08` 弧度 |
| 轨道平面 | 垂直于主人视线方向，以眼部位置为中心 |
| 主人牵引范围 | 48 格——超出即消散 |
| 唤发后寿命上限 | 200 tick（10 秒） |
| 客户端追踪范围 | 8 区块，更新间隔 1 tick |

当主人死亡、离开维度、超出范围，或该 Orb 不再位于主人的序列中时，Orb 会消散（伴随 `AMETHYST_BLOCK_BREAK` 音效与白色烟雾）。

## 容量与挤出

| 属性 | 默认值 | 范围 |
|:---|:---|:---|
| `minethespire:max_charge_ball` | 1 | 0 – 16 |
| `minethespire:orb_attack_range` | 8 | 0 – 64 |
| `minethespire:orb_passive_speed` | 0.5 | 0.01 – 20 |

容量是 `max_charge_ball` 向下取整，因此默认你**只能**持有一个 Orb。`cracked_core` 与 `defect_mask` 各提供 +2。

Orb 列表是先进先出的。在满容量时引导新 Orb 会**唤发最旧的那个**而不是直接丢弃——你依然能得到它的唤发效果。如果 `max_charge_ball` 下降（例如卸下破损核心），列表尾部多出的 Orb 会直接消散，不会唤发。

## 被动计时器

被动周期长度是 `ceil(20 / orb_passive_speed)` tick——**默认 0.5 时为 40 tick**。同类型的 Orb 共用这个周期，并在周期内均匀错相，所以三个冰霜球会按等间隔轮流动作，而不是同时触发。

等离子球只要存在，就会给 `orb_passive_speed` 添加一个 `+0.2` 的临时修饰符，从而缩短你**所有** Orb 的周期（0.5 → 0.7 对应 29 tick 周期）。

## 目标选择

被动与唤发攻击都通过 `CombatState.getRandomHostileIn` 选取目标：从你的战斗状态敌对集合中，**随机**挑一个位于 `orb_attack_range` 以内的实体。这带来两个需要注意的后果：

- Orb 不会攻击任何还未与你进入战斗的目标。在一头无害的牛旁边引导闪电球，只要它没被登记为敌对，就什么都不会发生。
- 每次动作触发时都会重新随机，因此攻击会在当前所有敌对目标之间随机散开，而不会集火某一个。

若 Orb 在没有有效目标时被唤发，闪电球与黑暗球会沿主人视线方向以每 tick `0.7` 格直线飞出；有目标时以相同速度追踪。

## 各类型细节

### 闪电充能球

- 被动：仅在主人处于战斗中时触发；造成 `focus + 3` 点 `minethespire:orb_lightning` 伤害，并向目标绘制一条电火花／末地烛粒子线。
- 唤发：变为追踪弹射物；击中的第一个实体受到 `focus + 8` 伤害，随后 Orb 消散。
- 脱离战斗后开始 `400–599` tick 的倒计时，到期消散。重新进入战斗会重置该倒计时。

### 冰霜充能球

- 被动：为主人授予 `focus + 5` 格挡值，伴随锁链落地音效与雪花粒子。无论是否在战斗中都会生效。
- 唤发：授予 `focus + 20` 格挡值并立即消散。
- 冰霜球在创建时就获得一个 `400–599` tick 的随机寿命，且**无条件**倒数。与闪电球不同，处于战斗中并不会延长它，所以冰霜球总是在大约 20–30 秒后到期。

### 黑暗充能球

- 初始蓄能为 `6.0`，以数字形式显示在球体旁。
- 战斗中被动：蓄能增加 `focus + 3`。
- 脱离战斗时被动：蓄能减少 `max(蓄能 × 0.2, 1.0)`，降到 0 时 Orb 消散。
- 唤发：变为追踪弹射物，造成等于其**当前蓄能**的 `minethespire:orb_dark` 伤害。命中时不再叠加 focus——focus 已在每次蓄能时计入。

### 等离子充能球

- 完全没有被动动作；它的 `passiveAction` 只调用空的基类实现。
- 存活期间提供上文所述的 `orb_passive_speed` 加成，因此它的真正用途是加速你的其他 Orb。
- 唤发：读取你当前的**等离子充能**效果，移除它，再以 `等级 + 1` 重新施加 600 tick——因此反复唤发可以无限叠加等级。随后 Orb 用 `discard()` 移除而非 `dissipate()`，所以不会产生烟雾或破碎音效。

## 引导物品与双重释放

四种 Orb 物品各自引导对应的 Orb。`minethespire:dualcast` 会复制你的第一个 Orb，把副本镜像到视线轴的另一侧，然后**同时唤发**原件与副本，伴随信标音效与两处电火花粒子。对黑暗球而言，副本会继承原件的蓄能。
