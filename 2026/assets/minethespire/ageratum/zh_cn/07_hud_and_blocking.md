# 格挡值与 HUD

格挡值是模组的伤害吸收层：一个会衰减的池子，在伤害触及生命值之前先行吸收，并以额外一行图标绘制在原版生命条下方。

## 存储方式

格挡值**不是**能力（capability）也不是 NBT 字段，而是某个属性的*基础值*。这正是它无需额外网络同步就能被 Jade、`/attribute` 和 HUD 读取的原因。

| 属性 | 默认值 | 最小值 | 最大值 |
|:---|:---|:---|:---|
| `minethespire:blocking_value` | 0 | 0 | 256 |
| `minethespire:blocking_value_change_rate` | −0.5 | −1024 | 1024 |

每个生物都附加了这两个属性，因此怪物同样可以持有格挡值。

## 衰减与回复

`BlockingValueHandler.tick` 每 tick 对每个生物运行，把 `blocking_value_change_rate` 加到当前值上并限制在 0 以上。按默认速率 `−0.5` 计算，格挡值**每秒流失 10 点**。

各类增益操纵的正是这个变化率：

| 来源 | 修饰符 | 结果速率 |
|:---|:---|:---|
| 壁垒效果 | +0.5 | `0.0` —— 衰减完全停止 |
| 快速格挡效果 | `等级 + 1.5` | 强正值，急速回复 |

因此壁垒并非「额外护盾」，而是「你的护盾停止流失」，壁垒药水可将这一状态维持 8 分钟。

## 吸收

在 `LivingDamageEvent.Pre` 中，伤害会被当前格挡值最多吸收等量的数值，池子同时扣除相同数量。若池子能覆盖整次命中，伤害变为 0。

该事件内部的顺序很重要：**易伤的伤害倍率先应用**，随后格挡值吸收的是已被放大后的数值。无实体的固定上限 1.0 则更早生效，位于 `LivingIncomingDamageEvent`。

## 获取方式

处理器提供三种不同的操作，来源使用哪一种会改变叠加行为：

| 操作 | 行为 | 使用者 |
|:---|:---|:---|
| `add` | 加到当前值上 | 冰霜球、岿然不动、`prepared_blocking` 类遗物 |
| `grant` | 设为 `max(当前值, 数值)` —— **不叠加** | 蜥蜴尾巴 |
| `multiply` | 乘以当前值 | 巩固 |

| 来源 | 数值 |
|:---|:---|
| 锚 | 进入战斗时 +30 |
| 舷夹板 | 进入战斗时 +40 |
| 舵盘 | 进入战斗时 +50 |
| 冰霜球被动 | 每周期 `focus + 5` |
| 冰霜球唤发 | `focus + 20` |
| `minethespire:impervious` | 食用时 +200 |
| `minethespire:entrench` | 使用时 ×2 |
| 蜥蜴尾巴免死 | 授予至 `2 × 最大生命值` |

由于属性上限为 **256**，上述若干项会被静默截断。岿然不动单独 +200 就几乎填满池子，而蜥蜴尾巴的 `2 × 最大生命值` 对任何最大生命值超过 128 的实体都会被压到 256。

`prepared_blocking`（默认 0，上限 256）是三件船具遗物贡献的属性；它只在进入战斗时被读取一次并转换为格挡值，所以提高它并不会给你永久护盾。

## 格挡值 HUD 行

`BlockingValueHudRenderer` 使用两张精灵图，在原版生命行上方绘制额外一行图标：

- `minethespire:hud/heart/blocking_value_full`
- `minethespire:hud/heart/blocking_value_half`

行为细节：

- 当格挡值小于等于 0、GUI 被隐藏，或当前游戏模式无法伤害玩家时，整行完全隐藏。
- 图标延续生命值网格：从生命值与伤害吸收容器之后紧接着开始，每行 10 个换行，并沿用玩家生命过多时原版使用的压缩行高。
- 一个图标代表 2 点，总数为奇数时最后一个图标渲染为半格。
- 渲染器会把自身高度回报给 `leftHeight`，因此其他 HUD 元素能正确地向上堆叠。

这一行没有配置开关；只要你拥有格挡值就会出现。

## 战斗状态 HUD

`CombatStateHudRenderer` 在**右下角**绘制一个小指示器，且**默认关闭**。启用客户端配置项 `combat_state`（「渲染战斗状态信息」）才能看到它。

| 元素 | 细节 |
|:---|:---|
| 图标 | 战斗中为 `minethespire:hud/combat_state_combat`，否则为 `minethespire:hud/combat_state_idle` |
| 图标尺寸 | 18 × 18，距两边各 8 像素 |
| 第 1 行 | `Time: <n>s` —— 剩余战斗刻数向上取整为整秒 |
| 第 2 行 | `Hostiles: <n>` —— 敌对 UUID 集合的大小 |
| 背景 | 文字后方的半透明黑色面板 |

两行字符串都是渲染器里硬编码的英文字面量，因此**没有翻译**；即使在中文客户端上也会显示 `Time:` / `Hostiles:`。

## Jade 集成

安装 Jade 后，任何生物的提示信息中都会追加一行格挡值。

- 由 `MineTheSpireJadePlugin` 注册为实体数据提供器加实体组件提供器，两者都针对 `LivingEntity`。
- 配置项为 `config.jade.plugin_minethespire.blocking_value`（「显示格挡值」），默认启用。
- 数值由服务端提供，并以成功色文本元素渲染，因此你可以在决定出手之前先读出怪物的护盾量。

## 实战理解

由于每秒衰减 10 点，格挡值是一种爆发资源而非被动增益。设计意图中的循环是：堆叠 `prepared_blocking` 遗物让每场战斗开局自带护盾；常驻引导一个冰霜球获得稳定细流；喝壁垒药水冻结池子；把巩固留到刚刚填满池子的时候用来翻倍。
