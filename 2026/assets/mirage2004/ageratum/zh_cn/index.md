# 2004

**2004**（模组 ID `mirage2004`，版本 `0.1.0`，MIT，作者 littlebai）是一套建筑方块，只为一件很具体的事而做：**中国 2000 年代初城市住宅的样子**。模组名就是年份。

光看调色板就能认出来——脏白、水磨石、马赛克蓝、日晒芥黄、灰紫褐；再看它选择建模的东西：**防盗网、水泥电线杆、架空电线、预制阳台窗、小方砖外墙**。这些正是大多数建筑模组会跳过的街道构件。

## 首先要知道的一件事

::: warning
**完全没有配方** —— 模组不随包任何 `recipe/` 目录。全部 275 个方块只能从创造分页取用或用 `/give`。但每个方块**都有**战利品表，因此**已放置的方块破坏后掉落自身**、建造过程不会损失材料；只是最初那一组无法在生存中合成。
:::

## 里面到底有什么

275 个方块听起来很多，但它们不是 275 件互不相干的东西。整套是**从一份很小的规格生成的**：23 种调色板颜色 × 18 个材料族，再加少数手工编写的特殊形状。掌握这两个轴就足以预测什么存在——见[调色板与材料族](02_palette_and_families)。

材料族既覆盖平整表面，也覆盖让场景读起来像真实地点的街道构件：

| 分组 | 举例 |
|:---|:---|
| 表面 | 小方砖、竖条砖、横条砖、马赛克、水磨石、水泥、混凝土与抹灰、砖与瓦、石与骨料 |
| 形状 | 实心、台阶、楼梯、墙、窗格、镂空、方块、斜坡、三角墙 |
| 玻璃 | 幕墙玻璃、窗玻璃板、框窗 1/2/3、预制阳台窗 |
| 街道 | 防盗网（板/拱/箱/笼/帽）、水泥电线杆、电线、线缆系统 |

## 本文档的覆盖范围

方块目录有 277 条定义且高度规整。这些页面不逐个列出 ID，而是先讲清**生成它们的两个轴**，然后记录那些**不**遵循该规律的部分——手工编写的碰撞形状、防盗网的连接标签、以及自定义模型加载器。这些正是你看创造分页无法得知的信息。
